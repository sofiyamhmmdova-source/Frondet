# İsmet Cahangirov Academy

Bu layihə tələbə üçün hazırlanmış frontend + backend öyrənmə platformasıdır. Layihədə:

- React + TypeScript + Tailwind CSS
- Redux Toolkit + RTK Query
- React Router
- Express.js backend
- Login / Register
- Admin dashboard
- Dərslər və video linkləri

## Başlamaq

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
