CSS Box Model nədir?

CSS Box Model (Qutu Modeli) — brauzer hər bir HTML elementini render edərkən istifadə etdiyi fundamental bir anlayışdır. Brauzer hər elementi dörd qatdan ibarət qutu kimi qəbul edir. Bu qatlar içəridən xaricə doğru belə sıralanır: content → padding → border → margin. Elementin ümumi yer tutması, görünüşü və qonşu elementlərlə məsafəsi məhz bu model vasitəsilə idarə olunur.

Border — Kənar Xətt Elementi əhatə edən xətt. Genişlik, stil, rəng ilə idarə olunur.
Margin — Xarici Boşluq Elementin xaricindəki şəffaf sahə. Qonşu elementlərlə məsafəni tənzimləyir.
🛠️

DevTools ipucu: Brauzerdə hər hansı elementi sağ klikləyin → İncele (Inspect) → Elements bölməsinin altındakı Computed tabında box modeli vizual şəkildə görə bilərsiniz.

Ümumi Genişlik Necə Hesablanır?

Standart (content-box) rejimdə elementin brauzer tərəfindən ayrılan ümumi eni bu düsturla hesablanır:

formula 
/* Ümumi eni */
total-width = width + padding-left + padding-right
            + border-left + border-right
            + margin-left + margin-right

/* Nümunə */
.element {
  width:          200px;
  padding:        20px;  /* sol+sağ = 40px */
  border:         5px solid #333; /* sol+sağ = 10px */
  margin:         15px;
}
/* Ümumi eni = 200 + 40 + 10 = 250px */
🟦

Content — Məzmun

Content Box Model-in ən daxili hissəsidir. Mətn, şəkil, video, digər elementlər — yəni əsl görünəcək məzmun buradadır. width və height xassələri birbaşa bu sahəni ölçür (content-box rejimində).

css 
.qutu {
  width:       250px;
  height:      80px;
  min-width:   100px;
  max-width:   400px;
  min-height:  50px;
  max-height:  200px;
  overflow:    hidden;
}
width: 100% / height: 45px
width: 60% / height: 35px
width: 40%

Əsas Xassələr

XassəStandart Dəyərİzah
width auto Elementin eni
height auto Elementin hündürlüyü
min-width 0 Minimum en — element bundan dar olmaz
max-width none Maksimum en — element bundan geniş olmaz
min-height 0 Minimum hündürlük
max-height none Maksimum hündürlük
overflow visible Sığmayan məzmunla nə ediləcəyi: hidden, scroll, auto
💡

width: 100% ilə width: auto arasındakı fərq: 100% valideynin enini götürür, amma padding/border əlavə olunduqda taşabilir. auto isə mövcud sahəyə uyğunlaşır. Responsive dizaynda max-width çox istifadə olunur.

🟩

Padding — Daxili Boşluq

Padding — məzmun (content) ilə border arasındakı daxili boşluqdur. Elementin background-color-u padding sahəsinə tətbiq olunur — bu xüsusiyyət onu margin-dən fərqləndirir. Padding elementin görünüşünü böyüdür, lakin ətrafındakı elementlərə məsafə qoymur.

css 
/* 1 dəyər: 4 tərəf bərabər */
.el { padding: 20px; }

/* 2 dəyər: üst-alt | sol-sağ */
.el { padding: 10px 20px; }

/* 3 dəyər: üst | sol-sağ | alt */
.el { padding: 10px 20px 15px; }

/* 4 dəyər: üst | sağ | alt | sol (saat istiqaməti) */
.el { padding: 10px 20px 15px 5px; }

/* Tərəflər ayrı-ayrı */
.el {
  padding-top:    10px;
  padding-right:  20px;
  padding-bottom: 15px;
  padding-left:   5px;
}
padding: 30px (yaşıl sahə)
Content

Arxa rəng padding-ə də şamil olur ↑

Shorthand Qaydaları

padding: A;

Bütün 4 tərəf A dəyərini alır

padding: A B;

A = üst+alt, B = sol+sağ

padding: A B C;

A = üst, B = sol+sağ, C = alt

padding: A B C D;

Saat istiqaməti: üst → sağ → alt → sol

⚠️

Nəzərə alın: padding mənfi dəyər (negative value) qəbul etmir. Mənfi dəyər vermək istəyirsinizsə, bunun əvəzinə margin-dən istifadə edin.

💡

% dəyəri: padding: 50% kimi faiz dəyər veriləndə bu həm üst-alt, həm sol-sağ üçün valideynin enindən hesablanır. Bu xüsusiyyət aspect-ratio saxlamaq üçün istifadə olunur.

Border — Kənar Xətt

Border padding-i əhatə edən xəttdir. Üç əsas xassəsi var: genişlik (width), stil (style) və rəng (color). Bunları shorthand ilə birlikdə yazmaq mümkündür. border-radius ilə küncləri yuvarlatmaq olar.

css 
/* Shorthand: genişlik | stil | rəng */
.el { border: 2px solid #A78BFA; }

/* Tərəflər ayrı-ayrı */
.el {
  border-top:    3px dashed #60A5FA;
  border-right:  3px solid  #4ADE80;
  border-bottom: 3px dotted #F97316;
  border-left:   0;
}

/* Xassələr ayrı-ayrı */
.el {
  border-width: 2px;
  border-style: solid;
  border-color: #A78BFA;
}

/* Yuvarlanmış küncler */
.el {
  border-radius: 8px;          /* hamısı bərabər */
  border-radius: 50%;         /* dairə */
  border-radius: 8px 0 8px 0; /* üst-sol, üst-sağ, alt-sağ, alt-sol */
}

border-style: none standart dəyərdir — yəni border-color və ya border-width versəniz belə, style göstərməsəniz border görünməz.

Margin — Xarici Boşluq

Margin — elementin xarici boşluğudur, yəni border-dan kənardakı şəffaf sahədir. Qonşu elementlər arasındakı məsafəni tənzimləyir. Margin həmişə şəffafdır — background-color buraya tətbiq olunmur.

css 
/* Shorthand (padding kimi eyni qayda) */
.el { margin: 20px; }
.el { margin: 10px 20px; }
.el { margin: 10px 20px 15px 5px; }

/* Elementi mərkəzləmək üçün */
.el {
  width:  300px;
  margin: 0 auto; /* sol+sağ auto = mərkəz */
}

/* Mənfi margin */
.el { margin-top: -20px; }

/* Tərəflər ayrı-ayrı */
.el {
  margin-top:    10px;
  margin-right:  20px;
  margin-bottom: 15px;
  margin-left:   5px;
}
margin: 20px
(narıncı sahə = margin)

⚠️ Margin Collapsing — Marjin Yığılması

CSS-in ən çaşdırıcı davranışlarından biri — iki şaquli (vertical) blok elementin marjinləri toplanmır, sadəcə böyük olanı qəbul edilir. Bu fenomenə Margin Collapsing deyilir.

❌ Gözlənilən (50+30=80px)

Birinci qutu
margin-bottom: 50px
80px boşluq ??
İkinci qutu
margin-top: 30px

✅ Əslində olan (max=50px)

Birinci qutu
margin-bottom: 50px
50px (böyük olan)
İkinci qutu
margin-top: 30px
🚨

Margin collapsing yalnız şaquli (vertical) istiqamətdə baş verir. Üfüqi (horizontal) marginlər həmişə toplanır. Ayrıca, flex və ya grid container-larında margin collapsing baş vermir.

💡

margin: 0 auto — elementi üfüqi olaraq mərkəzləşdirməyin klassik üsulu. Bunun işləməsi üçün elementin mütləq width dəyəri olmalıdır, həm də display: block olmalıdır.

Box-sizing

box-sizing xassəsi brauzerə width/height-in nəyi əhatə etdiyini bildirir. Bu xassənin iki dəyəri var: content-box (standart, köhnə davranış) və border-box (müasir, tövsiyə edilən). Fərqi anlamaq responsive dizaynın açarıdır.

❌ content-box (standart)

width yalnız məzmunu ölçür. Padding və border əlavə olunduqda element daha geniş olur.

width:100% + padding + border → DAŞIR!

width: 100% olsa da, padding (12+12=24px) +
border (4+4=8px) əlavə olunur → 132px

✅ border-box (tövsiyə edilən)

width padding + border-u özündə saxlayır. Element həmişə tam olaraq göstərilən eni tutur.

width:100% = tam sahə ✓

width: 100% — padding və border buraya daxildir.
Heç vaxt daşmır.

css 
/* content-box (standart — problematik) */
.content-box-el {
  box-sizing: content-box; /* standart dəyər */
  width:       200px;
  padding:     20px;
  border:      5px solid;
  /* Real eni = 200 + 40 + 10 = 250px */
}

/* border-box (tövsiyə edilən) */
.border-box-el {
  box-sizing: border-box;
  width:       200px;
  padding:     20px;
  border:      5px solid;
  /* Real eni = həmişə 200px */
}

/* 🌟 Global Reset — bütün proyektlərdə tövsiyə edilir */
*, *::before, *::after {
  box-sizing: border-box;
}
🌟

Ən yaxşı təcrübə: Hər proyektin başında *, *::before, *::after { box-sizing: border-box; } yazın. Bütün müasir CSS framework-lər (Bootstrap, Tailwind) bunu edir. Bu qayda olmadan width: 50% + padding: 20px elementi gözlənilmədən daşıdır.

📍

Position — Mövqe Xassəsi

position xassəsi HTML elementinin brauzerdə necə mövqeləndirildiyini müəyyən edir. Hansı mövqedə olacağını top, right, bottom, left xassələri ilə dəqiqləşdiririk. 5 dəyəri var: static relative absolute fixed sticky

position: static — standart dəyərdir. Elementlər normal sənəd axını (document flow) ilə yerləşir. top, right, bottom, left xassələri heç bir effekt vermir. z-index də işləmir.

🔵 Birinci qutu — position: static (standart)
🔵 İkinci qutu — normal axın
🔵 Üçüncü qutu — top: 50px yazmaq bir şey dəyişdirmir
css 
.el {
  position: static;  /* standart — yazmağa ehtiyac yoxdur */
  top:      50px;   /* ❌ heç bir effekt yoxdur */
  left:     20px;   /* ❌ heç bir effekt yoxdur */
}
📌

Bütün elementlər yaradılanda position: static ilə gəlir. Xüsusi mövqeləndirmə lazım olmadıqda bu dəyəri dəyişdirməyin.

position: relative — element öz normal mövqeyindən nisbi olaraq köçürülür. Ən vacib məqam: orijinal sahə sənəddə qalır (ghost kimi), digər elementlər sanki o element hələ orada dayanırmış kimi davranır. top, right, bottom, left işləyir.

Normal qutu
← Bu yer boş qalır (orijinal mövqe)
↘ position: relative + top:14px + left:24px
Sonrakı qutu — yuxarıdakı boşluğu hiss edir
css 
.el {
  position: relative;
  top:      14px;  /* normal mövqeyindən 14px aşağı */
  left:     24px;  /* normal mövqeyindən 24px sağa */
}
/* ✅ Orijinal yer dokümanda qalır */
/* ✅ absolute child üçün ata/əcdad kimi istifadə olunur */
💡

position: relative-nin ən geniş istifadəsi özü köçürülmək deyil, position: absolute olan uşaq elementlər üçün çərçivə (containing block) yaratmaqdır.

position: absolute — element normal sənəd axınından tamamilə çıxır. Ən yaxın position: relative (və ya absolute/fixed/sticky) olan əcdad elementinə nisbətən mövqelənir. Belə əcdad tapılmazsa, <html> elementinə görə yerləşir. Digər elementlər sanki bu element mövcud deyilmiş kimi davranır.

position: relative olan valideyn Bu valideyn elementin içindəyik.
Aşağıdakı uşaq element mütləq mövqedədir.
position: absolute
top:8px / right:8px

↑ Yaşıl qutu valideyninin sağ üst küncünə yapışıb

css 
.valideyn {
  position: relative; /* çərçivə yaradır */
}

.usaq {
  position: absolute;
  top:      8px;   /* valideyndən 8px aşağı */
  right:    8px;   /* valideyndən 8px soldan */
}
/* Sənəd axınından çıxır — yer tutmur */
/* İstifadə: tooltip, dropdown, badge, overlay */
⚠️

position: absolute element normal axından çıxır, yəni digər elementlər onun yerini tutmaz. Valideyn elementin ölçüsünə də daxil olmur — valideyn darala bilər.

position: fixed — element sənəd axınından çıxır və viewport-a (görünən ekrana) nisbətən mövqelənir. Sürüşdürmə (scroll) zamanı yerindən hərəkət etmir. Naviqasiya çubuqları, "Yuxarı qayıt" düymələri, bildiriş çubuqları üçün istifadə olunur.

📌 position: fixed navbar — scroll etsəniz də qalır
Scroll edin → yuxarıdakı navbar sabit qalır...

Məzmun sürüşür...

Navbar hara getsəniz orada...

Bu CSS-in ən çox istifadə olunan xüsusiyyətlərindən biridir.
css 
.navbar {
  position: fixed;
  top:      0;
  left:     0;
  width:    100%;
  z-index:  1000;
}
/* Viewport-a görə mövqelənir */
/* Scroll-da yerindən tərpənmir */
/* İstifadə: navbar, cookie banner, chat widget */
📌

Fixed element sənəd axınından çıxdığı üçün arxasındakı məzmunu örtə bilər. body-ə padding-top əlavə edərək bunu həll edin.

position: sticky — relative ilə fixed-in birləşməsidir. Element əvvəlcə normal axında qalır, lakin scroll edərək müəyyən həddi keçdikdə yapışır. top, bottom dəyəri məcburidir. Valideyn konteyner görünən olduğu müddətdə yapışqan qalır.

Scroll ↓ edin:
📌 Sticky Başlıq — position: sticky + top: 0
Məzmun 1 — Normal axında başlayır...

Məzmun 2 — Scroll edərkən başlıq yapışır...

Məzmun 3 — Başlıq yuxarıda qalır...

Məzmun 4 — Valideyn bitənə qədər...

Məzmun 5 — Sonra da gedir.
css 
.sticky-header {
  position: sticky;
  top:      0;    /* viewport-dan 0px-dən aşağı düşmür */
  z-index:  10;
}
/* ✅ Normal axında qalır — sənəd quruluşunu pozmur */
/* ✅ Valideyn bitdikdə yapışqanlıq da sona çatır */
/* İstifadə: bölmə başlıqları, cədvəl başlıqları */

/* ⚠️ Valideynin overflow: hidden/auto olması sticky-ni sındırır! */
⚠️

Sticky işləmir? Yoxlayın: 1) top dəyəri verilib mi? 2) Valideyn elementdə overflow: hidden var mi? 3) Valideynin scroll edəcək qədər hündürlüyü varmı?

Z-index — Qat Sırası

z-index üst-üstə düşən elementlər arasında hansının önddə, hansının arxada görünəcəyini müəyyən edir. Z oxu ekrana perpendikulyar istiqamətdir. Yalnız position dəyəri static-dən fərqli olan elementlərə tətbiq olunur.

z-index: 1 arxada
z-index: 2 ortada
z-index: 3 öndə

Böyük z-index = daha önddə

css 
.arxada {
  position: absolute;
  z-index:  1;  /* ən arxada */
}

.ortada {
  position: absolute;
  z-index:  2;  /* ortada */
}

.onde {
  position: absolute;
  z-index:  3;  /* ən öndə */
}

/* ❌ Yanlış — static üçün işləmir */
.yanlis {
  position: static; /* z-index effektsiz */
  z-index:  999;
}
⚠️

Stacking Context (Yığım Konteksti): Bəzi CSS xassələri (opacity < 1, transform, filter) yeni stacking context yaradır. Bu halda həmin elementin uşaqlarının z-index-i yalnız öz kontekstindəki elementlərlə müqayisə olunur — xarici elementlərə görə deyil. Bu, z-index-in "işləməməsi"-nin ən geniş yayılmış səbəbidir.

Tövsiyə olunan z-index sistemi

1–10
Normal elementlər
100–200
Dropdown, tooltip
1000+
Navbar, modal, overlay
