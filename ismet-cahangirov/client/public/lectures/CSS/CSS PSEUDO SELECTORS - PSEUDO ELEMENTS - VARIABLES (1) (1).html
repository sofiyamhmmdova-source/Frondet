Pseudo Selectors

Elementlərin müəyyən vəziyyətlərini seçən CSS seçiciləri

Pseudo selector — bir sözlə, elementin özü deyil, onun müəyyən halını (state) hədəfləyən seçicidir. Bir : (bir iki nöqtə) ilə yazılır.

:hover — siçan üstündəykəndə

İstifadəçi siçanı elementin üzərinə gətirdikdə tətbiq olunur.

style.css :hover 
.düymə:hover {
  background-color: #3d6de0;
  transform:        translateY(-2px);
  box-shadow:       0 8px 20px rgba(0,0,255,.25);
  cursor:           pointer;
}

/* Transition olmadan hover ani görünür — həmişə əlavə edin! */
.düymə {
  transition: background-color .25s, transform .2s, box-shadow .25s;
}
🖱 Canlı Nümunə — düymənin üzərinə gəlin
⚠️ Diqqət

Mobil cihazlarda :hover etibarlı deyil — mobil üçün :focus və ya :active istifadə edin.

:focus — elementin fokuslanması

İstifadəçi Tab ilə və ya klikklə bir elementə fokuslandıqda tətbiq olunur. Əlçatanlıq (accessibility) baxımından çox vacibdir.

style.css :focus 
input:focus {
  border-color: #5b8af5;
  box-shadow:   0 0 0 3px rgba(91,138,245,.2);
  outline:      none; /* outline:none qoyduqda mütləq öz stilini yaz! */
}
⌨️ Canlı Nümunə — daxilə klikləyin və ya Tab basın
🚫 Ümumi Səhv

outline: none yazıb öz alternativini yazmamaq — bu klaviatura istifadəçilərini (o cümlədən əlilləri) interfeysdə itirmək deməkdir. Həmişə öz fokus stilini yaz!

:active — kliklənmə anı

Düymə basılıb buraxılana qədər olan an.

style.css :active 
.düymə:active {
  transform: scale(0.96);
  box-shadow: none;
}

:visited — ziyarət edilmiş link

Brauzer tarixçəsindəki linklərə tətbiq olunur.

style.css :visited 
a:link    { color: #5b8af5; } /* ziyarətsiz link */
a:visited { color: #b47df5; } /* ziyarət edilmiş */
a:hover   { color: #3ecf8e; }
a:active  { color: #f5a623; }
💡 LVHA Qaydası

Link → Visited → Hover → Active. Bu sıra mütləq gözlənilməlidir, əks halda stillər bir-birini ləğv edə bilər. Yadda saxlamaq üçün: LoVe HAte.

:disabled / :enabled — form elementləri

style.css :disabled / :enabled 
button:disabled {
  opacity:    0.45;
  cursor:     not-allowed;
  background: #555;
}
input:enabled {
  border-color: #5b8af5;
}

:checked — seçilmiş checkbox / radio

style.css :checked 
input[type="checkbox"]:checked + label {
  color:           #3ecf8e;
  font-weight:     700;
  text-decoration: line-through;
}

/* Gözəl custom toggle üçün əla üsul! */

:not() — istisna selektoru

Müəyyən elementi çıxarıb qalanları seçmək üçün istifadə olunur.

style.css :not() 
/* .xüsusi class-ı olmayan bütün p-ləri seç */
p:not(.xüsusi) {
  color: #aaa;
}

/* Son elementdən başqa hamısına border */
li:not(:last-child) {
  border-bottom: 1px solid #333;
}
✅ Praktik Tövsiyə

:not(:last-child) kombinasiyası ən son elementdən başqa hamısına stil vermək üçün çox istifadə olunur — separator xəttləri üçün əladır.

Pseudo Elements

HTML-ə toxunmadan element hissələrini yarat və ya seç

Pseudo element — elementin müəyyən hissəsini (ilk hərf, ilk sətir) seçmək və ya HTML-ə yeni məzmun (qabaq / arxa) əlavə etmək üçündür. İki :: ilə yazılır (köhnə CSS-də bir : də işləyirdi, amma standart ::-dir).

::before — elementin əvvəlinə məzmun əlavə et

style.css ::before 
.siyahı-maddəsi::before {
  content:     "▶ ";    /* content mütləq olmalıdır! */
  color:       #5b8af5;
  font-size:   0.8em;
}

/* Boş content ilə şəkil elementləri üçün istifadə */
.kart::before {
  content:    "";
  display:    block;
  width:      100%;
  height:     4px;
  background: linear-gradient(90deg, #5b8af5, #3ecf8e);
}
✨ Canlı Nümunə — ::before ilə oxucuqlar

CSS çox güclü bir dildir

Pseudo elementlər HTML-ə toxunmadan işləyir

Bu oxucuqlar CSS ilə əlavə edilib

::after — elementin sonuna məzmun əlavə et

style.css ::after 
.qiymət::after {
  content: " ₼";  /* manat simvolunu CSS-dən əlavə et */
  color:   #f5a623;
}

/* Clearfix — float-ları təmizləmək üçün klassik üsul */
.clearfix::after {
  content: "";
  display: table;
  clear:   both;
}
⚠️ Vacib Qeyd

content xassəsi mütləq olmalıdır, hətta boş olsa belə: content: "". Onsuz ::before / ::after ekranda görünməz.

::first-line — mətnin ilk sətri

style.css ::first-line 
p::first-line {
  font-weight: 700;
  color:       #f5a623;
  font-size:   1.1em;
  letter-spacing: 0.05em;
}

::first-letter — mətnin ilk hərfi

style.css ::first-letter 
p::first-letter {
  font-size:   2.5em;
  float:       left;
  margin-right:6px;
  color:       #5b8af5;
  line-height: 1;
}
📖 ::first-letter nümunəsi

CSS Pseudo Elements sayəsində mətnin ilk hərfini xüsusi stilə sala bilərik. Bu klassik qəzetlərdəki "drop cap" effektidir. Kitab dizaynında çox istifadə olunur.

::selection — seçilmiş mətn

İstifadəçi mətni seçdikdə (highlight) tətbiq olunur.

style.css ::selection 
::selection {
  background-color: #5b8af5;
  color:            #ffffff;
}

/* Yalnız müəyyən elementin seçimini dəyiş */
.xüsusi-mətn::selection {
  background-color: #3ecf8e;
  color:            #000;
}
💡 Məlumat

::selection üçün yalnız bu xassələr işləyir: color, background-color, text-shadow. Digər xassələr brauzerlər tərəfindən nəzərə alınmır.

::placeholder — input placeholder stili

style.css ::placeholder 
input::placeholder {
  color:       rgba(200,200,200,.45);
  font-style:  italic;
  font-size:   0.9em;
}
⚠️ Köhnə brauzer prefiksi

Çox köhnə brauzerlər üçün ::-webkit-input-placeholder və ::-moz-placeholder lazım ola bilər. Müasir layihələrdə artıq lazım deyil.

CSS Dəyişənləri (Custom Properties)

Dəyərləri bir yerdə saxla, hər yerdə istifadə et

CSS dəyişənləri (adı: Custom Properties) — eyni dəyəri (rəng, ölçü, font) bir dəfə yazıb, bütün faylda istifadə etməyə imkan verir. Dizayn sistemlərinin əsasıdır.

Elan (Declaration)

Dəyişən adı mütləq -- ilə başlamalıdır.

style.css Custom Properties elanı 
/* :root — bütün sənəddə görünən qlobal dəyişənlər */
:root {
  --əsas-rəng:       #5b8af5;
  --arxa-rəng:       #0e1117;
  --mətn-rəngi:      #dce3f0;
  --kənar-radius:    10px;
  --keçid-müddəti:   0.25s;
  --font-əsas:       'DejaVu Sans', Arial, sans-serif;
  --aralıq-kiçik:    8px;
  --aralıq-orta:     16px;
  --aralıq-böyük:    32px;
}

İstifadə (var())

style.css var() istifadəsi 
.düymə {
  background-color: var(--əsas-rəng);
  border-radius:    var(--kənar-radius);
  font-family:      var(--font-əsas);
  transition:       all var(--keçid-müddəti) ease;
  padding:          var(--aralıq-kiçik) var(--aralıq-orta);
}

.kart {
  background: var(--arxa-rəng);
  color:      var(--mətn-rəngi);
  padding:    var(--aralıq-böyük);
}

Ehtiyat dəyər (Fallback)

Dəyişən tapılmazsa istifadə ediləcək default dəyər — var(--dəyişən, ehtiyat):

style.css Fallback dəyər 
.element {
  /* əgər --xüsusi-rəng yoxdursa, #ff6b6b istifadə ediləcək */
  color: var(--xüsusi-rəng, #ff6b6b);

  /* başqa bir dəyişəni fallback kimi istifadə */
  background: var(--xüsusi-arxa, var(--arxa-rəng, #000));
}

Lokal dəyişən — komponentin öz dəyişəni

Dəyişənlər miras (inheritance) alınır — uşaq elementlər valideyinin dəyişənlərini görür.

style.css Lokal dəyişənlər 
.kart {
  --kart-rəng: #5b8af5;     /* bu .kart içindədir */
  border: 2px solid var(--kart-rəng);
}

.kart.uğur   { --kart-rəng: #3ecf8e; }
.kart.xəbərdarlıq { --kart-rəng: #f5a623; }
.kart.xəta   { --kart-rəng: #e05c5c; }

/* .kart içindəki bütün elementlər --kart-rəng görəcək */
.kart h3 { color: var(--kart-rəng); }
.kart svg { fill:  var(--kart-rəng); }
🎨 Canlı Nümunə — lokal dəyişənlər
Mavi kart (default --kart-rəng)
Yaşıl kart (--kart-rəng: #3ecf8e)
Narıncı kart (--kart-rəng: #f5a623)

JavaScript ilə dəyişmək

script.js JS + CSS Variables 
// Dəyişəni oxu
const rəng = getComputedStyle(document.documentElement)
  .getPropertyValue('--əsas-rəng');

// Dəyişəni yenilə (tema dəyişikliyi!)
document.documentElement.style
  .setProperty('--əsas-rəng', '#ff6b6b');

// Tema toggler nümunəsi
function togglTema(tema) {
  if (tema === 'qaranlıq') {
    document.documentElement.style.setProperty('--arxa', '#000');
    document.documentElement.style.setProperty('--mətn', '#fff');
  }
}
✅ Niyə CSS Variables SCSS dəyişənlərindən üstündür?

SCSS dəyişənləri compile zamanı sabit dəyərlərə çevrilir — dəyişdirilmir. CSS Variables isə real vaxt rejimində JS ilə dəyişdirilə bilir, miras alınır, mediya sorğularında override edilə bilər. Tema sistemi üçün CSS Variables düzgün seçimdir.

nth-child, odd & even Selektorlar

Elementləri sıralarına görə seç

:nth-child() ailəsi, elementləri sıra nömrəsinə görə seçməyə imkan verir. Cədvəllərin zebra effektindən tutmuş mürəkkəb şəbəkə dizaynlarına qədər hər yerdə istifadə olunur.

Əsas sintaksis

style.css nth-child sintaksisi 
/* Sabit sıra nömrəsi */
li:nth-child(1)  { color: red;    }  /* birinci element */
li:nth-child(3)  { color: blue;   }  /* üçüncü element */

/* Açar sözlər */
li:nth-child(odd)  { background: #1a2035; }  /* tək: 1,3,5,7... */
li:nth-child(even) { background: #0d1620; }  /* cüt: 2,4,6,8... */

/* An+B düsturu */
li:nth-child(2n)    /* hər 2-ci = cüt  */
li:nth-child(2n+1)  /* hər 2-ci +1 = tək  */
li:nth-child(3n)    /* hər 3-cü: 3,6,9,12... */
li:nth-child(3n+1)  /* 3-cü +1: 1,4,7,10... */
li:nth-child(n+4)   /* 4-cüdən sonra hamısı */
li:nth-child(-n+3)  /* yalnız ilk 3 element */

An+B Düsturu İzahı

izah An+B nə deməkdir? 
/*
  :nth-child(An + B)
  ─────────────────────────────────
  A  = addım (hər neçəsi?)
  n  = 0, 1, 2, 3 ... sonsuz
  B  = başlanğıc nöqtəsi (offset)

  Nümunə: :nth-child(3n+2)
  ─────────────────────────
  n=0 → 3×0+2 = 2   ✓
  n=1 → 3×1+2 = 5   ✓
  n=2 → 3×2+2 = 8   ✓
  Seçilən: 2-ci, 5-ci, 8-ci, 11-ci...
*/
🔢 Canlı Nümunə — odd/even/first/last
  • 1-ci element (first-child — narıncı)
  • 2-ci element (even — yaşıl)
  • 3-cü element (odd — mavi)
  • 4-cü element (even — yaşıl)
  • 5-ci element (odd — mavi)
  • 6-cı element (even — yaşıl)
  • 7-ci element (last-child — qırmızı)

:first-child & :last-child

style.css first / last child 
li:first-child {
  font-weight: 700;
  border-top:  2px solid #5b8af5;
}

li:last-child {
  border-bottom: none; /* son elementdən border-ı götür */
}

:nth-of-type() — eyni tipli elementlər arasında

:nth-child bütün qardaş elementlər arasında sayır. :nth-of-type isə yalnız eyni etiket tipli elementlər arasında sayır.

style.css nth-of-type 
/* HTML:
  <div>
    <p>Birinci p</p>    ← p:nth-of-type(1)
    <span>Span</span>
    <p>İkinci p</p>    ← p:nth-of-type(2)
    <p>Üçüncü p</p>   ← p:nth-of-type(3)
  </div>
*/

p:nth-of-type(2)  { color: #3ecf8e; }  /* ikinci p */
p:nth-of-type(odd){ color: #5b8af5; }  /* tək p-lər */
⚠️ nth-child vs nth-of-type fərqi

p:nth-child(2) — atasının 2-ci uşağı həm də p olmalıdır.
p:nth-of-type(2) — atasının p elementləri arasında 2-cisi.
Qarışdırmaq ən çox görülən CSS xətalarından biridir!

:nth-last-child() — sondan saymaq

style.css nth-last-child 
/* Sondan 2-ci element */
li:nth-last-child(2) {
  color: #b47df5;
}

/* Son 3 elementdən başqa hamısını seç */
li:not(:nth-last-child(-n+3)) {
  opacity: 0.6;
}

Zebra Cədvəl Nümunəsi

style.css Zebra cədvəl 
table { border-collapse: collapse; width: 100%; }

tr:nth-child(even) {
  background-color: rgba(91,138,245,.07);
}

tr:hover {
  background-color: rgba(91,138,245,.15);
}

/* Header cərgəni istisna et */
thead tr:hover {
  background-color: transparent;
}

Combinator Selektorlar

Elementlər arasındakı münasibəti hədəfləyən CSS operatorları

Combinator — iki seçici arasında əlaqəni müəyyən edir. Hansı elementin hansı elementə görə seçiləcəyini bildirir. Dörd növ mövcuddur:

Nəsil (Boşluq)
>Birbaşa uşaq
+Bitişik qardaş
~Ümumi qardaş

1. Nəsil Kombinator (Descendant) — boşluq

Bir elementin daxilindəki bütün nəsillərini (uşaq, nəvə, nəticə …) seçir. İç-içə nə qədər dərin olsa da tapır.

style.css Descendant combinator 
/* .nav içindəki bütün a elementlərini seç
   (birbaşa uşaq olsun ya nəvə — fərq etmir) */
.nav a {
  color:           #5b8af5;
  text-decoration: none;
}

/* article içindəki bütün p-ləri seç */
article p {
  line-height: 1.8;
  color:       #dce3f0;
}

/* HTML strukturu:
  <article>
    <p>Seçilir ✓</p>
    <div>
      <p>Bu da seçilir ✓ (nəvə)</p>
    </div>
  </article>
*/
🌳 Nəsil selektoru — article p

Bu mətni article p selektoru seçir — birbaşa uşaq

Bu da seçilir — div içindəki p (nəvə) ✓

⚠️ Performans Diqqəti

CSS selektorlar sağdan sola oxunur. div p yazdıqda brauzer əvvəl bütün p-ləri tapır, sonra div içindəmi deyə yoxlayır. Çox ümumi selektor (məs. * span) performansı aşağı sala bilər — mümkün qədər spesifik ol.

2. Uşaq Kombinator (Child) — >

Yalnız birbaşa uşaqları seçir — nəvələri, nəticələri seçmir. Nəsil kombinator ilə ən çox qarışdırılan operatordur.

style.css Child combinator > 
/* .menyu-nun BİRBAŞA uşağı olan li-ləri seç
   İç-içə alt menyu li-ləri seçilmir! */
.menyu > li {
  padding:     12px 16px;
  border-left: 3px solid #5b8af5;
}

/* HTML:
  <ul class="menyu">
    <li>Seçilir ✓</li>         ← birbaşa uşaq
    <li>Seçilir ✓</li>         ← birbaşa uşaq
      <ul>
        <li>SEÇİLMİR ✗</li>    ← nəvə, birbaşa uşaq deyil
      </ul>
  </ul>
*/

/* Praktik istifadə — yalnız birinci səviyyə başlıqlar */
.kart > h3 { font-size: 1.2rem; color: #fff; }
.kart > p  { color: #aaa; }
👶 Child > — yalnız birbaşa uşaqlar

Birbaşa uşaq p — SEÇİLİR (.child-demo > p) ✓

div içindəki p — SEÇİLMİR ✗

3. Bitişik Qardaş Kombinator (Adjacent Sibling) — +

Bir elementin dərhal ardınca gələn qardaş elementini seçir. Yalnız bir element seçilir — həm eyni valideyni olmalı, həm də dərhal bitişik.

style.css Adjacent Sibling + 
/* h2-nin dərhal ardınca gələn p-ni seç */
h2 + p {
  font-size:   1.1rem;
  color:       #3ecf8e;
  font-weight: 500;
}

/* HTML:
  <h2>Başlıq</h2>
  <p>Seçilir ✓ — dərhal ardınca gəlir</p>
  <p>SEÇİLMİR ✗ — bitişik deyil</p>
*/

/* Klassik istifadə: checkbox-un etiketi */
input[type="checkbox"] + label {
  cursor:      pointer;
  user-select: none;
}
input[type="checkbox"]:checked + label {
  color:           #3ecf8e;
  text-decoration: line-through;
}
➕ Adjacent Sibling — h4 + p

Bu h4-dür

Bu p dərhal h4 sonrasındadır — SEÇİLİR ✓ (yaşıl)

Bu p isə bitişik deyil — SEÇİLMİR ✗

4. Ümumi Qardaş Kombinator (General Sibling) — ~

Bir elementin eyni valideyni olan, sonrasında gələn bütün qardaş elementlərini seçir. Bitişik olmaq məcburiyyəti yoxdur.

style.css General Sibling ~ 
/* h2-dən sonra gələn bütün p-ləri seç */
h2 ~ p {
  color:       #b47df5;
  padding-left:12px;
}

/* HTML:
  <h2>Başlıq</h2>
  <p>Seçilir ✓</p>
  <div>Div — seçilmir</div>
  <p>Bu da seçilir ✓</p>
  <p>Bu da seçilir ✓</p>
*/

/* Praktik: checkbox toggle ilə bütün sibling elementləri gizlət/göstər */
#menyu-toggle:checked ~ .nav {
  display: block;
}
#menyu-toggle:not(:checked) ~ .nav {
  display: none;
}
〜 General Sibling — h4 ~ p

Bu h4-dür (başlanğıc nöqtəsi)

Birinci qardaş p — SEÇİLİR ✓

span elementi — seçilmir (p deyil)

İkinci qardaş p — SEÇİLİR ✓

Üçüncü qardaş p — SEÇİLİR ✓

4 Kombinator — Müqayisəli Cədvəl

OperatorAdNəyi seçirNümunə
(boşluq) Descendant (Nəsil) İçindəki bütün uyğun elementlər (istənilən dərinlikdə) div p
> Child (Birbaşa uşaq) Yalnız birinci səviyyə uşaqlar ul > li
+ Adjacent Sibling (Bitişik qardaş) Dərhal ardınca gələn bir qardaş h2 + p
~ General Sibling (Ümumi qardaş) Sonrasında gələn bütün qardaşlar h2 ~ p
✅ Real Layihə Nümunəsi — CSS-only menyu

Checkbox + ~ kombinatoru ilə JavaScript olmadan açılan/bağlanan menyu yaratmaq olar: input:checked ~ nav { display: block; } — bu klassik CSS-only toggle üsuludur.

🚫 Yoxdur: Valideyn Selektoru (köhnə CSS-də)

Uzun müddət CSS-də valideyn seçmək mümkün deyildi — yəni "içi şəkil olan div" kimi sorğu yazılmırdı. Bu problemi :has() selektoru həll etdi (növbəti bölmə).

🔍

:has() — Valideyn Selektoru

CSS-in ən güclü yeni selektoru — "içi X olan Y" sual forması

:has() — bir elementin içindəki elementlərə əsaslanaraq həmin elementi seçməyə imkan verir. Uzun illər CSS-də olmayan "valideyn selektoru" problemi artıq həll edilib. 2023-cü ildən bütün müasir brauzerlər dəstəkləyir.

💡 Brauzer Dəstəyi

Chrome 105+, Firefox 121+, Safari 15.4+. IE-də işləmir. Köhnə brauzerlər üçün JavaScript ilə fallback lazım ola bilər.

Əsas sintaksis

style.css :has() sintaksisi 
/* İçində img olan hər div-i seç */
div:has(img) {
  border:  2px solid #3ecf8e;
  padding: 0;         /* şəkil varsa padding lazım deyil */
}

/* İçində :checked input olan label */
label:has(input:checked) {
  color:       #3ecf8e;
  font-weight: 700;
}

/* İçindəki h2-nin mətni boşsa section-u gizlət */
section:has(h2:empty) {
  display: none;
}

/* Sonrakı qardaşını seçmək: A-nın ardınca B gəlirsə A-nı seç */
h2:has(+ p) {
  margin-bottom: 4px;   /* p varsa boşluğu azalt */
}
🔍 Canlı Nümunə — :has() ilə kart stilləri
Şəkilsiz kart

Normal stil

:has(img) — yaşıl sərhəd ✓

:has(input:checked) aktiv ✓

:has(input:checked) aktiv ✓

:has() ilə mürəkkəb nümunələr

style.css :has() — mürəkkəb nümunələr 
/* 1. İçi boş olmayan form sahəsi */
input:not(:placeholder-shown) {
  border-color: #3ecf8e;
}

/* 2. Xətalı input olan form */
form:has(input:invalid) .göndər-düymə {
  opacity: 0.5;
  cursor:  not-allowed;
  pointer-events: none;
}

/* 3. Ən azı 3 uşağı olan ul */
ul:has(li:nth-child(3)) {
  column-count: 2;    /* 3+ element varsa 2 sütun yap */
}

/* 4. Video olan section tam genişlikdə */
section:has(video) {
  max-width: 100%;
  padding:   0;
}

/* 5. :has() + :not() kombinasiyası */
.kart:has(img):not(:has(.başlıq)) {
  padding-top: 0; /* şəkli var amma başlığı yoxdur */
}
✅ :has() niyə inqilabçıdır?

Əvvəllər bunları etmək üçün JavaScript lazım idi — indi sırf CSS ilə mümkündür. form:has(input:invalid) kimi selektorlar form validasiyasını tamamilə CSS-ə köçürməyə imkan verir.

🚫 :has() içinə pseudo-element yazma

div:has(::before) işləmir — :has() yalnız real elementləri arqument kimi qəbul edir, pseudo elementlər deyil.

🚫

:not() — İstisna Selektoru

"Bundan başqa hamısını seç" — məntiqi dəfedici selektor

:not() — arqumentdə verilən selektora uyğun olmayan elementləri seçir. CSS3-də yalnız sadə selektor qəbul edirdi; CSS4 ilə mürəkkəb selektorlar da daxil edildi.

Əsas sintaksis

style.css :not() sintaksisi 
/* .aktiv class-ı olmayan bütün li-lər */
li:not(.aktiv) {
  opacity: 0.5;
}

/* Son elementdən başqa hamısına alt xətt */
li:not(:last-child) {
  border-bottom: 1px solid #2a3045;
}

/* p olmayan elementlər */
div > *:not(p) {
  margin-bottom: 8px;
}

/* disabled olmayan düymələr */
button:not(:disabled):hover {
  background: #5b8af5;
  color:       #fff;
}
🚫 Canlı Nümunə — li:not(.xüsusi)

.xüsusi class-ı olmayan elementlər solğun göstərilir

  • Adi element — :not(.xüsusi) seçilir (solğun)
  • Xüsusi element — class var, seçilmir ✓
  • Adi element — :not(.xüsusi) seçilir (solğun)
  • Xüsusi element — class var, seçilmir ✓
  • Adi element — :not(.xüsusi) seçilir (solğun)
🔘 Canlı Nümunə — button:not(:disabled):hover

CSS4 — Çoxlu arqument

Müasir CSS-də :not() içinə vergüllə ayrılmış bir neçə selektor yazmaq olar:

style.css :not() — çoxlu arqument (CSS4) 
/* ❌ CSS3 — yalnız bir selektor mümkün idi */
li:not(.aktiv):not(.seçili):not(:first-child) { ... }

/* ✅ CSS4 — çox daha oxunaqlı (Chrome 88+, Firefox 84+, Safari 9+) */
li:not(.aktiv, .seçili, :first-child) {
  opacity: 0.4;
}

/* Praktik: h1, h2, h3 olmayan bütün mətn elementləri */
:not(h1, h2, h3, h4, h5, h6) {
  max-width:  65ch;
  line-height:1.7;
}

:not() ilə kombinasiyalar

style.css :not() + digər selektorlar 
/* 1. :not() + :hover — disabled hoverı blokladı */
button:not(:disabled):hover {
  transform: translateY(-2px);
}

/* 2. :not() + :nth-child — son 2-dən başqa hamısı */
li:not(:nth-last-child(-n+2)) {
  border-bottom: 1px solid #2a3045;
}

/* 3. :not() + :has() — şəkilsiz kartlar */
.kart:not(:has(img)) {
  padding: 24px;
}

/* 4. :not() + attribute — href-i olmayan linklər */
a:not([href]) {
  color:  #666;
  cursor: default;
}

/* 5. Form validasiyası — boş olmayan, keçərli sahələr */
input:not(:placeholder-shown):not(:focus):valid {
  border-color: #3ecf8e;
  background:   rgba(62,207,142,.05);
}
⚠️ :not() Spesifiklik Davranışı

:not() arqumentinin özü spesifikliyə təsir edir. :not(.klass) = .klass qədər spesifik (0,1,0). :not(#id) = #id qədər spesifik (1,0,0) — ehtiyatla istifadə et!

🚫 :not() içinə pseudo-element yazma

p:not(::first-line) etibarsız yazılışdır. :not() yalnız selektorlar qəbul edir, pseudo elementlər (::) deyil.

:not() vs CSS Spesifikliyi — Qısa İzah

izah Spesifiklik hesabı 
/*
  Spesifiklik = (ID, Class, Element)

  p                  → (0, 0, 1)
  p:not(.x)         → (0, 1, 1)  ← .x-in spesifikliyini əlavə edir
  p:not(#id)        → (1, 0, 1)  ← #id-nin spesifikliyini əlavə edir
  p:not(:first-child)→ (0, 1, 1)  ← pseudo-class kimi sayılır

  ❗ Buna görə :not(#id) yazanda sonradan override etmək çətinləşir!
*/

Ümumi Xətalar & Buqlar

Tələbələrin ən çox düşdüyü tələlər

  • content xassəsi unudulub
    ::before / ::after elementlərini yazmaq, amma content: "" qoymamaq. Element görünməyəcək. 
    /* ❌ Yanlış — heç nə görünməyəcək */
.element::before {
  background: red;
  width: 10px;
}

/* ✅ Düzgün */
.element::before {
  content:    "";       /* mütləq! */
  display:    block;
  background: red;
  width:      10px;
  height:     10px;
}
  • outline:none yazıb alternativsiz qalmaq
    :focus stilini silmək əlçatanlığı pozur. Həmişə öz fokus stilini yaz. 
    /* ❌ Yanlış — klaviatura istifadəçiləri itirilir */
*:focus { outline: none; }

/* ✅ Düzgün — öz stilini qur */
*:focus-visible {
  outline:        none;
  box-shadow:     0 0 0 3px rgba(91,138,245,.5);
  border-radius:  4px;
}
  • nth-child ilə nth-of-type qarışdırmaq
    Mürəkkəb HTML strukturunda :nth-child(2) istənilən elementi seçməyə bilər. 
    /* HTML:
  <section>
    <h2>Başlıq</h2>    ← 1-ci uşaq
    <p>Mətn 1</p>       ← 2-ci uşaq
    <p>Mətn 2</p>       ← 3-cü uşaq
  </section>
*/

/* ❌ İkinci p-ni seçmək istəyirik, amma belə olur: */
p:nth-child(2)  /* ← birinci p-ni seçir (2-ci uşaq) */
p:nth-child(3)  /* ← ikinci p-ni seçir (3-cü uşaq) */

/* ✅ Düzgün yol — p-lər arasında say */
p:nth-of-type(2)  /* ← ikinci p — doğru! */
  • LVHA sırası pozulub
    Link stilləri yanlış sıralandıqda :visited və ya :hover işləmir. 
    /* ❌ Yanlış sıra — :hover işləməyə bilər */
a:hover   { color: green; }
a:link    { color: blue;  }
a:visited { color: purple;}
a:active  { color: red;   }

/* ✅ Düzgün: L → V → H → A  (LoVe HAte) */
a:link    { color: blue;   }
a:visited { color: purple; }
a:hover   { color: green;  }
a:active  { color: red;    }
  • :: əvəzinə : yazmaq (pseudo element)
    Köhnə sintaksis hələ işləsə də, standart ikiqat iki nöqtə ::-dir. 
    /* Köhnə sintaksis — hələ işləyir amma tövsiyə olunmur */
p:before       { content: "▶"; }
p:first-letter { font-size: 2em; }

/* ✅ Standart CSS3 sintaksisi */
p::before       { content: "▶"; }
p::first-letter { font-size: 2em; }
  • CSS dəyişən adı böyük-kiçik hərflərə həssasdır
    --Rəng ilə --rəng fərqli dəyişənlərdir! 
    /* ❌ Bu iki dəyişən FƏRQLIDIR */
:root {
  --Rəng: blue;
  --rəng: red;
}

.element { color: var(--Rəng); } /* blue */
.digər   { color: var(--rəng); } /* red */

/* ✅ Konvensiya: həmişə kiçik hərf + tire */
:root { --əsas-rəng: blue; }
  • CSS dəyişəni hesablamada birbaşa istifadə
    Rəqəm dəyişənlərini vahidlə birlikdə hesablamaq üçün calc() lazımdır. 
    /* ❌ Yanlış — işləmir */
:root { --cərçivə: 16; }
.element { padding: var(--cərçivə)px; } /* BU İŞLƏMİR! */

/* ✅ Düzgün seçim 1 — vahidi dəyişəndə saxla */
:root { --cərçivə: 16px; }
.element { padding: var(--cərçivə); }

/* ✅ Düzgün seçim 2 — calc() istifadə et */
:root { --bazis: 16; }
.element { padding: calc(var(--bazis) * 1px); }
  • :hover mobil cihazlarda etibarlı deyil
    Touch ekranlarda :hover "yapışır" — bir dəfə toxunanda aktivləşib qalır. 
    /* ✅ Yalnız hover cihazlarda :hover tətbiq et */
@media (hover: hover) {
  .kart:hover {
    transform: scale(1.03);
  }
}

/* Touch cihazlar üçün :active istifadə et */
.kart:active {
  transform: scale(0.97);
}
  • > ilə boşluq (space) qarışdırmaq
    ul > li yalnız birbaşa uşaqları seçir; ul li bütün nəsilləri seçir. Yanlış seçim içiçə menyuları da stilə alır. 
    /* ❌ Alt menyu li-lərinə də təsir edir */
.nav li { padding: 12px; }

/* ✅ Yalnız birinci səviyyə li-lər */
.nav > li { padding: 12px; }
.nav > li > ul > li { padding: 6px 12px; }
  • + ilə ~ qarışdırmaq
    h2 + p yalnız dərhal bitişik bir p-ni seçir; h2 ~ p isə sonrasındakı bütün p-ləri seçir. 
    /* Bunlar fərqlidir! */
h2 + p  /* ← yalnız h2-nin dərhal ardınca gələn p */
h2 ~ p  /* ← h2-dən sonra gələn bütün p-lər */
  • :has() köhnə brauzerdə işləmir
    IE, köhnə Chrome/Firefox versiyaları :has()-i dəstəkləmir. Kritik UI üçün JS fallback lazımdır. 
    /* ✅ @supports ilə dəstəyi yoxla */
@supports selector(:has(img)) {
  div:has(img) {
    border: 2px solid green;
  }
}

/* JS fallback */
if (!CSS.supports('selector(:has(img))')) {
  // köhnə brauzer — JS ilə ekvivalenti yap
}
  • :not() içinə pseudo-element yazmaq
    p:not(::first-line) etibarsız yazılışdır — :not() yalnız selektorlar qəbul edir. 
    /* ❌ Yanlış */
p:not(::first-line) { ... }   /* etibarsız */

/* ✅ :not() yalnız real selektor qəbul edir */
p:not(.xüsusi)        { ... }   /* düzgün */
p:not(:first-child)   { ... }   /* düzgün */
