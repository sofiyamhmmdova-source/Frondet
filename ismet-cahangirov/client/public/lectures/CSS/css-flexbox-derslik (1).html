// 01

Flexbox nədir?

Flexbox (Flexible Box Layout) — elementləri bir sırada və ya sütunda asanlıqla düzmək, aralarındaki boşluğu idarə etmək üçün CSS-ə əlavə edilmiş xüsusi bir düzülüş sistemidir.

Eskidən elementləri yan-yana düzmək üçün float və ya mürəkkəb position hiylələrindən istifadə edilirdi. Flexbox bunları çox sadələşdirdi.

🎯 Flexbox nə vaxt işlədilir?

Naviqasiya paneli, kart sıraları, forma elementləri, mərkəzləmə, eyni hündürlüklü sütunlar — bunların hamısı üçün Flexbox mükəmməldir.

💡

Qayda: Flexbox bir istiqamətdə (ya üfüqi, ya şaquli) işləyir. İki istiqamətdə işləmək üçün CSS Grid-dən istifadə edin.

// 02

Flex Container — Başlanğıc

Flexbox-u aktiv etmək üçün valideyn elementə display: flex yazırıq. Bu qayda yazıldıqdan sonra həmin elementin birbaşa uşaqları flex itemə çevrilir.

style.css 
/* Flex Container yaradırıq */
.konteyner {
  display: flex;  /* ← bu sehrli sözü yazmaq kifayətdir */
}

/* İndi .konteyner-in uşaqları flex item olur */
// display: flex — əvvəl və sonra

// 03

Əsas Ox və Çarpaz Ox

Flexbox-da hər şey iki ox ətrafında qurulur. Bu oxları anlamadan xassələri mənimsəmək çətin olur.

Əsas Ox (Main Axis)
Çarpaz Ox (Cross Axis)

🧭 Yadda saxla

Əsas ox — elementlərin düzüldüyü istiqamət (flex-direction ilə dəyişir).
Çarpaz ox — əsas oxa perpendikulyar olan istiqamət.
justify-content əsas ox boyunca, align-items isə çarpaz ox boyunca işləyir.

// 04

flex-direction

Elementlərin hansı istiqamətdə düzüləcəyini müəyyən edir. Defolt dəyər row-dur.

style.css 
.konteyner {
  display: flex;
  flex-direction: row;         /* → soldan sağa (defolt) */
  flex-direction: row-reverse;  /* ← sağdan sola */
  flex-direction: column;       /* ↓ yuxarıdan aşağı */
  flex-direction: column-reverse;/* ↑ aşağıdan yuxarı */
}

flex-wrap

Elementlər konteynerə sığmadıqda nə olacağını müəyyən edir. Defolt nowrap-dır — elementlər sığmasa da sıxışdırılır.

style.css 
.konteyner {
  flex-wrap: nowrap;        /* sığmayan sıxışdırılır (defolt) */
  flex-wrap: wrap;           /* sığmayan aşağı keçir */
  flex-wrap: wrap-reverse;   /* sığmayan yuxarı keçir */
}
// nowrap — elementlər sıxışdırılır (konteyner kiçildikcə görünər)

align-items

Elementləri çarpaz ox boyunca (adətən şaquli) hizalamaq üçün istifadə olunur. justify-content-in şaquli oxdakı qardaşı kimi düşünün.

style.css 
.konteyner {
  align-items: stretch;      /* konteyner boyuna uzanır (defolt) */
  align-items: flex-start;   /* yuxarıya hizalanır */
  align-items: flex-end;     /* aşağıya hizalanır */
  align-items: center;       /* şaquli mərkəzdə */
  align-items: baseline;     /* mətn bazal xəttinə görə */
}
// stretch — hər element konteyner hündürlüyünə uzanır

align-content

flex-wrap: wrap istifadə edildikdə bir neçə sıra əmələ gəlirsə, bu sıraların çarpaz ox boyunca necə paylaşılacağını müəyyən edir. Yalnız bir sıra varsa təsiri olmur.

.konteyner {

gap (row-gap, column-gap)

Flex itemlər arasındakı boşluğu idarə edir. Əvvəllər margin ilə həll olunan bu problem indi çox sadədir.

style.css 
.konteyner {
  gap: 16px;             /* hər tərəfdən 16px boşluq */
  gap: 16px 24px;        /* sıra boşluğu 16px, sütun boşluğu 24px */
  row-gap: 16px;         /* yalnız sıralar arası boşluq */
  column-gap: 24px;      /* yalnız sütunlar arası boşluq */
}

Flex Item Xassələri

Yuxarıdakı xassələr konteynerə (valideynə) yazılırdı. İndi isə ayrı-ayrı itemlərə (uşaqlara) yazılan xassələrə baxaq.

order

Elementin görünüş sırasını dəyişir. HTML sırası dəyişmədən vizual sıra dəyişir.

0 -1 1, 2, 3...
flex-grow

Boş yer varsa, elementin nə qədər böyüyəcəyini müəyyən edir. 0 — böyümür.

0 (defolt) 1 2
flex-shrink

Yer az olduqda elementin nə qədər kiçilə biləcəyini müəyyən edir.

1 (defolt) 0 (kiçilmə)
flex-basis

Elementin əsas ölçüsünü (böyümə/kiçilmədən əvvəl) müəyyən edir.

auto 200px 30%
align-self

Yalnız bu element üçün align-items-i ləğv edir.

auto flex-start center flex-end

flex-grow nümunəsi

style.css 
.item-a { flex-grow: 1; } /* boş yerin 1 pay alır */
.item-b { flex-grow: 2; } /* boş yerin 2 payı alır (ikiqat geniş) */
.item-c { flex-grow: 1; } /* boş yerin 1 payı alır */
// flex-grow: 1 | 2 | 1

flex shorthand (qısa yazılış)

flex-grow, flex-shrink və flex-basis-i bir xəttdə yazmaq üçün flex shorthand-ı istifadə edirik.

style.css 
/* flex: grow  shrink  basis */
.item { flex: 1 1 auto; }    /* böyü, kiçil, əsas ölçü avtomatik */

/* Ən çox istifadə olunan dəyərlər */
.item { flex: 1; }         /* flex: 1 1 0% — bərabər böyümə */
.item { flex: auto; }      /* flex: 1 1 auto */
.item { flex: none; }      /* flex: 0 0 auto — sabit ölçü */
.item { flex: 0 0 200px; } /* həmişə 200px, böyümür, kiçilmir */
// flex:1 — hər element bərabər yer alır

flex: 1
// flex: 1 | 2 | 1 — proporsional böyümə
flex: 1
flex: 2
flex: 1
// flex: none — element öz ölçüsündə qalır

🧠 Özünü Yoxla

Öyrəndiklərini test et! Cavabı seç, dərhal nəticəni gör.

1. Elementləri üfüqi olaraq bərabər boşluqla ayırmaq üçün hansı dəyəri istifadə edirik?

✅ Doğru! justify-content: space-between elementlər arasında bərabər boşluq yaradır, kənarlara boşluq qoymur.

2. Bir elementi həm üfüqi, həm şaquli mərkəzə yerləşdirmək üçün nə istifadə edirik?

✅ Doğru! Bu klassik "mükəmməl mərkəzləmə" həllidir — hər Flexbox istifadəçisinin əzbər bilməli olduğu bir patterndir.

3. flex-grow: 2 verilmiş element, flex-grow: 1 olan elementdən neçə dəfə daha geniş olur?

✅ Doğru! flex-grow dəyərlər nisbətini müəyyən edir. 2:1 nisbəti — boş yerin 2/3-ü birinci elementə, 1/3-ü ikinciyə gedir.

4. Konteyner xassəsi olmayan, yalnız müəyyən bir item üçün çarpaz ox hizasını dəyişdirən xassə hansıdır?

✅ Doğru! align-self yalnız o item üçün align-items-i ləğv edir. Qeyd: justify-self Flexbox-da işləmir, yalnız Grid-də işləyir.

5. Elementlər konteynerə sığmadıqda növbəti sıraya keçmələri üçün nə yazmalıyıq?

✅ Doğru! flex-wrap: wrap sığmayan elementlərin növbəti sıraya keçməsini təmin edir. Bu, responsiv dizayn üçün çox vacibdir.
