1

setTimeout nədir?

setTimeout() — müəyyən gecikmədən sonra bir dəfə funksiya çağıran brauzer (və Node.js) metodudur. Yəni "X millisaniyə gözlə, sonra bu işi gör" deməkdir.

⏱️
Vacib məlumat

1000 millisaniyə = 1 saniyə. setTimeout-a verilən delay dəyəri hər zaman millisaniyə ilə ifadə olunur.

Sintaksis belədir:

JavaScript — Sintaksis 
// Əsas sintaksis:
const timerId = setTimeout( callback, delay, arg1, arg2 );

// callback — çağırılacaq funksiya
// delay    — neçə millisaniyə sonra çağırılsın
// arg1,2   — callback-ə göndərilən əlavə arqumentlər (ixtiyari)

Parametrləri ayrıca izah edək:

  • 1
    callback — Gecikdikdən sonra çağırılacaq funksiyadır. Ad verilmiş funksiya da, arrow function da ola bilər.
  • 2
    delay — Millisaniyə ilə gözləmə müddəti. 0 versən belə, sıfır gecikmə demək dərhal demək deyil — izahı 8-ci bölmədə var.
  • 3
    timerId — setTimeout qaytardığı ədəddir. Bu ID ilə sonradan taymer ləğv edilə bilər.
2

setTimeout Nümunələri

Nümunə 1 — Sadə istifadə:

JavaScript 
setTimeout(function() {
  console.log("2 saniyə keçdi!");
}, 2000);

// Arrow function ilə daha qısa:
setTimeout(() => {
  console.log("3 saniyə keçdi!");
}, 3000);

Nümunə 2 — Funksiya ayrı yazılmış halda:

JavaScript 
function salamVer(ad) {
  console.log("Salam, " + ad + "!");
}

// Funksiya adını yazırıq — mötərizəsiz!
setTimeout(salamVer, 1000, "Əli");

// 1 saniyə sonra: "Salam, Əli!"
🚨
Klassik xəta

Funksiya adından sonra () qoymayın! setTimeout(salamVer(), 1000) — bu kod dərhal salamVer()-i çağırır, 1 saniyə gözləmir. Doğrusu: setTimeout(salamVer, 1000).

Nümunə 3 — setTimeout içində setTimeout (rekursiv):

JavaScript 
function sayac(n) {
  if (n === 0) {
    console.log("Hazır!");
    return;
  }
  console.log(n);
  setTimeout(() => sayac(n - 1), 1000); // özünü yenidən çağırır
}

sayac(5); // 5, 4, 3, 2, 1, "Hazır!" — hər saniyə bir ədəd
💡
Niyə rekursiv setTimeout?

Bu üsul setInterval-dan daha çevik sayılır — çünki növbəti çağırışı əvvəlki bitdikdən sonra başladır. Bu, çağırışlar arasında sabit boşluq saxlayır.

3

clearTimeout — Taymer Ləğv Etmək

clearTimeout(id) funksiyası hələ işə düşməmiş taymeri ləğv edir. Bunun üçün setTimeout-un qaytardığı ID lazımdır.

JavaScript 
const taymerID = setTimeout(() => {
  console.log("Bu görünməyəcək!");
}, 5000);

// İstəsək ləğv edirik:
clearTimeout(taymerID);
// Artıq 5 saniyə sonra heç nə olmayacaq

Praktik nümunə — istifadəçinin axtarışını gec göndərmək (debounce):

JavaScript — Debounce nümunəsi 
let gecikdirmeTaymeri;

document.getElementById("axtaris")
  .addEventListener("input", (e) => {

  // Əvvəlki taymer varsa ləğv et
  clearTimeout(gecikdirmeTaymeri);

  // Yeni taymer qur — 500ms sonra axtar
  gecikdirmeTaymeri = setTimeout(() => {
    serverdeAxtar(e.target.value);
  }, 500);
});

// İstifadəçi hər hərfə basanda taymer sıfırlanır
// Yalnız yazmağı dayandırdıqdan 500ms sonra sorğu göndərilir
ℹ️
Bu pattern "Debounce" adlanır

Axtarış qutuları, form validasiyaları, scroll hadisələrini azaltmaq üçün debounce çox istifadə olunur. Hər dəfə yeni hadisə gəldikdə əvvəlki taymer ləğv edilir.

4

setInterval nədir?

setInterval() — müəyyən müddət keçdikdən sonra funksiyaı dəfələrlə, dövri olaraq çağırır. clearInterval() çağırılana qədər dayanmır.

🔄
Xülasə

setTimeout → Bir dəfə çağırır.    setInterval → Dəfələrlə, hər X millisaniyədə çağırır.

JavaScript — Sintaksis 
const intervalId = setInterval( callback, delay );

// Hər 2 saniyədə bir çağırılır:
setInterval(() => {
  console.log("Hər 2 saniyədə bir!");
}, 2000);

Necə işlədiyini vizual olaraq görək:

setInterval başladı
t=0ms
1-ci çağırış
t=1000ms
2-ci çağırış
t=2000ms
clearInterval → dayanır
t=?ms
5

setInterval Nümunələri

Nümunə 1 — Sadə saat:

JavaScript 
function vaxtGoster() {
  const indi = new Date();
  const vaxt = indi.toLocaleTimeString("az-AZ");
  document.getElementById("saat").textContent = vaxt;
}

// Hər saniyə yeniləyir
setInterval(vaxtGoster, 1000);

Nümunə 2 — Geri sayım:

JavaScript 
let qalan = 10;

const id = setInterval(() => {
  console.log("Qalan: " + qalan);
  qalan--;

  if (qalan < 0) {
    clearInterval(id); // dayanır!
    console.log("Vaxt bitdi!");
  }
}, 1000);

Nümunə 3 — Animasiya (elementi hərəkətləndirmək):

JavaScript 
let movqe = 0;
const qutu = document.getElementById("qutu");

const animId = setInterval(() => {
  movqe += 2;                            // hər addım 2px
  qutu.style.left = movqe + "px";

  if (movqe >= 300) {
    clearInterval(animId);               // 300px-ə çatdı, dayanır
  }
}, 10);                                   // hər 10ms-dən bir

// Not: Animasiya üçün requestAnimationFrame daha yaxşıdır!
6

clearInterval — Interval Ləğv Etmək

clearInterval(id) — davam edən interval taymeri dayandırır. ID-ni mütləq saxlamalısınız, əks halda ləğv edə bilməzsiniz.

JavaScript 
const id = setInterval(() => {
  console.log("Çalışır...");
}, 1000);

// 5 saniyə sonra dayandır:
setTimeout(() => {
  clearInterval(id);
  console.log("Dayandırıldı!");
}, 5000);

// Nəticə: "Çalışır..." 4 dəfə çap olunur (1,2,3,4 saniyədə)
// 5-ci saniyədə clearInterval çağırılır
⚠️
Diqqət — Memory Leak

Komponent yüklənib-silinən SPA (React, Vue) proqramlarda interval dayandırılmasa, yaddaş sızıntısı (memory leak) yaranır. Komponent silinəndə clearInterval çağırın!

React nümunəsi (komponent təmizlənəndə interval dayandırılır):

React (JavaScript) 
useEffect(() => {
  const id = setInterval(() => {
    console.log("Çalışır");
  }, 1000);

  // Cleanup funksiyası — komponent silinəndə çalışır
  return () => clearInterval(id);
}, []);

setTimeout vs setInterval — Fərqlər

Xüsusiyyət setTimeout setInterval
Neçə dəfə? Yalnız 1 dəfə Davamlı, dövri
Ləğv etmək clearTimeout(id) clearInterval(id)
İstifadə yeri Gecikmə, əməliyyatdan sonra Saat, animasiya, polling
Dəqiqlik Nisbi (Event Loop) Nisbi (Event Loop)
Rekursiv istifadə Bəli — çevik interval üçün Gərəksiz
Minimum delay ~4ms (brauzer) ~4ms (brauzer)
🔑
Nə vaxt hansını seç?

Əgər işi bir dəfə gecikdirmək istəyirsinizsə → setTimeout. Əgər işi dövri olaraq təkrar etmək istəyirsinizsə → setInterval. Dinamik gecikmə lazımdırsa → rekursiv setTimeout.

8

Event Loop — Taymer əslində necə işləyir?

JavaScript tək iş parçacıqlı (single-threaded) dildir. Bu o deməkdir ki, eyni anda yalnız bir iş görülür. Bəs taymer necə işləyir?

  • 1
    Siz setTimeout(fn, 2000) yazırsınız. JavaScript bunu brauzerə (Web API-yə) tapşırır.
  • 2
    Brauzer geri sayım başladır. Bu vaxt əsnasında JS kodu işləməyə davam edir — taymer blok etmir.
  • 3
    2000ms keçdikdə brauzer fn funksiyasını Callback Queue-yə əlavə edir.
  • 4
    Event Loop daim yoxlayır: "Call Stack boşdurmu?" — boşdursa, Queue-dən funksiyaı götürüb çalışdırır.
⏳
setTimeout(fn, 0) — dərhal deyil!

setTimeout(fn, 0) yazsanız belə, fn dərhal çalışmaz. Əvvəlcə hazırkı kod bitir, sonra fn növbəyə gəlir. Bu, "mövcud stack-dan sonra çalış" demək üçün istifadə olunur.

JavaScript — Sıra nümunəsi 
console.log("A");             // 1-ci çap olunur

setTimeout(() => {
  console.log("B");           // 3-cü çap olunur
}, 0);

console.log("C");             // 2-ci çap olunur

// Çıxış: A → C → B
// "0ms" olsa da, B ən sonda çap olunur!

Tez-tez Edilən Xətalar (Bugs)

🐛 Xəta #1 — Funksiyaya mötərizə əlavə etmək
YANLIŞ 
setTimeout(salamVer(), 1000); // ❌ Dərhal çağırır!
✅ Düzgün
DOĞRU 
setTimeout(salamVer, 1000); // ✅ Referans verilir
// Yaxud:
setTimeout(() => salamVer(), 1000); // ✅ Wrapper ilə
🐛 Xəta #2 — ID-ni saxlamamaq
YANLIŞ 
setInterval(() => {
  console.log("Dayanmaq bilmirəm!");
}, 1000); // ❌ ID saxlanmadı — ləğv etmək mümkün deyil
✅ Düzgün
DOĞRU 
const id = setInterval(() => {
  console.log("Lazım olduqda dayanaram");
}, 1000);

clearInterval(id); // ✅ Ləğv edə bilirik
🐛 Xəta #3 — Intervali dəfələrlə başlatmaq
YANLIŞ 
// Hər dəfə düyməyə basanda yeni interval açılır!
button.addEventListener("click", () => {
  setInterval(() => vaxtGoster(), 1000); // ❌ İki dəfə bassan, iki interval
});
✅ Düzgün
DOĞRU 
let intervalId = null;

button.addEventListener("click", () => {
  if (intervalId) return; // artıq çalışırsa, yeni açma
  intervalId = setInterval(() => vaxtGoster(), 1000);
});
🐛 Xəta #4 — setTimeout daxilindəki "this" problemi
YANLIŞ 
const obyekt = {
  ad: "Əli",
  salam() {
    setTimeout(function() {
      console.log(this.ad); // ❌ undefined! "this" obyekt deyil
    }, 1000);
  }
};
✅ Düzgün — Arrow function istifadə et
DOĞRU 
const obyekt = {
  ad: "Əli",
  salam() {
    setTimeout(() => {        // ✅ Arrow func "this"-i miras alır
      console.log(this.ad); // "Əli" — düzgün!
    }, 1000);
  }
};
🐛 Xəta #5 — Dəqiq vaxtı zəmanət etmək

Taymer dəqiq 1000ms-dən sonra çalışmağı zəmanət vermir! Event Loop-da əvvəlki iş bitməsə, gecikə bilər.

Nümunə 
setTimeout(() => {
  console.log("1 saniyə sonra?");
}, 1000);

// Əgər bu iş blok edərsə:
for (let i = 0; i < 1e9; i++) {} // uzun iş!
// Taymer 1 saniyədən GEC çalışacaq — çünki stack boşalmayıb
⚠️
Minimum Gecikdirmə Qaydası

Brauzerlər (HTML5 standartına görə) 4ms-dən az gecikmələri avtomatik 4ms-ə yuvarlaqlaşdırır. setTimeout(fn, 0) yazanda belə, ən az ~1-4ms gözlənilir.

11

Xülasə və Tövsiyələr

⏱

setTimeout

Müəyyən vaxtdan sonra yalnız bir dəfə iş gör. Debounce, gecikmə, xəbərdarlıqlar üçün idealdır.

🔄

setInterval

Hər X millisaniyədə bir işi təkrar et. Saatlar, polling, animasiyalar üçün istifadə et.

🗑

Həmişə ləğv et

İstifadə edilmədikdə clearTimeout / clearInterval çağır. Memory leak-dən qaçın.

🧠

Event Loop-u unutma

Taymer dəqiq deyil — Stack boş olmasa gecikir. setTimeout(fn,0) dərhal deyil!

🚀
Növbəti addımlar

setTimeout/setInterval-ı öyrəndikdən sonra: Promise, async/await, requestAnimationFrame və Web Workers mövzularını araşdırın. Bunlar asinxron JS-in daha güclü alətləridir.

JavaScript — Qızıl qaydalar 
// ✅ 1. ID-ni həmişə saxla
const id = setTimeout(...);
const ivId = setInterval(...);

// ✅ 2. Referans ver, çağırma
setTimeout(fn, 1000);      // doğru
setTimeout(fn(), 1000);    // ❌ yanlış

// ✅ 3. Arrow function istifadə et (this problemi yoxdur)
setTimeout(() => fn(), 1000);

// ✅ 4. Lazım olmadıqda ləğv et
clearInterval(ivId);
clearTimeout(id);
