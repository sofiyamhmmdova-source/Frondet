Math Obyektinə Giriş

Riyazi sabitlər və funksiyalar toplusu

Math obyekti JavaScript-ə daxil olan, riyazi əməliyyatları yerinə yetirmək üçün istifadə olunan statik obyektdir. Onu new Math() şəklində yaratmırsınız — birbaşa istifadə edirsiniz.

JavaScript 
// Math.PI sabitinə nümunə
console.log(Math.PI);   // → 3.141592653589793
console.log(Math.E);    // → 2.718281828459045
💡

Əsas qayda: Math metodları həmişə böyük M ilə yazılır: Math.round(), Math.floor() — heç vaxt math.round() deyil!

Math.round()

Yuvarlaqlaşdırma

Ən yaxın tam ədədə yuvarlaqlaşdırır

Math.round(x) — 0.5 və ya daha böyük olduqda yuxarı, əksi halda aşağı yuvarlaqlaşdırır.

JavaScript 
Math.round(4.3);  // → 4   (0.3 < 0.5 → aşağı)
Math.round(4.5);  // → 5   (0.5 ≥ 0.5 → yuxarı)
Math.round(4.7);  // → 5   (0.7 ≥ 0.5 → yuxarı)
Math.round(-4.5); // → -4  (mənfi ədədlər fərqlidir!)

floor / ceil / trunc

Tam Ədədə Çevirməyin 3 Üsulu

Hər birinin fərqli məntiqi var

1

Math.floor() — Döşəmə (aşağı)

Həmişə aşağıya doğru yuvarlaqlaşdırır, heç vaxt qiymətini artırmır.

2

Math.ceil() — Tavan (yuxarı)

Həmişə yuxarıya doğru yuvarlaqlaşdırır, heç vaxt qiymətini azaltmır.

3

Math.trunc() — Kəsik (sıfıra)

Kəsr hissəni sadəcə atar, müsbət və ya mənfi olmasından asılı olmayaraq.

JavaScript – müqayisəli nümunə 
let x = 4.7;
Math.floor(x);   // → 4  (aşağı)
Math.ceil(x);    // → 5  (yuxarı)
Math.trunc(x);   // → 4  (kəsr atıldı)
Math.round(x);   // → 5  (0.7 ≥ 0.5, yuxarı)

// Mənfi ədədlər üçün fərq daha aydındır:
let y = -4.7;
Math.floor(y);   // → -5  (aşağı → daha kiçik)
Math.ceil(y);    // → -4  (yuxarı → sıfıra yaxın)
Math.trunc(y);   // → -4  (kəsr atıldı → sıfıra)

Math.abs()

Mütləq Qiymət

Ədədin işarəsini silir, həmişə müsbət qaytarır

Math.abs(x) — x-in mütləq qiymətini qaytarır. Məsafə hesablamalarında, yaxud iki qiymət arasındakı fərqi müsbət göstərmək üçün çox istifadə olunur.

JavaScript 
Math.abs(-7);    // → 7
Math.abs(7);     // → 7
Math.abs(-3.14); // → 3.14

// Praktiki nümunə: iki temperatur arasındakı fərq
let sabah   = 12;
let bugun  = 18;
let ferq    = Math.abs(sabah - bugun);
console.log("Temperatur fərqi: " + ferq + "°C"); // → 6°C
Math.min() / Math.max()

Ən Kiçik və Ən Böyük

Bir neçə ədəd arasından seçim edir

Math.min() ən kiçik, Math.max() ən böyük ədədi qaytarır. Neçə arqument versəniz, hamısı arasında axtarır.

JavaScript 
Math.min(3, 7, 1, 9, 5);  // → 1
Math.max(3, 7, 1, 9, 5);  // → 9

// Array ilə istifadə (spread operatoru):
let qiymetler = [45, 12, 78, 33, 99];
Math.min(...qiymetler);        // → 12
Math.max(...qiymetler);        // → 99

// Praktiki: istifadəçi girişini 1-100 arasında saxla
let giris = 150;
let saxla = Math.min(Math.max(giris, 1), 100);
console.log(saxla); // → 100  (150 > 100 olduğu üçün)

Math.sqrt() / Math.pow()

Kök və Dərəcə

Kvadrat kök və ədədi dərəcəyə yüksəltmə

JavaScript 
// Math.sqrt(x) → x-in kvadrat kökü
Math.sqrt(9);        // → 3
Math.sqrt(2);        // → 1.4142135623730951
Math.sqrt(25);       // → 5

// Math.pow(x, n) → x-i n-ci dərəcəyə qaldır
Math.pow(2, 10);    // → 1024
Math.pow(3, 3);     // → 27

// Müasir alternativ: ** operatoru
2 ** 10;              // → 1024  (eyni nəticə)
Math.random()

Təsadüfi Ədəd — Ən Çox İstifadə Olunan

0 (daxil) ilə 1 (istisna) arasında float qaytarır

Math.random() hər çağırıldığında [0, 1) aralığında fərqli onluq ədəd qaytarır. Lakin tək başına istifadəsi nadir hallarda kifayət edir — adətən Math.floor() ilə birləşdirilir.

Math.random() nəticəsi (hər dəfə dəyişir):

—

Praktiki Düstur: N ilə M arasında tam ədəd:

JavaScript – universal düstur 
// [min, max] arasında tam ədəd (hər iki son daxil)
function randomAraliq(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

// Misal istifadələr:
randomAraliq(1,  6);   // → zər atışı: 1, 2, 3, 4, 5 və ya 6
randomAraliq(1,  100); // → 1-100 arası
randomAraliq(0,  1);   // → ya 0, ya 1 (sikkə atışı)

// Massivdən təsadüfi element:
let renglar = ["qırmızı", "yaşıl", "mavi"];
let secim   = renglar[randomAraliq(0, renglar.length - 1)];

let indi = new Date();

GET Metodları

Tarix Komponentlərini Almaq

getFullYear, getMonth, getDate, getDay, getHours...

JavaScript – GET metodları 
let tarix = new Date(2026, 5, 18, 14, 45, 30);
// ay=5 → İYUN (0=yanvar, 5=iyun)

// ── İl ──────────────────────────────────
tarix.getFullYear();   // → 2026

// ── Ay (0-dan 11-ə qədər!) ──────────────
tarix.getMonth();      // → 5  (İyun = 5)
// Real ay almaq üçün +1 əlavə et:
tarix.getMonth() + 1; // → 6  ← İstifadəçiyə göstəriləcək!

// ── Ayın günü (1-dən 31-ə) ──────────────
tarix.getDate();       // → 18

// ── Həftənin günü (0=Bazar, 6=Şənbə) ──
tarix.getDay();        // → 4 (Cümə axşamı)

// ── Saat, dəqiqə, saniyə ────────────────
tarix.getHours();     // → 14
tarix.getMinutes();   // → 45
tarix.getSeconds();   // → 30

// ── Timestamp (1970-dən bəri ms) ────────
tarix.getTime();      // → böyük ədəd (ms)

SET Metodları

Tarixi Dəyişdirmək

setFullYear, setMonth, setDate, setHours...

Set metodları mövcud Date obyektini yerindəcə dəyişdirir (mutates). Hər biri uyğun get metodunun əksidir.

JavaScript – SET metodları 
let d = new Date();   // cari tarix

// İli dəyişdir
d.setFullYear(2030);

// Ayı dəyişdir (0=Yanvar, 11=Dekabr)
d.setMonth(0);        // → Yanvar

// Ayın gününü dəyişdir
d.setDate(1);         // → Ayın 1-i

// Saatı dəyişdir
d.setHours(9, 0, 0); // 09:00:00

console.log(d);
// → Thu Jan 01 2030 09:00:00

// ── Praktiki: sabahın tarixi ────────────
let sabah = new Date();
sabah.setDate(sabah.getDate() + 1);
// → yeni Date obyekti yaratmadan tarix irəlilədi

// ── Praktiki: 30 gün sonra ──────────────
let gec = new Date();
gec.setDate(gec.getDate() + 30);
// → ay keçsə belə, düzgün hesablanır

Tarix Formatlama — Real Layihə Nümunəsi

Tarixin DD/MM/YYYY formatında göstərilməsi

JavaScript – tarix formatı funksiyası 
function formatTarix(tarix) {
  let gun  = String(tarix.getDate()).padStart(2, '0');
  let ay   = String(tarix.getMonth() + 1).padStart(2, '0');
  //                          ↑ +1 unutma!
  let il   = tarix.getFullYear();
  return `${gun}/${ay}/${il}`;
}

// İstifadəsi:
let bu_gun = new Date();
console.log(formatTarix(bu_gun));
// → "18/06/2026"

// Azərbaycan formatı ilə ay adları:
const AYLAR = [
  "Yanvar", "Fevral", "Mart",    "Aprel",
  "May",    "İyun",   "İyul",    "Avqust",
  "Sentyabr", "Oktyabr", "Noyabr", "Dekabr"
];

function azFormat(tarix) {
  let g = tarix.getDate();
  let a = AYLAR[tarix.getMonth()];
  let i = tarix.getFullYear();
  return `${g} ${a} ${i}`;
}
console.log(azFormat(bu_gun));
// → "18 İyun 2026"

Kritik Xətalar

Tələbələrin ən çox etdiyi səhvlər və onların həlli

🐛 Xəta #1 — Math-ı kiçik hərflə yazmaq

JavaScript-də Math obyektinin adı həmişə böyük M ilə başlamalıdır. Kiçik math yazılsa, "math is not defined" xətası alınır.

❌ Yanlış
// ReferenceError!
math.round(4.5);
MATH.floor(3.9);
Math.Round(4.5);
// TypeError!
✅ Düzgün
// Həmişə böyük M!
Math.round(4.5);
Math.floor(3.9);
Math.ceil(2.1);
🐛 Xəta #2 — "new" olmadan Date çağırmaq

Date() şəklində (new olmadan) çağırılsa, nəticə String qaytarır — Date obyekti deyil! .getFullYear() kimi metodları çağıra bilməzsiniz.

❌ Yanlış
// Date() → String qaytarır!
let d = Date();
console.log(typeof d);
// → "string"
d.getFullYear();
// TypeError: not a function!
✅ Düzgün
// new Date() → Object!
let d = new Date();
console.log(typeof d);
// → "object"
d.getFullYear();
// → 2026 ✓
🐛 Xəta #3 — getMonth() nəticəsini real ay ilə qarışdırmaq

getMonth() 0-dan 11-ə qədər qaytarır. İyun ayı üçün 5 qaytarır, 6 deyil! İstifadəçiyə göstərərkən +1 əlavə etmək şərtdir.

❌ Yanlış
let d = new Date();
// Birbaşa göstərmək:
console.log(
  "Ay: " + d.getMonth()
);
// → "Ay: 5"  ← Yanvar→0 sistemi!
// İyun üçün 5 göstərir → yanlış!
✅ Düzgün
let d = new Date();
// +1 əlavə etmək:
console.log(
  "Ay: " + (d.getMonth() + 1)
);
// → "Ay: 6"  ← İyun üçün doğru!
🐛 Xəta #4 — getYear() yerinə getFullYear() istifadə etmək

getYear() köhnə metoddur və 1900 çıxılmış ildən etibarən qaytarır (2026 → 126 qaytarır). Həmişə getFullYear() istifadə edin!

❌ Yanlış (köhnə)
let d = new Date();
d.getYear();
// → 126  (2026 - 1900)
// İstifadəçiyə 126 göstərir — çox yanlış!
✅ Düzgün
let d = new Date();
d.getFullYear();
// → 2026  (tam il)
🐛 Xəta #5 — Math.random() ilə tam ədəd almaq

Math.random() heç vaxt tam ədəd (int) qaytarmır — həmişə 0 ilə 1 arasında onluq ədəd qaytarır. Tam ədəd lazımdırsa, Math.floor() ilə birləşdirin.

❌ Yanlış
// 1-6 arası tam ədəd istəyir...
let zer = Math.random() * 6;
console.log(zer);
// → 3.7291...  tam ədəd deyil!
✅ Düzgün
// floor + düstur:
let zer = Math.floor(
  Math.random() * 6
) + 1;
console.log(zer);
// → 1, 2, 3, 4, 5 və ya 6 ✓
✅ Ümumi Məsləhətlər

1. Math metodlarını yazmadan əvvəl həmişə böyük M ilə başladığınızı yoxlayın.

2. Date yaratarkən new sözünü unutmayın — linteriniz xəbərdarlıq vermirsə, typeof ilə yoxlayın: typeof d === 'object' olmalıdır.

3. getMonth() nəticəsini göstərərkən mütləq +1 əlavə edin. Bu xətanı önləmək üçün AYLAR[d.getMonth()] kimi ay adları massivindən istifadə etmək daha yaxşı yanaşmadır.

4. Math.random() ilə tam ədəd üçün həmişə Math.floor(Math.random() * (max - min + 1)) + min düsturunu yadda saxlayın.

💡 Yadda saxla: getDay() vs getDate()

getDate() — ayın gününü qaytarır (1–31).

getDay() — həftənin gününü qaytarır (0=Bazar, 1=Bazar ertəsi, ... 6=Şənbə).

Bu iki metodu çox tez-tez qarışdırırlar!
