reduce() ilə meyvə sayma

Massiv üzərində dövr edilir. Hər meyvə obyektdə açar kimi saxlanılır, say artırılır. obj[m] || 0 — əgər açar yoxdursa 0-dan başlayır.

let meyvələr = ["alma", "armud", "alma", "üzüm", "alma"]; let say = meyvələr.reduce((obj, m) => { obj[m] = (obj[m] || 0) + 1; return obj; }, {});

sort((a, b) => a − b) — Artan sıralama

Müqayisə funksiyası a − b qaytarır. Mənfi → a öndə, Müsbət → b öndə, 0 → dəyişməz. Hər keçiddə ən böyük element sona "qabarcıq kimi" çıxır.

let rəqəmlər = [10, 2, 100, 21]; rəqəmlər.sort((a, b) => a - b); // Nəticə: [2, 10, 21, 100] ✅

sort((a, b) => b − a) — Azalan sıralama

Müqayisə funksiyası b − a qaytarır — artan sıralamadan fərqli olaraq a ilə b-nin yeri dəyişdirilib. Nəticədə ən böyük element əvvəldə olur.

rəqəmlər.sort((a, b) => b - a); // Nəticə: [100, 21, 10, 2]
