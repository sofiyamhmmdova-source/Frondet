🖥️ Window Obyekti

Window — brauzerdəki bütün JavaScript kodunun işlədiyi qlobal mühitdir. Brauzer pəncərəsini təmsil edir. Kodunuzdakı hər bir qlobal dəyişən avtomatik olaraq window obyektinin xüsusiyyətinə çevrilir.

💡 Vacib məlumat
window yazmasanız da, brauzer onu avtomatik anlar. Yəni alert("Salam") ilə window.alert("Salam") eynidir.
javascript
// Bunlar eyni şeydir:
alert("Salam");
window.alert("Salam");

// Qlobal dəyişən = window xüsusiyyəti
var ad = "Əli";
console.log(window.ad); // "Əli"

// let/const isə window-a əlavə olunmur!
let soyad = "Həsənov";
console.log(window.soyad); // undefined
⚠️ Fərq: var vs let/const
var ilə elan edilən dəyişənlər window-a əlavə olunur. Lakin let və const ilə elan edilənlər əlavə olunmur. Bu, ən çox çaşdıran məqamlardan biridir!

⚠️ Window — Xətalar & Buqlar

🐛 Bug 1 — Qlobal çirkləndirmə (Global Pollution)
var ilə yazılan dəyişənlər window-a əlavə olunur və başqa kodlarla toqquşa bilər. Həmişə let/const istifadə edin.
❌ Yanlış
var name = "Əli";
// window.name-i əvəz edir!
// window.name artıq brauzer üçün
// xüsusi məna daşıyır
✅ Doğru
let istifadeciAdi = "Əli";
// Unikal ad seçin
// let/const istifadə edin
🐛 Bug 2 — setInterval dayandırılmır (Memory Leak)
setInterval-ı dayandırmasanız, yaddaş sızıntısı (memory leak) baş verir. Həmişə ID-ni saxlayın.
❌ Yanlış
setInterval(() => {
  console.log("işləyir")
}, 1000);
// ID yoxdur, dayandırmaq
// mümkün deyil! ← BUG
✅ Doğru
const id = setInterval(() => {
  console.log("işləyir")
}, 1000);
// Lazım olduqda:
clearInterval(id); // ✓
🐛 Bug 3 — localStorage-da tip itkisi
localStorage yalnız string saxlayır. Rəqəm yazsanız, geri oxuyanda string kimi gəlir.
❌ Yanlış
localStorage.setItem("yas", 25);
const yas = localStorage.getItem("yas");
yas + 5; // "255" ← String!!
✅ Doğru
localStorage.setItem("yas", 25);
const yas = Number(
  localStorage.getItem("yas"));
yas + 5; // 30 ✓

📦 Destructuring (Parçalama)

Destructuring massivlərdən və ya obyektlərdən dəyərləri çıxarıb dəyişənlərə mənimsətməyin qısa yoludur. ES6 ilə gəldi.

💡 Niyə lazımdır?
Əvvəllər massivdən hər elementi ayrıca yazmaq lazım idi. Destructuring ilə bunu bir sətrdə etmək olur.

📋 Massiv Destructuring

javascript
// Əvvəlki üsul
const meyveler = ["alma", "armud", "gilas"];
const birinci = meyveler[0]; // köhnə üsul
const ikinci  = meyveler[1]; // köhnə üsul

// Destructuring ilə (ES6)
const [birinci, ikinci, ucuncu] = meyveler;
console.log(birinci); // "alma"
console.log(ikinci);  // "armud"
console.log(ucuncu); // "gilas"

// Element atlamaq — vergül istifadə edin
const [a, , c] = [1, 2, 3];
console.log(a); // 1
console.log(c); // 3 (2-ci atlandı)

// Dəyişənləri yer dəyişmək (SWAP)
let x = 10, y = 20;
[x, y] = [y, x]; // Əla trick!
console.log(x); // 20
console.log(y); // 10

🔧 Standart Dəyərlər (Default Values)

Əgər xüsusiyyət mövcud deyilsə və ya undefined-dirsə, standart dəyər istifadə olunur.

javascript
// Massivdə standart dəyər
const [a = 10, b = 20] = [5];
console.log(a); // 5   (massivdən gəldi)
console.log(b); // 20  (standart dəyər işləndi)

// Obyektdə standart dəyər
const istifadeci = { ad: "Kamran" };
const {
  ad,
  yas = 18,       // mövcud deyil → 18 istifadə olunur
  rol = "tələbə"   // mövcud deyil → "tələbə" istifadə olunur
} = istifadeci;
console.log(ad);  // "Kamran"
console.log(yas); // 18
console.log(rol); // "tələbə"

// Adlandırma + standart dəyər birlikdə
const { ad: tam_ad = "Naməlum" } = {};
console.log(tam_ad); // "Naməlum"
⚠️ Diqqət: null vs undefined
Standart dəyər yalnız undefined olduqda işlənir. null olduqda işlənmir!
javascript
const { a = 5 } = { a: undefined };
console.log(a); // 5  ← standart işləndi (undefined)

const { b = 5 } = { b: null };
console.log(b); // null ← standart işlənmədi! (null dəyərdir)

🔄 Funksiyalarda Destructuring

javascript
// Parametr kimi obyekt destructuring
function salamVer({ ad, yas = 0, sehir = "Bakı" }) {
  console.log(`Salam, ${ad}! Yaşın: ${yas}, Şəhər: ${sehir}`);
}

salamVer({ ad: "Leyla", yas: 23 });
// "Salam, Leyla! Yaşın: 23, Şəhər: Bakı"

// Funksiyadan massiv qaytarmaq + destructuring
function getMinMax(arr) {
  return [Math.min(...arr), Math.max(...arr)];
}

const [min, max] = getMinMax([3, 1, 9, 5, 2]);
console.log(min); // 1
console.log(max); // 9

// for...of ilə destructuring
const telebeler = [
  { ad: "Anar", bal: 88 },
  { ad: "Günel", bal: 95 },
];
for (const { ad, bal } of telebeler) {
  console.log(`${ad}: ${bal} bal`);
}

⚠️ Destructuring — Xətalar & Buqlar

🐛 Bug 1 — null/undefined-dan destructuring
null və ya undefined dəyərindən destructuring etmək TypeError verir!
❌ Xəta — TypeError
const data = null;
const { ad } = data;
// TypeError: Cannot destructure
// property 'ad' of null
✅ Müdafiəli yazı
const data = null;
const { ad } = data || {};
// "" — null olarsa boş
// obyekt istifadə olunur
🐛 Bug 2 — Obyekt destructuringdə mötərizə xətası
Artıq elan edilmiş dəyişənlərə obyekt destructuring etdikdə {} ifadəsi blok kimi oxunur.
❌ SyntaxError
let ad, yas;
{ ad, yas } = { ad: "Əli", yas: 25 };
// SyntaxError! {} blok sayılır
✅ Mötərizə əlavə et
let ad, yas;
({ ad, yas } = { ad: "Əli", yas: 25 });
// () içinə aldıqda işləyir ✓
🐛 Bug 3 — Mövcud olmayan açar
Olmayan açarı destructuring etsəniz undefined alırsınız, xəta yox. Bu gizli buqlara səbəb ola bilər.
javascript
const { ad, telefon } = { ad: "Murad" };
console.log(ad);      // "Murad"
console.log(telefon); // undefined ← Xəta yox, amma diqqətli olun!

// Həll: standart dəyər istifadə edin
const { telefon: tel = "Naməlum" } = { ad: "Murad" };
console.log(tel); // "Naməlum"

✨ Spread & Rest Operatoru (...)

Hər ikisi eyni simvoldan (...) istifadə edir, lakin fərqli yerlərdə fərqli işlər görür:

OperatorHaradaNə edir
Spread ...Funksiyanı çağırmaqda, massiv/obyekt literalındaMassiv/obyekti açır, yayır
Rest ...Funksiya parametrindəm destructuringdəQalan elementləri massivə toplayır

🔀 Spread — Massivlərdə

javascript
// Massivləri birləşdirmək
const sebzeler = ["pomidor", "xiyar"];
const meyveler = ["alma", "armud"];

const qida = [...sebzeler, ...meyveler];
console.log(qida);
// ["pomidor", "xiyar", "alma", "armud"]

// Massivi kopyalamaq (dayaz nüsxə)
const original = [1, 2, 3];
const kopya = [...original];
kopya.push(4);
console.log(original); // [1, 2, 3]  ← dəyişmədi
console.log(kopya);    // [1, 2, 3, 4]

// Funksiyaya argument kimi
const reqemler = [8, 3, 5, 1, 9, 2];
console.log(Math.max(...reqemler)); // 9
console.log(Math.min(...reqemler)); // 1

// String-dən massiv yaratmaq
const herfler = [..."Salam"];
console.log(herfler); // ["S","a","l","a","m"]

📋 Rest Parametrləri

Funksiyaya göndərilən qalan bütün arqumentləri bir massivə toplayır. Həm funksiya parametrlərində, həm destructuringdə istifadə olunur.

javascript
// Funksiyada rest parametri
function topla(...reqemler) {
  // reqemler bir massivdir
  return reqemler.reduce((cem, n) => cem + n, 0);
}

console.log(topla(1, 2, 3));          // 6
console.log(topla(10, 20, 30, 40)); // 100
console.log(topla(5));               // 5

// İlk parametr sabit, qalanlar rest
function mesaj(basliq, ...detallar) {
  console.log("Başlıq:", basliq);
  console.log("Detallar:", detallar);
}

mesaj("Xəbər", "Bakıda", "yağış", "yağdı");
// Başlıq: Xəbər
// Detallar: ["Bakıda", "yağış", "yağdı"]

// Destructuringdə rest
const [birinci, ikinci, ...qalanlar] = [10, 20, 30, 40, 50];
console.log(birinci);  // 10
console.log(ikinci);   // 20
console.log(qalanlar); // [30, 40, 50]

// Obyekt destructuringdə rest
const { ad, yas, ...qalan } = { ad: "Sevinc", yas: 24, sehir: "Gəncə", hobbi: "Musiqi" };
console.log(ad);     // "Sevinc"
console.log(yas);    // 24
console.log(qalan); // { sehir: "Gəncə", hobbi: "Musiqi" }

⚠️ Spread & Rest — Xətalar & Buqlar

🐛 Bug 1 — Rest ən sonda olmalıdır
Rest parametri həmişə son parametr olmalıdır, yoxsa SyntaxError verir.
❌ SyntaxError
function test(...a, b) {}
// SyntaxError: Rest parameter
// must be last formal parameter

const [...a, b] = [1, 2, 3];
// SyntaxError!
✅ Doğru
function test(b, ...a) {}
// ✓ b sabit, a rest

const [b, ...a] = [1, 2, 3];
// ✓ b=1, a=[2,3]
🐛 Bug 2 — Dayaz kopyalama (Shallow Copy) tələsi
Spread yalnız dayaz (shallow) nüsxə yaradır. İç-içə obyektlər hələ eyni referansı paylaşır!
❌ Gizli Bug
const a = { x: { y: 1 } };
const b = { ...a };
b.x.y = 99;
console.log(a.x.y);
// 99 ← a da dəyişdi! BUG!
✅ Dərin kopyalama
const a = { x: { y: 1 } };
const b = JSON.parse(
  JSON.stringify(a));
b.x.y = 99;
console.log(a.x.y); // 1 ✓
🐛 Bug 3 — Spread ilə çoxlu sayda arqument
Böyük massivi spread ilə funksiyaya verdikdə bəzi brauzerlərdə stack overflow baş verə bilər.
❌ Stack overflow riski
const boyuk = new Array(1000000);
Math.max(...boyuk);
// RangeError: Maximum call
// stack size exceeded
✅ reduce istifadə et
const boyuk = [3,1,9,2,...];
const maks = boyuk.reduce(
  (m,v) => Math.max(m,v), -Infinity);
// Təhlükəsiz ✓
🐛 Bug 4 — Obyekt spread funksiyaları itirmir
Spread ilə obyekt kopyalandıqda prototip metodları itir. Class nümunələrini spred etmək risklidir.
javascript
class Insan {
  constructor(ad) { this.ad = ad; }
  salam() { return `Salam, ${this.ad}`; }
}

const eli = new Insan("Əli");
eli.salam(); // "Salam, Əli" ✓

const kopya = { ...eli };
kopya.salam(); // TypeError! salam metodu yoxdur!
// Kopya sadəcə {ad: "Əli"}-dir, metodu yoxdur

// Destructuring + Rest ilə gizli məlumatı ayır
const {
  istifadeci: { token, ...aciqInfo },
  dersler: [birinci, ikinci, ...qalanlar]
} = apiCavabi;

console.log(aciqInfo);
// { id: 42, ad: "Günel", email: "gunel@example.com" }
// token çıxarıldı!

console.log(birinci, ikinci); // "JS" "React"
console.log(qalanlar);         // ["Node", "SQL"]
