Data Transformation Nədir?
Data transformation — məlumatları bir strukturdan digərinə çevirmək prosesidir. Real layihələrdə hər gün rast gəlinir:

• Backend API cavabı → UI-a uyğun obyekt
• Xam istifadəçi məlumatı → Filtrli, sıralanmış siyahı
• Çox sətirli cədvəl → Qruplaşdırılmış hesabat
• E-ticarət məhsulları → Kateqoriyaya görə bölünmüş katalog
Əsas konsepsiya
javascript 
// DATA TRANSFORMATION — əsas fikir:
// Giriş (INPUT) → Dəyişiklik (TRANSFORM) → Çıxış (OUTPUT)

const rawData = [1, 2, 3, 4, 5];

const result = rawData
  .filter(n => n % 2 === 0)       // → [2, 4]
  .map(n => n * 10)              // → [20, 40]
  .reduce((acc, n) => acc + n, 0); // → 60

console.log(result); // 60
Nəticə
60

İstifadəçi siyahısını formatlayın

.map() — hər elementi çevirir, massiv ölçüsünü dəyişmir. Bu nümunədə:

• Template literal (${}) ilə ad+soyad birləşdirilir
• .toLowerCase() emaili kiçik hərfə çevirir — DB-də normalized saxlamaq üçün vacibdir
• Köməkçi funksiya getAgeGroup məntiqi ayrıca saxlayır — test etmək asanlaşır

🏢 Real Layihə

02
Məhsul kataloqonu filtrlayın
E-ticarət məhsullarını qiymət aralığına, stok vəziyyətinə və kateqoriyaya görə filtirləyin. Çoxlu şərt tətbiq edin.
.filter() E-commerce Multi-criteria
Məhsullar (mock API cavabı)
GET/api/products?category=electronics
const products = [
  { id: 1, name: "Laptop", price: 1200, inStock: true,  category: "electronics" },
  { id: 2, name: "Siçan",  price: 45,   inStock: false, category: "electronics" },
  { id: 3, name: "Monitor",price: 350,  inStock: true,  category: "electronics" },
  { id: 4, name: "Qələm",  price: 5,    inStock: true,  category: "office"     }
];
Həll
javascript 
// Filtr parametrləri (UI-dan gəlir)
const filters = {
  minPrice: 50,
  maxPrice: 1500,
  inStockOnly: true,
  category: "electronics"
};

const filtered = products.filter(p => {
  const priceOk = p.price >= filters.minPrice 
                && p.price <= filters.maxPrice;
  const stockOk = filters.inStockOnly ? p.inStock : true;
  const catOk   = p.category === filters.category;
  
  return priceOk && stockOk && catOk;
});

// Dinamik filtr funksiyası — istənilən şərtlər üçün
const createFilter = (conditions) => (item) =>
  conditions.every(fn => fn(item));

const smartFilter = createFilter([
  p => p.inStock,
  p => p.price > 100
]);
const result = products.filter(smartFilter);
filtered nəticəsi
[ { id: 1, name: "Laptop", price: 1200, inStock: true, category: "electronics" }, { id: 3, name: "Monitor", price: 350, inStock: true, category: "electronics" } ]
.filter() — true qaytaran elementləri saxlayır, false qaytaranları silir.

• Ternary operator: inStockOnly ? p.inStock : true — filtr aktiv deyilsə bütün elementlər keçir
• createFilter pattern — Higher-Order Function: şərtlər massivi qəbul edir, filtr funksiyası qaytarır. every() bütün şərtlər yerinə yetirilsə true qaytarır
• Orijinal products massivi dəyişmir — immutability prinsipi
🛒 Real Layihə — Trendyol / Amazon klon
E-ticarət saytlarında sol panel filtrlər məhz bu pattern ilə işləyir. İstifadəçi qiymət sürüşdürücüsünü dəyişdikdə yeni filters obyekti yaranır, .filter() yenidən icra olunur, React state yenilənir. Backend-ə sorğu göndərilmir — client-side filtering.

Satış hesabatını hesablayın
Sifariş massivindən ümumi gəlir, ən çox satılan kateqoriya, ortalama qiymət hesablayın. reduce ilə kompleks aggregasiya.
.reduce() Analytics Aggregation
Sifarişlər (Backend mock)
GET/api/orders?period=2024-Q1
const orders = [
  { id: 1, category: "Elektronika", amount: 1200, qty: 2 },
  { id: 2, category: "Geyim",      amount: 85,   qty: 5 },
  { id: 3, category: "Elektronika", amount: 450,  qty: 1 },
  { id: 4, category: "Geyim",      amount: 120,  qty: 3 },
  { id: 5, category: "Kitab",       amount: 30,   qty: 8 }
];
Həll
javascript 
const report = orders.reduce((acc, order) => {
  // Ümumi gəlir
  acc.totalRevenue += order.amount * order.qty;
  
  // Kateqoriyaya görə qruplaşdır
  if (!acc.byCategory[order.category]) {
    acc.byCategory[order.category] = { revenue: 0, count: 0 };
  }
  acc.byCategory[order.category].revenue += order.amount * order.qty;
  acc.byCategory[order.category].count++;
  
  // Ən böyük sifariş
  if (order.amount > acc.maxOrder.amount) {
    acc.maxOrder = order;
  }
  
  return acc;
}, { totalRevenue: 0, byCategory: {}, maxOrder: orders[0] });

// Ən çox gəlir gətirən kateqoriya
report.topCategory = Object
  .entries(report.byCategory)
  .sort(([,a], [,b]) => b.revenue - a.revenue)[0][0];
report nəticəsi
{ totalRevenue: 3375, byCategory: { "Elektronika": { revenue: 2850, count: 2 }, "Geyim": { revenue: 785, count: 2 }, "Kitab": { revenue: 240, count: 1 } }, maxOrder: { id: 1, category: "Elektronika", amount: 1200, qty: 2 }, topCategory: "Elektronika" }
.reduce() — ən güclü massiv metodu. Bütün elementləri bir dəyərə (rəqəm, obyekt, massiv) çevirir.

• Accumulator pattern: acc — hər iterasiyada yenilənən "yığım" obyekti
• İlkin dəyər ({ totalRevenue: 0, byCategory: {} }) ikinci arqument kimi verilir
• Dynamic key: acc.byCategory[order.category] — kateqoriya adı dinamik açar kimi istifadə olunur
• Object.entries().sort() — kateqoriyaları gəlirə görə sıralayır, destructuring ilə [,a] dəyər götürülür (açar lazım deyil)
📊 Real Layihə — Dashboard Analytics
Google Analytics, Mixpanel kimi analitika platformalarında bu pattern əsasdır. Frontend chart kitabxanaları (Chart.js, Recharts) məhz belə strukturlaşdırılmış məlumat qəbul edir. reduce() ilə bir keçişdə bütün statistikalar hesablanır — performans üçün əladır.

04
Massivdən lookup cədvəli yaradın
İstifadəçilər massivini ID-yə görə sürətli axtarış üçün obyektə çevirin. O(n) axtarış yerinə O(1) əldə edin.
reduce Performance Normalize
Giriş məlumatı
javascript 
const users = [
  { id: 101, name: "Leyla",  dept: "Engineering" },
  { id: 102, name: "Rauf",   dept: "Design"      },
  { id: 103, name: "Nigar",  dept: "Marketing"   }
];

// ❌ Yavaş yol — hər axtarışda bütün massivi tarayır O(n)
const user = users.find(u => u.id === 102);

// ✅ Sürətli yol — bir dəfə indeks qur, sonra O(1)
const usersById = users.reduce((acc, user) => {
  acc[user.id] = user;
  return acc;
}, {});

// Object.fromEntries ilə daha qısa:
const usersById2 = Object.fromEntries(
  users.map(u => [u.id, u])
);

// İstifadə:
console.log(usersById[102].name); // "Rauf" — ani!
usersById nəticəsi
{ "101": { id: 101, name: "Leyla", dept: "Engineering" }, "102": { id: 102, name: "Rauf", dept: "Design" }, "103": { id: 103, name: "Nigar", dept: "Marketing" } }
Normalization (normallaşdırma) — Redux Toolkit, React Query, TanStack Query-nin əsas pattern-ı.

10.000 istifadəçi varsa, .find() hər çağırışda 10.000 elementi nəzərdən keçirir. Lookup obyekti isə birbaşa əldə etməyə imkan verir. Əvvəl bir dəfə qur, sonra sonsuz dəfə sürətlə istifadə et.
⚛️ Real Layihə — Redux State Shape
redux pattern 
// Redux-da normalized state:
state = {
  users: {
    ids: [101, 102, 103],
    entities: {
      101: { id: 101, name: "Leyla"  },
      102: { id: 102, name: "Rauf"   },
    }
  }
}
// state.users.entities[userId] — O(1) əldə
05
Obyekt açarlarını çevirin (rename keys)
Backend snake_case açarlarını (first_name) frontend camelCase-ə (firstName) çevirin. API kontrakt dəyişdikdə mərkəzləşdirilmiş çevirmə.
Object.entries fromEntries API Transform
Həll
javascript 
// Backend-dən gələn snake_case
const apiUser = {
  first_name: "Günel",
  last_name: "Əliyeva",
  birth_date: "1995-03-12",
  is_verified: true
};

// snake_case → camelCase çeviricisi
const toCamelCase = (str) =>
  str.replace(/_([a-z])/g, (_, c) => c.toUpperCase());

const transformKeys = (obj) =>
  Object.fromEntries(
    Object.entries(obj).map(([key, val]) => [toCamelCase(key), val])
  );

const frontendUser = transformKeys(apiUser);

// Massiv üçün:
const transformAll = (arr) => arr.map(transformKeys);

// Xüsusi sahə xəritəsi ilə:
const fieldMap = { first_name: "name", birth_date: "dob" };
const remapFields = (obj) =>
  Object.fromEntries(
    Object.entries(obj).map(([k, v]) => [fieldMap[k] ?? k, v])
  );
frontendUser nəticəsi
{ firstName: "Günel", lastName: "Əliyeva", birthDate: "1995-03-12", isVerified: true }

javascript 
// Bütün işçiləri departament məlumatı ilə düzləşdir
const allEmployees = company.departments.flatMap(dept =>
  dept.employees.map(emp => ({
    ...emp,
    department: dept.name,
    company: company.name
  }))
);

// Ümumi maaş hesabatı
const payroll = allEmployees.reduce((acc, emp) => {
  acc.total += emp.salary;
  acc.byDept[emp.department] ??= 0;
  acc.byDept[emp.department] += emp.salary;
  return acc;
}, { total: 0, byDept: {} });

// flat() alternativis — iç-içə massivlər üçün
const allEmps2 = company.departments
  .map(d => d.employees)  // → [[emp1,emp2],[emp3]]

allEmployees nəticəsi
[ { id: 1, name: "Elmar", salary: 3500, department: "Mühəndislik", company: "AzTech LLC" }, { id: 2, name: "Sevinc", salary: 3200, department: "Mühəndislik", company: "AzTech LLC" }, { id: 3, name: "Nərmin", salary: 2800, department: "Dizayn", company: "AzTech LLC" } ] payroll: { total: 9500, byDept: { "Mühəndislik": 6700, "Dizayn": 2800 } }
.flatMap(fn) = .map(fn).flat(1) — daha qısa, daha sürətli.

• Spread operator (...emp) — əsl obyektin bütün xüsusiyyətlərini kopyalayır, üstünə yeni sahələr əlavə edir
• Nullish coalescing assignment (??=) — yalnız undefined və null olduqda dəyər təyin edir. acc.byDept[dept] = acc.byDept[dept] || 0 əvəzinə
• Dərin iç-içəlik üçün: .flat(Infinity) — bütün səviyyələri düzləşdirir
👔 Real Layihə — İşçi İdarəetmə Sistemi
SAP, Workday kimi HR sistemlərinin frontend hissəsi bu pattern-i geniş istifadə edir. Ağac strukturunu düz siyahıya çevirmək, həm cədvəl göstərmək, həm axtarış, həm Excel export üçün lazımdır.
07
Massivi kateqoriyaya görə qruplaşdırın
Xəbərlər massivini tarixə və kateqoriyaya görə qruplaşdırın. Yeni Object.groupBy() + reduce alternativin müqayisəsi.
groupBy reduce News feed
Həll
javascript 
const articles = [
  { id: 1, title: "Azərbaycan iqtisadiyyatı", cat: "Siyasət", date: "2024-01-15" },
  { id: 2, title: "Yeni texnologiyalar",      cat: "Tech",    date: "2024-01-15" },
  { id: 3, title: "Xəzər neft yataqları",    cat: "Siyasət", date: "2024-01-16" }
];

// ✅ Müasir: Object.groupBy() — ES2024
const byCat = Object.groupBy(articles, a => a.cat);

// ✅ Universal: reduce ilə (bütün brauzerlərdə işləyir)
const groupBy = (arr, key) =>
  arr.reduce((groups, item) => {
    const group = typeof key === "function" ? key(item) : item[key];
    (groups[group] ??= []).push(item);
    return groups;
  }, {});

// İkili qruplaşdırma — tarix + kateqoriya
const byDateAndCat = groupBy(articles, a => `${a.date}_${a.cat}`);
byCat nəticəsi
{ "Siyasət": [ { id: 1, title: "Azərbaycan iqtisadiyyatı", ... }, { id: 3, title: "Xəzər neft yataqları", ... } ], "Tech": [ { id: 2, title: "Yeni texnologiyalar", ... } ] }
groupBy pattern — Kanban board, News feed, Timeline kimi görünüşlər üçün vacibdir.

• Object.groupBy() — ES2024, Chrome 117+, Node 21+. Köhnə mühit üçün polyfill lazımdır
• Yenidən istifadə edilə bilən groupBy() yardımçı funksiyası həm string açar, həm funksiya qəbul edir
• Template literal açar (`${date}_${cat}`) — çox kriterialı qruplaşdırma üçün sadə həll
📋 Real Layihə — Trello / Linear / Jira
Trello-da vəziyyətə (To Do, In Progress, Done) görə kart qruplaşdırması, LinkedIn-də tarixə görə qruplaşdırılmış aktiv lenti — hamısı bu pattern. Frontend bir siyahı alır, groupBy ilə sütunlara bölür, hər sütunu render edir.

Pagination Normalize Adapter pattern
Müxtəlif Backend Formatları (mock)
javascript 
// 1-ci Backend: Laravel/Django stil (offset-based)
const laravelResponse = {
  data: [{ id: 1, name: "Məhsul A" }],
  current_page: 2, last_page: 10,
  per_page: 15, total: 148
};

// 2-ci Backend: Node.js REST stil
const nodeResponse = {
  items: [{ id: 1, name: "Məhsul A" }],
  pagination: { page: 2, pages: 10, limit: 15, total: 148 }
};

// 3-cü Backend: GraphQL cursor-based
const graphqlResponse = {
  edges: [{ node: { id: 1, name: "Məhsul A" }, cursor: "abc123" }],
  pageInfo: { hasNextPage: true, endCursor: "abc123" }
};

// ✅ Adapter: hamısını vahid formata çevir
const normalizePage = (response, type = "laravel") => {
  if (type === "laravel") return {
    items: response.data,
    currentPage: response.current_page,
    totalPages: response.last_page,
    total: response.total,
    hasMore: response.current_page < response.last_page
  };
  if (type === "graphql") return {
    items: response.edges.map(e => e.node),
    cursor: response.pageInfo.endCursor,
    hasMore: response.pageInfo.hasNextPage
  };
};

const unified = normalizePage(laravelResponse, "laravel");

Zəncirvari çevirmə, memoization, compose pattern

09
Çevirmə boru kəməri (Pipeline)
Bir neçə çevirmə addımını ardıcıl tətbiq edin. pipe() / compose() pattern ilə funksional yanaşma.
Functional compose pipe
javascript 
// pipe: soldan sağa icra (sol → sağ)
const pipe = (...fns) => (x) =>
  fns.reduce((v, fn) => fn(v), x);

// compose: sağdan sola icra (riyazi notasiya)
const compose = (...fns) => (x) =>
  fns.reduceRight((v, fn) => fn(v), x);

// Çevirmə addımları
const removeInactive  = users => users.filter(u => u.active);
const sortByName      = users => [...users].sort((a,b) => a.name.localeCompare(b.name, "az"));
const addDisplayName  = users => users.map(u => ({...u, display: `${u.name} (${u.role})`}));
const limitTo10       = users => users.slice(0, 10);

// Pipeline qur — oxunması asan, test etmək rahat
const prepareUserList = pipe(
  removeInactive,
  sortByName,
  addDisplayName,
  limitTo10
);

const rawUsers = [
  { name: "Zaur",  role: "dev",     active: true  },
  { name: "Aynur", role: "design",  active: false },
  { name: "Elşən", role: "manager", active: true  }
];

const displayUsers = prepareUserList(rawUsers);
displayUsers nəticəsi
[ { name: "Elşən", role: "manager", active: true, display: "Elşən (manager)" }, { name: "Zaur", role: "dev", active: true, display: "Zaur (dev)" } ]
Pipeline pattern — funksional proqramlaşdırmanın ürəyi.

• Hər addım pure function — eyni giriş, eyni çıxış. Test etmək sadədir
• Addımları asanlıqla yenidən sıralamaq, əlavə etmək, çıxarmaq olar
• Redux middleware eyni pattern: applyMiddleware(logger, thunk, saga)
• Express.js middleware: app.use(cors(), auth(), rateLimit())
10
Memoize ilə hesablama keşləyin
Bahalı hesablamaları keşləyin. Eyni arqumentlə ikinci çağırışda hesablamadan keşdən götürün.
Memoization Performance Cache
javascript 
// Ümumi memoize funksiyası
const memoize = (fn) => {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    if (cache.has(key)) {
      console.log("Keşdən götürüldü:", key);
      return cache.get(key);
    }
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
};

// Ağır hesablama — məsələn, böyük data analizi
const analyzeData = memoize((dataset, year) => {
  console.log(`${year} üçün analiz aparılır...`);
  // Bura ağır hesablama: filtrlər, aggregasiya, sort
  return dataset
    .filter(d => d.year === year)
    .reduce((sum, d) => sum + d.revenue, 0);
});

const data = [
  { year: 2023, revenue: 5000 },
  { year: 2024, revenue: 7500 }
];

analyzeData(data, 2023); // Hesablanır → 5000
analyzeData(data, 2023); // Keşdən → 5000 (sürətli!)
analyzeData(data, 2024); // Hesablanır → 7500
Konsol çıxışı
2023 üçün analiz aparılır... Keşdən götürüldü: "[...,2023]" 2024 üçün analiz aparılır... Nəticələr: 5000 → 5000 → 7500

Azərbaycan əlifbası ilə sıralama
Azərbaycan hərfləri (ə, ğ, ı, ö, ü, ş, ç) ilə söz sıralama. localeCompare("az") istifadəsi.
localeCompare Azərbaycan Collation
javascript 
const names = [
  "Ülfət", "Aytən", "Şəbnəm", "Çiçək",
  "Əsmər", "Gülnar", "Ömər", "İlham"
];

// ❌ Yanlış — ASCII sıralaması Azərbaycan üçün işləmir
const wrongSort = [...names].sort();
// Ç, Ə, İ, Ö, Ş, Ü ASCII-də böyük dəyərə malikdir

// ✅ Düzgün — Azərbaycan locale ilə
const azSort = [...names].sort((a, b) =>
  a.localeCompare(b, "az", { sensitivity: "base" })
);

// Collator — daha sürətli (böyük siyahılar üçün)
const azCollator = new Intl.Collator("az", {
  sensitivity: "base",
  numeric: true   // "10" > "9" kimi sıralayır
});

const fastSort = [...names].sort(azCollator.compare);

// Çoxlu sahə üzrə sıralama
const people = [
  { ad: "Əli",   yas: 25 }, { ad: "Aynur", yas: 30 },
  { ad: "Əli",   yas: 22 }
];

const multiSort = [...people].sort((a, b) =>
  a.ad.localeCompare(b.ad, "az") || a.yas - b.yas
);
azSort nəticəsi — düzgün Azərbaycan sırası
["Aytən", "Çiçək", "Əsmər", "Gülnar", "İlham", "Ömər", "Şəbnəm", "Ülfət"] multiSort: [ { ad: "Aynur", yas: 30 }, { ad: "Əli", yas: 22 }, ← əvvəl gənc Əli { ad: "Əli", yas: 25 } ]
Müqayisə:

• .sort() — Unicode kod nöqtəsinə görə. "Ə" (U+018F) > "Z" (U+005A), buna görə Azərbaycan hərfləri axıra düşür
• localeCompare("az") — OS-in Azərbaycan əlifbasını bilən sıralama qaydalarından istifadə edir
• Intl.Collator — böyük massivlər üçün daha sürətli, çünki bir dəfə yaranır, dəfələrlə .compare() çağırılır
• sensitivity: "base" — Böyük/kiçik hərfə əhəmiyyət vermir: "Əli" = "əli"

Dərin klon və immutable yeniləmə
Obyekti mutasiya etmədən yeniləyin. structuredClone(), immer pattern, spread operator ilə dərin kopyalama.
Immutability structuredClone State management
javascript 
const state = {
  user: { name: "Fidan", age: 26 },
  settings: { theme: "dark", lang: "az" },
  cart: [{ id: 1, qty: 2 }]
};

// ❌ Problem: sığ kopyalama (shallow copy)
const copy1 = { ...state };
copy1.user.age = 30; // state.user.age da dəyişir!

// ✅ structuredClone — tam dərin klon (ES2022)
const deepCopy = structuredClone(state);
deepCopy.user.age = 30; // orijinal dəyişmir ✓

// ✅ İmmutable yeniləmə (React/Redux pattern)
const updateUserAge = (state, newAge) => ({
  ...state,
  user: { ...state.user, age: newAge }
});

const addToCart = (state, item) => ({
  ...state,
  cart: [...state.cart, item]
});

const removeFromCart = (state, id) => ({
  ...state,
  cart: state.cart.filter(i => i.id !== id)
});

// Zəncirvari state yeniləmə
const newState = pipe(
  s => updateUserAge(s, 27),
  s => addToCart(s, { id: 2, qty: 1 })
)(state);
newState nəticəsi (orijinal dəyişməyib)
{ user: { name: "Fidan", age: 27 }, ← yeniləndi settings: { theme: "dark", lang: "az" }, cart: [{ id: 1, qty: 2 }, { id: 2, qty: 1 }] ← əlavə edildi } state.user.age hələ də 26-dır ✓
Immutability React-in state yeniləməsinin əsasıdır — React dəyişikliyi yalnız yeni referans ilə aşkar edir.

• structuredClone() — Date, Map, Set, RegExp, ArrayBuffer dəstəkləyir. JSON.parse(JSON.stringify()) bu tipləri pozur
• Spread (...) yalnız sığ kopyalar — iç-içə obyektlər üçün hər səviyyəni ayrıca spread etmək lazımdır
• Immer.js kitabxanası bu ağrıpointini həll edir: mutable sintaksis yazırsınız, immutable nəticə əldə edirsiniz
