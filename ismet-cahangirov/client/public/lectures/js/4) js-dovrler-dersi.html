Bölmə 01 · Giriş

Dövr (loop) nədir?

Dövr — müəyyən şərt doğru (true) olduğu müddətcə eyni kod bloğunu təkrar-təkrar icra edən proqramlaşdırma strukturudur. Əl ilə eyni əməliyyatı dəfələrlə yazmaq əvəzinə, dövr həmin işi bizim üçün avtomatlaşdırır.

Dövr olmadan — 1-dən 5-ə qədər ədədləri çap etmək:

without-loop.js
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);
// 1000-ə qədər olsaydı, 1000 sətir kod lazım gələrdi!

Dövr ilə — eyni nəticə, cəmi 3 sətir:

with-loop.js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

JavaScript-də üç əsas dövr növü var: for (say məlum olduqda), while (şərtə əsaslanan) və do...while (ən azı bir dəfə icra olunmalı olan hallar üçün). Növbəti bölmələrdə hər birini ayrıca, nümunələrlə araşdıracağıq.

Bölmə 02 · for

for dövrü

for dövrü təkrarların sayı əvvəlcədən məlum olduqda ən uyğun seçimdir. Onun sintaksisi üç hissədən ibarətdir və hamısı bir sətirdə yazılır.

syntax
for (başlanğıc; şərt; addım) {
  // gövdə — təkrarlanacaq kod
}

1. Başlanğıc

Dövr başlamazdan əvvəl bir dəfə icra olunur. Adətən sayğac dəyişəni yaradılır: let i = 0

2. Şərt

Hər təkrardan əvvəl yoxlanılır. true olarsa gövdə icra olunur, false olarsa dövr dayanır.

3. Gövdə

Şərt doğru olduqda icra olunan kod bloğu. Burada istədiyin əməliyyatı yerinə yetirirsən.

4. Addım

Hər təkrardan sonra icra olunur. Adətən sayğacı artırır/azaldır: i++ və ya i--

Nümunə:

for-example.js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// Çıxış: 1 2 3 4 5

Addım-addım icra:

Nə vaxt istifadə et: təkrarların sayı əvvəlcədən bəlli olduqda — massiv elementlərini gəzmək, 1-dən N-ə qədər saymaq, sabit sayda əməliyyat təkrarlamaq və s.

Bölmə 03 · while

while dövrü

while dövrü daha sadədir: yalnız şərt var. Şərt doğru olduğu müddətcə gövdə icra olunur. Addımlama (say artırma/azaltma) gövdənin daxilində, əl ilə yazılmalıdır.

syntax
while (şərt) {
  // gövdə
  // addımlama BURADA əl ilə edilməlidir
}

Nümunə:

while-example.js
let i = 1;
while (i <= 5) {
  console.log(i);
  i++; // bunu unutsan, sonsuz dövr yaranar!
}
// Çıxış: 1 2 3 4 5
⚠️ Diqqət: i++ sətrini gövdədən silsən, şərt (i ≤ 5) heç vaxt yalan olmayacaq və brauzer donacaq.

Nə vaxt istifadə et: təkrarların sayı əvvəlcədən bilinmədikdə — məsələn istifadəçi düzgün məlumat daxil edənə qədər, ya da bir şərt (fayl sonuna çatana qədər və s.) ödənənə qədər davam edən proseslərdə.

Bölmə 04 · do...while

do...while dövrü

do...while, while-a çox bənzəyir, amma fərqli yerdə şərt yoxlanılır: gövdə əvvəlcə bir dəfə icra olunur, sonra şərt yoxlanılır.

syntax
do {
  // gövdə — ən azı 1 dəfə icra olunur
} while (şərt);

Nümunə — şərt başlanğıcdan yalan olsa belə:

do-while-example.js
let i = 10;
do {
  console.log(i);
  i++;
} while (i < 5);
// Çıxış: 10  (şərt (10 < 5) yalandır, amma gövdə yenə də 1 dəfə işləyib)

Nə vaxt istifadə et: gövdənin şərtdən asılı olmayaraq ən azı bir dəfə icra olunmalı olduğu hallarda — məsələn istifadəçidən ilk dəfə mütləq soruşulmalı olan menyu seçimi kimi.

Bölmə 06 · Nəzarət

break və continue

Bu iki açar söz dövrün normal axınına müdaxilə etməyə imkan verir.

break — dövrü tamamilə dayandırır

break-example.js
for (let i = 1; i <= 100; i++) {
  if (i % 7 === 0) {
    console.log("Tapıldı:", i);
    break; // dövr dərhal dayanır
  }
}
// Çıxış: Tapıldı: 7

continue — cari addımı ötürür

continue-example.js
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);
}
// Çıxış: 1 3 5 7 9  (cüt ədədlər keçilir)

İç-içə dövrlərdə (aşağıda) bu açar sözlərdən çox istifadə həddindən artıq istifadə kodun izlənməsini çətinləşdirə bilər — ölçülü istifadə et.

Bölmə 07 · İç-içə dövrlər

Nested loops (iç-içə dövrlər)

Bir dövrün gövdəsində başqa bir dövr yerləşdirmək olar. Klassik nümunə — vurma cədvəli:

nested-example.js
for (let i = 1; i <= 5; i++) {
  let setir = "";
  for (let j = 1; j <= 5; j++) {
    setir += (i * j) + "\t";
  }
  console.log(setir);
}
// 5x5 vurma cədvəlini sətir-sətir çap edir

Diqqət: iç-içə dövrlər mürəkkəbliyi sürətlə artırır (2 dövr → O(n²)). Böyük massivlərdə performans üçün ehtiyatlı ol, mümkünsə alternativ üsul (məs. axtarış üçün obyekt/Map) düşün.

Bölmə 08 · Diqqət!

Ola biləcək xətalar və bug-lar

Dövrlərlə işləyərkən yeni başlayanların (və təcrübəlilərin belə) ən çox rastlaşdığı 7 problem:

01

Sonsuz dövr (Infinite Loop)

Şərt heç vaxt false olmadıqda dövr sonsuza qədər işləyir və səhifə/brauzer donur.

for (let i = 0; i < 10; i--) {
  console.log(i);
}
// i azalır, amma şərt (i < 10) HƏMİŞƏ true qalır → sonsuz dövr!
Həll: addımlamanın şərtlə eyni istiqamətdə işlədiyinə əmin ol (i++ ↔ i < N), kodu yazdıqdan sonra addım-addım "əlində" icra et.
02

Off-by-one xətası

< əvəzinə <= (və ya əksinə) istifadə etmək bir addım artıq/az icraya səbəb olur.

const meyveler = ["alma", "armud", "gilas"];
for (let i = 0; i < meyveler.length - 1; i++) {
  console.log(meyveler[i]);
}
// "gilas" heç vaxt çap olunmur — length-dən 1 artıq çıxılıb!
Həll: massiv gəzərkən şərti i < massiv.length şəklində yaz (indeks 0-dan başladığı üçün <= lazım deyil).
03

= və ==/=== qarışdırılması

Şərt daxilində müqayisə əvəzinə təyinetmə operatoru yazmaq — şərti həmişə "doğru" edir.

let i = 0;
if (i = 5) { // === yerinə = yazılıb!
  console.log("Bu həmişə icra olunur");
}
Həll: şərtlərdə həmişə === (və ya ==) istifadə et, tək = yalnız dəyər mənimsətmək üçündür.
04

var ilə closure problemi

var funksiya-səviyyəli (function-scoped) olduğu üçün, gecikmiş kodlarda (məs. setTimeout) gözlənilməz nəticələr verir.

for (var i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Nəticə: 4, 4, 4  (gözlənilən 1, 2, 3 əvəzinə)
Həll: var əvəzinə let istifadə et — hər təkrarda öz blok-səviyyəli nüsxəsini yaradır: for (let i = 1; ...) → nəticə düzgün olaraq 1, 2, 3.
05

Sayğacı gövdə daxilində əl ilə dəyişmək

for dövründə i dəyişənini gövdənin içində əlavə olaraq dəyişmək kodun məntiqini izləməyi çətinləşdirir və gözlənilməz sonsuz dövrlərə yol aça bilər.

Həll: sayğacı yalnız dövrün öz "addım" hissəsində dəyiş; gövdə daxilində fərqli məqsəd üçün yeni dəyişən istifadə et.
06

Hər addımda təkrar hesablama (performans)

Şərtdə mürəkkəb ifadəni hər dəfə yenidən hesablatmaq (böyük massiv/DOM sorğusu və s.) böyük datasetlərdə yavaşlığa səbəb ola bilər.

// Daha yaxşı:
const uzunluq = massiv.length; // əvvəlcədən saxlanılır
for (let i = 0; i < uzunluq; i++) {
  console.log(massiv[i]);
}
Həll: dəyişməyəcək dəyərləri dövrdən əvvəl bir dəfə hesablayıb dəyişənə yaz.
07

do...while ilə gözlənilməz ilk icra

Gövdə şərtdən əvvəl icra olunduğu üçün, başlanğıc data hazır olmasa belə kod bir dəfə işləyəcək — bu bəzən istənilməyən yan effektə (məs. boş məlumatla əməliyyat) səbəb olur.

Həll: do...while-i yalnız "ən azı 1 dəfə icra lazımdır" məntiqi aydın olduqda seç, əks halda adi while daha təhlükəsizdir.
Bölmə 09 · Daha yaxşı necə edək?

Ən yaxşı təcrübələr

Yuxarıdakı bug-ların qarşısını almaq və daha təmiz kod yazmaq üçün bu tövsiyələrə əməl et:

let

var yox, let/const istifadə et

Blok-səviyyəli scope closure problemlərinin qarşısını alır və kodu daha proqnozlaşdırıla bilən edir.

Aa

Mənalı dəyişən adları ver

Sadə sayğaclar üçün i, j qəbul edilir, amma məzmunlu massivlərdə itemIndex kimi adlar daha oxunaqlıdır.

?

Şərti sadə saxla

Mürəkkəb məntiqi ayrıca bir funksiyaya çıxar: while (hazirdirmi()) oxumağı asanlaşdırır.

∞

Sonsuz dövrü əvvəlcədən yoxla

Kodu yazdıqdan sonra addımlama məntiqini test et — şərt həqiqətən nə vaxtsa false olacaqmı?

[]

Massivlərdə hazır metodlardan yararlan

Sadə gəzinti üçün for...of, transformasiya üçün map/filter/reduce daha oxunaqlı ola bilər.

▦

İç-içə dövrlərdən ehtiyatlı istifadə et

Mümkünsə alternativ struktur (obyekt, Map, Set) axtararaq O(n²) mürəkkəbliyindən qaç.

log

console.log ilə izlə

Dövr düzgün işləmirsə, sayğacın və şərtin dəyərini hər addımda çap edərək "debug" et.

B/C

break/continue-u ölçülü istifadə et

Faydalıdırlar, amma çox iç-içə istifadə olunanda kodun axınını izləmək çətinləşir.

Bonus — for...of və for...in fərqi:

for-of.js
const reqler = ["qırmızı", "yaşıl", "mavi"];
for (const reng of reqler) {
  console.log(reng);
}

Massiv/iterable dəyərlərini birbaşa gəzmək üçün — ən çox tövsiyə olunan üsul.

for-in.js
const insan = { ad: "Aysel", yas: 25 };
for (const acar in insan) {
  console.log(acar, ":", insan[acar]);
}

Obyektin açarlarını (key) gəzmək üçün. Massivlərdə istifadəsi tövsiyə olunmur.

Bölmə 12 · Xülasə

Sürətli istinad (cheat sheet)

for

  • Say əvvəlcədən məlum olduqda
  • Başlanğıc/şərt/addım bir sətirdə
  • Massiv gəzintisi üçün klassik seçim

while

  • Say məlum olmadıqda
  • Şərt öncədən yoxlanılır
  • Addımlamağı unutma!

do...while

  • Ən azı 1 dəfə icra lazımdırsa
  • Şərt gövdədən sonra yoxlanılır
  • Nadir hallarda istifadə olunur

Yadda saxla: let-dən istifadə et, addımlamanı yoxla, şərtini sadə saxla və sonsuz dövrdən qorxma — onu tanımağı öyrəndin! 🎉
