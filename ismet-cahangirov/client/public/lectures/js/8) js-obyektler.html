Obyekt Nədir?

Məlumatları birlikdə saxlamağın yolu

Gündəlik həyatdan düşünək. Bir insan haqqında məlumat yazmaq istəsəniz nə edərsiniz?

Onun adı, yaşı, şəhəri, tələbə olub-olmadığı var. Bunları ayrı-ayrı dəyişkənlərə yazmaq əvəzinə, hamısını bir yerdə — obyektdə saxlaya bilərsiniz.

💡
Qısa Tərif Obyekt — açar: dəyər (key: value) cütlərindən ibarət məlumat strukturudur. Hər bir cütə xüsusiyyət (property) deyilir.
🗝️

Açar (Key)

Xüsusiyyətin adı.
Məs: ad, yaş

📦

Dəyər (Value)

Həmin xüsusiyyətin saxladığı məlumat — string, number, boolean, array, başqa obyekt…

🔗

Xüsusiyyət (Property)

Açar + Dəyər birlikdə bir property əmələ gətirir

📝

Sintaksis

Fiqurlu mötərizə { } içinə yazılır, aralarında vergül , qoyulur

JavaScript— İlk obyekt nümunəsi
// Bir tələbəni təsvir edən obyekt
const tələbə = {
  ad: "Tural",           // açar: "ad"        → dəyər: "Tural"
  soyad: "Əliyev",       // açar: "soyad"     → dəyər: "Əliyev"
  yaş: 19,               // açar: "yaş"       → dəyər: 19 (rəqəm)
  tələbədir: true,       // açar: "tələbədir" → dəyər: boolean
  şəhər: "Bakı"          // açar: "şəhər"     → dəyər: "Bakı"
};

console.log(tələbə);
// → { ad: 'Tural', soyad: 'Əliyev', yaş: 19, tələbədir: true, şəhər: 'Bakı' }
📌
Yadda Saxla Hər xüsusiyyətin sonuna , qoyulur (sonuncu xüsusiyyətdə isteğe bağlı). Obyekt { } içinə yazılır, [ ] massiv (array) üçündür.
2

Obyekt Yaratmaq

3 müxtəlif üsul

Üsul 1 — Literal sintaksis (Ən çox istifadə edilən)

Birbaşa { } içinə yazırıq. Sadə, oxunaqlı, tövsiyə edilir.

JavaScript— Object literal
// Boş obyekt
const boşObyekt = {};

// Məlumatlarla dolu obyekt
const maşın = {
  marka:     "Toyota",
  model:     "Corolla",
  il:        2022,
  rəng:      "ağ",
  satışdadır: false
};

console.log(maşın.marka); // → "Toyota"
console.log(maşın.il);    // → 2022

Üsul 2 — new Object() konstruktoru

Daha köhnə üsul. Əksər hallarda literal daha yaxşıdır, amma bilmək lazımdır.

JavaScript— new Object()
const adam = new Object();

// Sonradan xüsusiyyətlər əlavə edilir
adam.ad   = "Rauf";
adam.yaş  = 25;
adam.şəhər = "Gəncə";

console.log(adam);
// → { ad: 'Rauf', yaş: 25, şəhər: 'Gəncə' }

Üsul 3 — Object.create()

Başqa bir obyektdən miras alan yeni obyekt yaradır. Daha qabaqcıl mövzudur.

JavaScript— Object.create()
const heyvan = {
  canlıdır:    true,
  nəfəsAlır:   true
};

// "it" obyekti heyvan-dan miras alır
const it = Object.create(heyvan);
it.ad   = "Bim";
it.cins = "Labrador";

console.log(it.ad);        // → "Bim"   (öz xüsusiyyəti)
console.log(it.canlıdır);  // → true    (heyvan-dan gəlir)
✅
Məsləhət Gündəlik işdə demək olar ki, həmişə literal sintaksis { } istifadə edin. Daha aydın, daha qısadır.

Xüsusiyyətlərə Müraciət

Dot notation vs Bracket notation

Obyektdəki məlumata çatmaq üçün iki üsul var:

ÜsulSintaksisNə vaxt istifadə et?
Nöqtə (Dot)obyekt.açarAçar sadə sözdürsə — ən çox istifadə edilir
Mötərizə (Bracket)obyekt["açar"]Açar adı boşluqlu, tireli, ya dəyişkəndən gəlirsə
JavaScript— Nöqtə ilə müraciət (Dot Notation)
const şagird = {
  ad:   "Nigar",
  yaş:  17,
  bal:  95
};

console.log(şagird.ad);   // → "Nigar"
console.log(şagird.yaş);  // → 17
console.log(şagird.bal);  // → 95
JavaScript— Mötərizə ilə müraciət (Bracket Notation)
const şagird = {
  ad:           "Nigar",
  "doğum yeri": "Sumqayıt",   // açar adında boşluq var!
  bal:          95
};

// Boşluqlu açar — MÜTLƏQ mötərizə lazımdır
console.log(şagird["doğum yeri"]);    // → "Sumqayıt"

// Açarı dəyişkəndən götürmək — çox güclü!
const hansı = "bal";
console.log(şagird[hansı]);           // → 95
// Bu üsul məsələn loop-larda çox işə yarayır
⚠️
Diqqət! Açar adında boşluq, tire (-), ya rəqəmlə başlama varsa mütləq [ ] istifadə edin. Nöqtə şagird.doğum yeri yazılsa — SyntaxError!
JavaScript— Olmayan xüsusiyyətə müraciət
const kitab = {
  başlıq: "Dəli Kür",
  müəllif: "İsmayıl Şıxlı"
};

// Olmayan xüsusiyyət → undefined qaytarır (xəta vermır!)
console.log(kitab.qiymət); // → undefined
console.log(kitab.il);     // → undefined

// Mövcudluğu yoxlamaq
if (kitab.qiymət === undefined) {
  console.log("Qiymət məlum deyil");
}
// → "Qiymət məlum deyil"

Dəyişmək · Əlavə Etmək · Silmək

Xüsusiyyət əməliyyatları

Obyekt yaradıldıqdan sonra istənilən zaman xüsusiyyətlərini dəyişmək, yenisini əlavə etmək ya da silmək mümkündür.

Dəyişmək (Update)

JavaScript— Dəyəri dəyişmək
const oyunçu = {
  ad:      "Elnur",
  bal:     0,
  səviyyə: 1
};

// Dəyər üstünə sadəcə yeni dəyər yazılır
oyunçu.bal     = 150;
oyunçu.səviyyə = 2;

console.log(oyunçu.bal);     // → 150
console.log(oyunçu.səviyyə); // → 2

Yeni Xüsusiyyət Əlavə Etmək (Add)

JavaScript— Yeni açar əlavə
const istifadəçi = {
  ad:    "Leyla",
  email: "leyla@example.com"
};

// Yeni xüsusiyyət — sadəcə yazın, JavaScript əlavə edir
istifadəçi.yaş    = 23;
istifadəçi.ölkə   = "Azərbaycan";
istifadəçi.aktiv  = true;

console.log(istifadəçi);
// → { ad: 'Leyla', email: '...', yaş: 23, ölkə: 'Azərbaycan', aktiv: true }

Xüsusiyyəti Silmək (Delete)

JavaScript— delete operatoru
const profil = {
  ad:     "Azər",
  email:  "azer@mail.com",
  şifrə:  "gizli123",      // ← bunu silmək istəyirik
  yaş:    28
};

delete profil.şifrə;

console.log(profil);
// → { ad: 'Azər', email: 'azer@mail.com', yaş: 28 }

console.log(profil.şifrə); // → undefined (artıq yoxdur)

Mövcudluğu Yoxlamaq

JavaScript— in operatoru & hasOwnProperty
const məhsul = {
  ad:      "Laptop",
  qiymət:  1200,
  anbarda: true
};

// "in" operatoru — xüsusiyyət varmı?
console.log("ad"     in məhsul);  // → true
console.log("rəng"   in məhsul);  // → false

// hasOwnProperty — eyni iş görür
console.log(məhsul.hasOwnProperty("qiymət")); // → true
console.log(məhsul.hasOwnProperty("rəng"));   // → false
✅
const ilə obyektlər — incə məqam const ilə yaradılmış obyektin xüsusiyyətlərini dəyişmək olar. Yalnız obyektin özünü başqa dəyərlə əvəzləmək olmaz. const yalnız yenidən mənimsətməni qoruyur.

Dövr Etmək (Loop)

for…in · Object.keys · Object.values · Object.entries

Bəzən obyektin bütün xüsusiyyətlərini bir-bir gəzmək lazım olur. Bunun üçün dörd əsas üsul var.

for…in dövrü

JavaScript— for...in ilə bütün açarlar
const şəhər = {
  ad:           "Bakı",
  əhali:        2300000,
  ölkə:         "Azərbaycan",
  quruluşİli:   1747
};

for (let açar in şəhər) {
  console.log(açar + ": " + şəhər[açar]);
}
// → ad: Bakı
// → əhali: 2300000
// → ölkə: Azərbaycan
// → quruluşİli: 1747

Object.keys() · Object.values() · Object.entries()

JavaScript— Obyekti array-ə çevirmək
const meyvə = {
  alma:  5,
  armud: 3,
  üzüm:  8
};

// Açarlar → array
console.log(Object.keys(meyvə));
// → ["alma", "armud", "üzüm"]

// Dəyərlər → array
console.log(Object.values(meyvə));
// → [5, 3, 8]

// Açar + Dəyər cütləri → array of arrays
console.log(Object.entries(meyvə));
// → [["alma", 5], ["armud", 3], ["üzüm", 8]]

// entries ilə loop — ən rahat üsul!
for (let [açar, dəyər] of Object.entries(meyvə)) {
  console.log(`${açar}: ${dəyər} ədəd`);
}
// → alma: 5 ədəd
// → armud: 3 ədəd
// → üzüm: 8 ədəd

İçiçə Obyektlər

Nested Objects — obyekt içində obyekt

Bir xüsusiyyətin özü də obyekt ola bilər. Buna içiçə (nested) obyekt deyilir. Real dünyada məlumatlar çox vaxt belə qurulur.

🏠
Real həyat nümunəsi Bir şəxsin adı, yaşı — sadə dəyərlər. Amma "ünvanı" desək — bu özü ayrıca məlumat toplusudur: şəhər, küçə, bina, mənzil. Buna görə ünvan xüsusiyyəti özü bir obyekt olur.
JavaScript— İçiçə obyekt — sadə nümunə
const şəxs = {
  ad:  "Fuad",
  yaş: 30,

  // "ünvan" xüsusiyyəti → özü də bir obyektdir!
  ünvan: {
    şəhər:  "Bakı",
    küçə:   "İstiqlaliyyət",
    bina:   12,
    mənzil: 5
  },

  // "əlaqə" xüsusiyyəti → yenə obyektdir
  əlaqə: {
    telefon: "+994501234567",
    email:   "fuad@example.com"
  }
};

// Birinci səviyyəyə müraciət
console.log(şəxs.ad);               // → "Fuad"

// İkinci səviyyəyə müraciət — nöqtəni uzadırıq
console.log(şəxs.ünvan.şəhər);      // → "Bakı"
console.log(şəxs.ünvan.mənzil);     // → 5
console.log(şəxs.əlaqə.email);      // → "fuad@example.com"

İçiçə xüsusiyyəti dəyişmək və əlavə etmək

JavaScript— Nested dəyər üzərində əməliyyatlar
const şəxs = {
  ad: "Fuad",
  ünvan: {
    şəhər: "Bakı",
    küçə:  "İstiqlaliyyət"
  }
};

// İçiçə dəyəri dəyişmək
şəxs.ünvan.şəhər = "Gəncə";
şəxs.ünvan.küçə  = "Hüseyn Cavid";

// İçiçə obyektə yeni xüsusiyyət əlavə etmək
şəxs.ünvan.poçtKodu = "AZ1000";

console.log(şəxs.ünvan);
// → { şəhər: 'Gəncə', küçə: 'Hüseyn Cavid', poçtKodu: 'AZ1000' }

Çox dərin iç-içəlik (Deep Nesting)

JavaScript— 4 səviyyəli nested nümunə
const şirkət = {
  ad:   "TechAZ",
  ölkə: "Azərbaycan",

  baş: {                        // ← 1-ci səviyyə
    ad: "Bakı ofisi",

    şöbələr: {                  // ← 2-ci səviyyə
      IT: {                     // ← 3-cü səviyyə
        işçiSayı: 45,
        müdir: {                // ← 4-cü səviyyə
          ad:    "Kamran",
          soyad: "Nəsirov",
          yaş:   38
        }
      },
      maliyyə: {
        işçiSayı: 12,
        büdcə:    500000
      }
    }
  }
};

// Hər səviyyəyə nöqtə ilə çatırıq
console.log(şirkət.baş.şöbələr.IT.işçiSayı);        // → 45
console.log(şirkət.baş.şöbələr.IT.müdir.ad);        // → "Kamran"
console.log(şirkət.baş.şöbələr.maliyyə.büdcə);      // → 500000

Obyekt içində Array (massiv)

JavaScript— Array xüsusiyyət kimi
const tələbə = {
  ad:  "Səbinə",
  yaş: 20,

  // dərslər — adi array
  dərslər: ["Riyaziyyat", "Fizika", "Kimya", "Coğrafiya"],

  // qiymətlər — obyektlər olan array
  qiymətlər: [
    { fənn: "Riyaziyyat", bal: 87 },
    { fənn: "Fizika",     bal: 92 },
    { fənn: "Kimya",      bal: 78 }
  ]
};

console.log(tələbə.dərslər[0]);       // → "Riyaziyyat"
console.log(tələbə.dərslər.length);   // → 4

// Array içindəki obyektə müraciət
console.log(tələbə.qiymətlər[1].fənn); // → "Fizika"
console.log(tələbə.qiymətlər[1].bal);  // → 92

// Hamısını gəzmək
tələbə.qiymətlər.forEach(q => {
  console.log(`${q.fənn}: ${q.bal}`);
});
// → Riyaziyyat: 87
// → Fizika: 92
// → Kimya: 78

Optional Chaining (?.) — Güvənli müraciət

İçiçə obyektdə bir xüsusiyyət olmaya bilər. ?. operatoru xətanın qarşısını alır.

JavaScript— ?. operatoru
const istifadəçi1 = {
  ad:    "Vüsal",
  ünvan: { şəhər: "Bakı" }
};

const istifadəçi2 = {
  ad: "Aynur"
  // ünvan xüsusiyyəti YOXdur!
};

// Adi müraciət — xəta verir:
// console.log(istifadəçi2.ünvan.şəhər);
// → TypeError: Cannot read properties of undefined

// ?. ilə — xəta yox, undefined qaytarır
console.log(istifadəçi1.ünvan?.şəhər);  // → "Bakı"
console.log(istifadəçi2.ünvan?.şəhər);  // → undefined  ✓ xəta yox!

// ?? (nullish coalescing) ilə birlikdə default dəyər
const şəhər = istifadəçi2.ünvan?.şəhər ?? "Bilinmir";
console.log(şəhər); // → "Bilinmir"

// Çox dərin yollarda çox işə yarayır
console.log(şirkət?.baş?.şöbələr?.IT?.müdir?.ad ?? "Tapılmadı");

Metodlar & this

Obyektin içindəki funksiyalar

Xüsusiyyətin dəyəri funksiya da ola bilər. Belə xüsusiyyətlərə metod deyilir.

JavaScript— Obyektə metod əlavə etmək
const hesab = {
  ad: "Sadə Hesablamacı",

  // Köhnə üsul — function() ilə
  topla: function(a, b) {
    return a + b;
  },

  // Müasir üsul (ES6+) — daha qısa, tövsiyə edilir
  çıxart(a, b) {
    return a - b;
  },

  vur(a, b) {
    return a * b;
  },

  böl(a, b) {
    if (b === 0) return "Sıfıra bölmək olmaz!";
    return a / b;
  }
};

// Metodları çağırmaq — adının arxasına () qoyulur
console.log(hesab.topla(10, 5));    // → 15
console.log(hesab.çıxart(10, 5));   // → 5
console.log(hesab.vur(4, 3));       // → 12
console.log(hesab.böl(10, 0));      // → "Sıfıra bölmək olmaz!"

this açar sözü

Metod daxilında obyektin özünə müraciət etmək lazım gəldikdə this istifadə edirik. this — "bu obyekt" deməkdir.

JavaScript— this ilə öz xüsusiyyətinə müraciət
const şəxs = {
  ad:    "Rəşad",
  soyad: "Məmmədov",
  yaş:   26,

  tamAd() {
    // this.ad   → bu obyektin "ad" xüsusiyyəti
    // this.soyad → bu obyektin "soyad" xüsusiyyəti
    return this.ad + " " + this.soyad;
  },

  salam() {
    return `Salam! Mən ${this.tamAd()}, yaşım ${this.yaş}-dir.`;
  },

  yaşArtır() {
    this.yaş++; // dəyişdirir
    return this.yaş;
  }
};

console.log(şəxs.tamAd());   // → "Rəşad Məmmədov"
console.log(şəxs.salam());   // → "Salam! Mən Rəşad Məmmədov, yaşım 26-dir."
şəxs.yaşArtır();
console.log(şəxs.yaş);       // → 27

Xətalar & Buglar

Tez-tez edilən səhvlər və həlləri

Hər proqramçının başına gəlir — o cümlədən peşəkarların da. Gəlin ən çox edilən xətaları görüb, həmişə doğru yazaq.

Xəta 1 TypeError — olmayan xüsusiyyətin içinə girməyə çalışmaq

Mövcud olmayan bir xüsusiyyətin altındakı xüsusiyyətə müraciət etmək TypeError verir.

❌ Yanlış
const istifadəçi = {
  ad: "Mərcan"
  // ünvan yoxdur!
};

console.log(
  istifadəçi.ünvan.şəhər
);
// → TypeError: Cannot read
//   properties of undefined
//   (reading 'şəhər')
✅ Düzgün
const istifadəçi = {
  ad: "Mərcan"
};

// ?. ilə güvənli müraciət
console.log(
  istifadəçi.ünvan?.şəhər
);
// → undefined  (xəta yox!)

// Şərtli yoxlama
if (istifadəçi.ünvan) {
  console.log(
    istifadəçi.ünvan.şəhər
  );
}
Xəta 2 Boşluqlu açara nöqtə ilə müraciət

Açar adında boşluq, tire, ya rəqəmlə başlama varsa — nöqtə işləmir.

❌ Yanlış
const m = {
  "məhsul adı": "Telefon",
  "ilk-qiymət": 800
};

// Hər ikisi XƏTA!
console.log(m.məhsul adı);
// → SyntaxError

console.log(m.ilk-qiymət);
// → NaN
// (çıxma əməli kimi görür)
✅ Düzgün
const m = {
  "məhsul adı": "Telefon",
  "ilk-qiymət": 800
};

// [ ] ilə müraciət
console.log(m["məhsul adı"]);
// → "Telefon"

console.log(m["ilk-qiymət"]);
// → 800
Xəta 3 const ilə obyekti tam əvəzləməyə çalışmaq

const dəyişkəni yenidən mənimsətmək olmaz — xüsusiyyətlərini dəyişmək isə olar.

❌ Yanlış
const avtomobil = {
  marka: "BMW"
};

// Tam əvəzləmə — OLMAZ!
avtomobil = { marka: "Audi" };
// → TypeError: Assignment to
//   constant variable.
✅ Düzgün
const avtomobil = {
  marka: "BMW"
};

// Xüsusiyyəti dəyişmək — OLAR ✓
avtomobil.marka = "Audi";
console.log(avtomobil.marka);
// → "Audi"

// Tam əvəzləmə lazımdırsa:
let araba = { marka: "BMW" };
araba = { marka: "Audi" }; // ✓
Xəta 4 Obyekti kopyalamaq — "istinad tələsi" (Reference Trap)

Obyektlər istinad (reference) ilə ötürülür. Sadə mənimsətmə həqiqi kopya yaratmır!

❌ Gözlənilməyən nəticə
const orijinal = {
  ad: "Kənan"
};

// Bu kopya DEYİL — eyni
// obyektə iki istinad!
const kopya = orijinal;

kopya.ad = "Elşən";

// Orijinal DƏYİŞDİ!
console.log(orijinal.ad);
// → "Elşən"  ← şok!
✅ Düzgün kopyalama
const orijinal = {
  ad: "Kənan"
};

// Spread ilə həqiqi (shallow) kopya
const kopya = { ...orijinal };

kopya.ad = "Elşən";

console.log(orijinal.ad); // → "Kənan" ✓
console.log(kopya.ad);    // → "Elşən" ✓

// Object.assign() ilə də olar:
const kopya2 =
  Object.assign({}, orijinal);
⚠️
Dərin kopyalama (Deep Clone) Spread ... yalnız bir səviyyəli kopyalayır. İçiçə obyektlər üçün structuredClone(obj) (müasir) ya da JSON.parse(JSON.stringify(obj)) istifadə edin.
Xəta 5 Arrow function ilə this işləmir!

Metod daxilında this lazımdırsa, arrow function () => {} istifadə etməyin — öz this-i yoxdur.

❌ Arrow function
const adam = {
  ad: "Tofiq",

  // Arrow function — this yoxdur!
  salam: () => {
    return "Salam, " + this.ad;
  }
};

console.log(adam.salam());
// → "Salam, undefined"
// this.ad tapılmır!
✅ Normal function
const adam = {
  ad: "Tofiq",

  // Normal metod sintaksisi
  salam() {
    return "Salam, " + this.ad;
  }
};

console.log(adam.salam());
// → "Salam, Tofiq"  ✓
Xəta 6 Vergül unutmaq — SyntaxError

Hər xüsusiyyətin sonuna , qoyulmalıdır (son xüsusiyyət isteğe bağlı). Ən çox edilən xətalardandır.

❌ Vergül yoxdur
const məhsul = {
  ad:      "Telefon"   // ← vergül yox!
  qiymət:  500         // ← vergül yox!
  anbarda: true
};
// → SyntaxError:
//   Unexpected token 'qiymət'
✅ Vergüllər var
const məhsul = {
  ad:      "Telefon",  // ← ✓
  qiymət:  500,        // ← ✓
  anbarda: true        // ← sonuncu, isteğe bağlı
};
// ✓ düzgündür
Xəta 7 Dərin nested-də zəncirli undefined

Çox dərin iç-içəlikdə bir ara xüsusiyyət undefined olarsa, növbəti müraciət kəskin xəta verir.

❌ Yanlış
const şirkət = {
  baş: {
    ad: "Bakı ofisi"
    // şöbələr yoxdur!
  }
};

// şöbələr undefined olduğu üçün
// .IT xəta verir:
console.log(
  şirkət.baş.şöbələr.IT.işçiSayı
);
// → TypeError!
✅ ?. ilə
const şirkət = {
  baş: {
    ad: "Bakı ofisi"
  }
};

// Hər pillədə ?. ilə yoxlama
console.log(
  şirkət.baş?.şöbələr
         ?.IT?.işçiSayı
);
// → undefined  (xəta yox!)

// Default dəyərlə:
const say =
  şirkət.baş?.şöbələr
  ?.IT?.işçiSayı ?? 0;
console.log(say); // → 0
🎓
Xülasə — Nə öyrəndik? Obyekt — key:value cütlərini saxlayır. Nöqtə . ya mötərizə [] ilə müraciət edirik. const ilə obyektin xüsusiyyətlərini dəyişmək olar, özünü yox. İçiçə (nested) obyektlər real dünyada çox işlənir — ?. ilə güvənli müraciət edin. Metodlar obyektin içindəki funksiyalardır — this ilə obyektə müraciət edirik. Arrow function-da this işləmir. Kopyalamada spread ... istifadə edin — sadə mənimsətmə istinad yaradır!
