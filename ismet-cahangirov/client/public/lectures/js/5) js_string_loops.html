1

String Nədir? Ən Vacib Metodlar

Hər metodu klik edərək izah və kod nümunəsini gör

String nədir? — Proqramlaşdırmada string sadə dillə mətn parçasıdır. Hərflər, rəqəmlər, boşluqlar — bunların hamısı tırnak içinə yazıldıqda string olur. JavaScript-də stringlər immutable (dəyişilməz)-dir: metod çağıranda orijinal dəyişmir, yeni dəyər qaytarılır. Azərbaycan hərfləri (ə, ı, ö, ü, ğ, ş, ç) Unicode-da mövcuddur — JavaScript onları tam dəstəkləyir.
.length String-in uzunluğunu öyrən ▼

length — metod deyil, property (xüsusiyyət)-dir. String-in yanına yazdıqda, neçə simvoldan ibarət olduğunu rəqəmlə qaytarır. Boşluqlar da sayılır! Azərbaycan hərfləri (ə, ı, ş, ğ...) hər biri 1 simvol kimi sayılır.

Kod nümunəsi
let ad = "Aynur Həsənova"; console.log(ad.length); // → 14 let sifre = "abc12"; if (sifre.length < 8) { console.log("Şifrə çox qısadır!"); // → çap olunur }
str[i] İndeks ilə hərfə birbaşa çatış YENİ ▼

str[i] — square bracket notation (kvadrat mötərizə). Hər hərfin bir indeksi var, 0-dan başlayır. str[0] ilk hərf, str[str.length-1] son hərf. Bu notation loop içində çox istifadə olunur. charAt(i) eyni işi görür — amma [i] daha qısa və müasirdir.

Kod nümunəsi
let metn = "Bakı"; console.log(metn[0]); // → "B" (0-cı indeks) console.log(metn[1]); // → "a" (1-ci indeks) console.log(metn[2]); // → "k" (2-ci indeks) console.log(metn[3]); // → "ı" (3-cü indeks) // Loop ilə hər hərfin indeksini çap et let soz = "Əlifba"; for (let i = 0; i < soz.length; i++) { console.log(i, "→", soz[i]); } // 0 → Ə // 1 → l // 2 → i ...və s.

Addım-addım izah

1
İndeks 0-dan başlayır — ilk hərf həmişə str[0]-dır, sona str[str.length-1] ilə çatırıq.
2
str[i] və str.charAt(i) eyni nəticəni verir. Müasir kodda [i] üstün tutulur.
3
Əgər i mövcud deyilsə: str[i] undefined, charAt(i) boş string qaytarır.
4
Azərbaycan hərfləri (ə, ı, ö, ü, ğ, ş, ç) bir simvol sayılır — [i] onları da düzgün oxuyur.
.indexOf() Mövqe tap → .includes() ilə mövcudluğu yoxla YENİ ▼

indexOf(axtarılan) — verdiyin simvol/söz harada başlayır? İndeks qaytarır. Tapılmasa -1 qaytarır. Azərbaycan hərfləri ilə də mükəmməl işləyir. İkinci arqument verib axtarışa müəyyən indeksdən başlamaq da olar: indexOf("a", 3).

Kod nümunəsi
let email = "tebrikler@gmail.com"; console.log(email.indexOf("@")); // → 10 console.log(email.indexOf("xyz")); // → -1 (tapılmadı) // -1 yoxlaması: if (email.indexOf("@") === -1) { console.log("@ işarəsi yoxdur!"); } // Azərbaycan hərfi ilə axtarış: let cumle = "Əlifba öyrənmək çox vacibdir"; console.log(cumle.indexOf("öyrənmək")); // → 8 // 2-ci arqument: 5-ci indeksdən axtar let s = "abcabc"; console.log(s.indexOf("a", 1)); // → 3 (ilkindən sonrakı "a") // includes() — sadəcə "var ya yox?" if (email.includes("@")) { console.log("Düzgün email ✓"); }

Addım-addım izah

1
indexOf indeks qaytarır — axtardığın şeyin string-in neçənci simvolundan başladığını göstərir.
2
Tapılmadıqda -1 qaytarır. Bu xüsusi dəyəri yoxlamaq mütləq vacibdir!
3
İkinci arqument (başlanğıc): indexOf("a", 3) — 3-cü indeksdən etibarən axtarır. Eyni simvolu dəfələrlə tapmaq üçün faydalıdır.
4
includes() sadəcə true/false qaytarır — yalnız var/yox bilmək lazımdırsa includes daha oxunaqlıdır.
.slice() String-dən hissə kəs → .substring() ▼

slice(başlanğıc, son) — string-in istədiyin hissəsini götürür. Son index daxil deyil! Mənfi index verəndə sondan saymağa başlayır. substring() oxşardır, amma mənfi index qəbul etmir.

Kod nümunəsi
let url = "https://example.com"; console.log(url.slice(8)); // → "example.com" console.log(url.slice(0, 5)); // → "https" console.log(url.slice(-3)); // → "com" console.log(url.substring(8,15)); // → "example"
.toLowerCase() / .toUpperCase() Böyük / kiçik hərfə çevir YENİ ▼

toLowerCase() hamısını kiçik, toUpperCase() hamısını böyük hərfə çevirir. Orijinal dəyişmir — yeni string qaytarılır. Azərbaycan xüsusi hərfləri: ə → Ə, ı → I, ö → Ö, ü → Ü, ğ → Ğ, ş → Ş, ç → Ç JavaScript tərəfindən avtomatik düzgün çevrilir.

Kod nümunəsi
let axtar = "JAVASCRIPT"; let melumat = "JavaScript öyrənmək maraqlıdır"; // Hər ikisini kiçiyə çevir, sonra müqayisə et if (melumat.toLowerCase().includes(axtar.toLowerCase())) { console.log("Tapıldı! ✓"); // → çap olunur } // toUpperCase — hamısını böyüt: let sehər = "bakı"; console.log(sehər.toUpperCase()); // → "BAKI" // Azərbaycan hərfləri ilə toUpperCase: let az = "əlifba, şəhər, çay, öyrən"; console.log(az.toUpperCase()); // → "ƏLİFBA, ŞƏHƏR, ÇAY, ÖYRƏN" // İlk hərfi böyüt (başlıq üçün): let kicik = "azərbaycan"; let baslig = kicik[0].toUpperCase() + kicik.slice(1); console.log(baslig); // → "Azərbaycan"

Addım-addım izah

1
toUpperCase() orijinal stringi dəyişmir — yeni string qaytarır. Həmişə yeni dəyişəndə yadda saxla.
2
Axtarış funksiyalarında mütləq lazımdır: "BAKI" da "baki" da eyni nəticəni versin deyə hər ikisini eyni case-ə çevirərik.
3
İlk hərfi böyütmək üçün trick: str[0].toUpperCase() + str.slice(1) — birinci hərfi böyüdüb, qalanını olduğu kimi yapışdırırıq.
4
Azərbaycan hərfləri — ə, ı, ö, ü, ğ, ş, ç — JavaScript-in Unicode dəstəyi sayəsində düzgün çevrilir.
.trim() Baş-axır boşluqları sil ▼

trim() — string-in əvvəlindəki və sonundakı boşluqları, tab və newline simvollarını silir. Ortadakı boşluqlara toxunmur. Form input-larından gələn məlumatı "təmizləmək" üçün demək olar həmişə lazım olur.

Kod nümunəsi
let input = " ali@mail.com "; console.log(input.trim()); // → "ali@mail.com" console.log(input.length); // → 18 (orijinal) console.log(input.trim().length); // → 12 (təmiz)
.split() String-i parçalayıb array-ə çevir ▼

split(ayırıcı) — verdiyin ayırıcı simvola görə string-i parçalayır, nəticəni array (siyahı) kimi qaytarır. Boş string "" verərsən hər hərfi ayrı element edir.

Kod nümunəsi
let csv = "Bakı,Gəncə,Sumqayıt"; let sehерler = csv.split(","); console.log(sehерler); // → ["Bakı", "Gəncə", "Sumqayıt"] let herfler = "salam".split(""); console.log(herfler); // → ["s","a","l","a","m"]
.splice() Array-dən element sil / əlavə et YENİ ▼

splice(başlanğıc, silinəcək, ...yenilər) — Array metodudur (string yox!). Verdiyin indeksdən etibarən istədiyin qədər element silir, istəsən yeni elementlər əlavə edir. Orijinal arrayi dəyişir (mutate edir) — bu fərqlidir! split() ilə qarışdırma: split string-i parçalayır, splice isə array-i dəyişdirir.

Kod nümunəsi
let sehərler = ["Bakı", "Gəncə", "Lənkəran", "Şuşa"]; // 1 element sil (indeks 1-dən, 1 ədəd): sehərler.splice(1, 1); console.log(sehərler); // → ["Bakı","Lənkəran","Şuşa"] // 0 sil, yeni element əlavə et (indeks 1-ə): sehərler.splice(1, 0, "Mingəçevir"); console.log(sehərler); // → ["Bakı","Mingəçevir","Lənkəran","Şuşa"] // 1 sil + 2 yeni əlavə et: sehərler.splice(2, 1, "Naxçıvan", "Quba"); console.log(sehərler); // → ["Bakı","Mingəçevir","Naxçıvan","Quba","Şuşa"] // splice sildiyi elementləri array kimi qaytarır: let silinən = sehərler.splice(0, 2); console.log(silinən); // → ["Bakı","Mingəçevir"]

Addım-addım izah

1
splice(başlanğıc, silinəcəkSay) — 1-ci arqument: haraddan başla, 2-ci: neçə element sil.
2
SilinəcəkSay 0 olarsa heç nə silinmir — yalnız yeni element əlavə edilir. Bu insert (yerə salmaq) əməliyyatıdır.
3
Mühüm: splice orijinal arrayi dəyişdirir! slice() isə orijinalı saxlayıb yeni array qaytarır. Bu fərqi unutma.
4
Sildiyi elementlər return dəyəri kimi qaytarılır — lazım gəlsə dəyişəndə yadda saxlaya bilərsən.
5
split vs splice: adları oxşardır amma tamam fərqlidir! split → string-i parçalayır, splice → array-i dəyişdirir.

Praktiki Tapşırıqlar

6 alqoritm — function yox, birbaşa kod + addım-addım izah

Qayda: Bütün həllərdə function açar sözü işlədilmir. Kod birbaşa icra olunur. reverse(), filter(), reduce() kimi hazır array metodları da yoxdur — hər şey təmiz for loop ilə qurulub.
1

Hərflərin Konsola Çıxarılması

String-in hər hərfini loop ilə ayrı-ayrı çap et

▼
let str = "Salam"; for (let i = 0; i < str.length; i++) { console.log(str[i]); // str[i] → i-ci hərfi götürür } // → S // → a // → l // → a // → m // Azərbaycan hərfləri ilə: let az = "Əlifba"; for (let i = 0; i < az.length; i++) { console.log(az[i]); // Ə, l, i, f, b, a }

Addım-addım izah

1
i = 0 — loop str[0] yəni "S" hərfini oxuyur, konsola çap edir.
2
i++ — i birər artır: 0 → 1 → 2 → 3 → 4. Hər dəfə növbəti hərfə keçir.
3
Şərt: i < str.length yəni i < 5. i = 5 olduqda şərt yalan olur, loop dayanır.
4
str[i] — kvadrat mötərizə notation-dır. Hər iterasiyada i-ci mövqedəki hərfi qaytarır.
2

String-i Tərsinə Çevirmək (Reverse)

Hazır metod yox — alqoritm ilə

▼
let str = "Bakı"; let netice = ""; for (let i = str.length - 1; i >= 0; i--) { netice += str[i]; // str[i] sondan əvvələ gedir } console.log(netice); // → "ıkaB"

Addım-addım izah

1
netice = "" — boş "səbət". Hərfləri buraya yığacağıq.
2
i = str.length - 1 — loop-u sondan başladırıq. "Bakı" üçün bu 3-dür (son index).
3
i-- — bu dəfə i azalır: 3 → 2 → 1 → 0. String-in sonundan əvvəlinə gedirik.
4
netice += str[i] — hər addımda tapılan hərfi sona yapışdırır. "ı"+"k"+"a"+"B" = "ıkaB".
5
Şərt: i >= 0. i mənfi olduqda dayanır — ilk hərfdən keçdikdən sonra.
3

Saitlərin Sayılması

a, e, i, o, u, ə, ı — neçə dənədir?

▼
let str = "Azərbaycan"; let saytac = 0; let saitler = "aeiouəıöü"; // Azərbaycan saitləri let kicik = str.toLowerCase(); for (let i = 0; i < kicik.length; i++) { if (saitler.includes(kicik[i])) { saytac++; } } console.log(saytac); // → 5

Addım-addım izah

1
saytac = 0 — sait tapdıqca artıracağıq. Bu counter (sayğac) pattern-i — çox tez-tez lazım olur.
2
toLowerCase() — "A" ilə "a" eyni sayılsın deyə hamısını kiçiyə çeviririk.
3
Loop hər addımda kicik[i] ilə bir hərf götürür. saitler.includes(kicik[i]) — o hərf sait siyahısındadırmı yoxlayır.
4
Şərt doğrudursa saytac++ — sayğac birər artır.
4

Alqoritm Bonusu — Faktorial

5! = 5 × 4 × 3 × 2 × 1 = 120

▼
let n = 5; let netice = 1; for (let i = 2; i <= n; i++) { netice *= i; // netice = netice * i } console.log(netice); // → 120 // n = 10 üçün: let n2 = 10; let netice2 = 1; for (let i = 2; i <= n2; i++) { netice2 *= i; } console.log(netice2); // → 3628800

Addım-addım izah

1
netice = 1 — nə üçün 0 deyil? İstənilən ədədi sıfıra vursaq sıfır çıxar. 1 neytral elementdir.
2
i = 2-dən başlayırıq, çünki 1-ə vurmaq nəticəni dəyişmir.
3
n=5 üçün: 1×2=2, 2×3=6, 6×4=24, 24×5=120. Hər addımda netice yenilənir.
4
i <= n — şərt n-i özü də daxil edir. Bu nöqtəni unutmaq çox ümumi xətadır!
5

Palindrom Yoxlanışı

"radar", "ana" — həm düz həm ters eyni oxunur?

▼
let str = "radar"; let kicik = str.toLowerCase(); let son = kicik.length - 1; let palindromMu = true; for (let i = 0; i < kicik.length / 2; i++) { if (kicik[i] !== kicik[son - i]) { palindromMu = false; break; // Fərq tapıldı, loopdan çıx } } console.log(palindromMu); // → true // "Əlifba" üçün yoxla: let str2 = "Əlifba"; let kicik2 = str2.toLowerCase(); let son2 = kicik2.length - 1; let palindromMu2 = true; for (let i = 0; i < kicik2.length / 2; i++) { if (kicik2[i] !== kicik2[son2 - i]) { palindromMu2 = false; break; } } console.log(palindromMu2); // → false

Addım-addım izah

1
palindromMu = true — əvvəlcədən "palindromdur" deyirik. Xəta tapdıqda false-a çeviririk.
2
son = length - 1 — son indeksi yadda saxlayırıq. son - i formulası hər addımda müvafiq arxadakı hərfin indeksini verir.
3
kicik[i] və kicik[son - i] — [i] notation ilə həm əvvəldən, həm sondan hərfləri müqayisə edirik.
4
i < length / 2 — yalnız ortaya qədər gedirik. "radar" üçün 2 müqayisə kifayətdir.
5
Uyğunsuzluq tapılanda break ilə loopdan çıxırıq — sona qədər gəzməyə ehtiyac yoxdur.
6

Ən Çox Təkrarlanan Hərf

Hansı hərf neçə dəfə var? Ən çoxu tap.

▼
let str = "aabbccca"; let say = {}; // Boş obyekt: {herf: neceDefeVar} // 1. Mərhələ: hər hərfi say for (let i = 0; i < str.length; i++) { let h = str[i]; // str[i] cari hərfi götürür if (say[h] === undefined) { say[h] = 1; // İlk dəfə görürük } else { say[h]++; // Artıq vardı, sayını artır } } // say indi: {a: 3, b: 2, c: 3} // 2. Mərhələ: ən böyük sayı tap let enCoxHerf = ""; let enCoxSay = 0; for (let herf in say) { if (say[herf] > enCoxSay) { enCoxSay = say[herf]; enCoxHerf = herf; } } console.log(enCoxHerf); // → "a" console.log(enCoxSay); // → 3

Addım-addım izah

1
İki mərhələli strategiya: əvvəl say, sonra ən böyüyü tap. Bu "frequency counter" pattern-i müsahibələrdə tez çıxır.
2
say = {} boş obyekt. Loop bitdikdə: {a:3, b:2, c:3} kimi görünəcək.
3
str[i] ilə cari hərfi götürürük. say[h] === undefined — o hərfi ilk dəfə görürüksə 1 veririk, əvvəlcədən vardısa say[h]++ ilə artırırıq.
4
İkinci loop: for...in ilə obyektin hər açarını (hərfini) gəzirik. Hər yoxlamada enCoxSay-dən böyük olarsa onu lider elan edirik.
