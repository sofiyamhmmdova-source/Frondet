DOM və Seçicilər

Brauzerdəki HTML elementlərini JavaScript ilə necə tapmaq, oxumaq və dəyişdirmək olar — izahdan praktikaya qədər addım-addım.

🌐
DOM nədir?
Document Object Model — Sənəd Obyekt Modeli

DOM (Document Object Model) — brauzer tərəfindən HTML səhifəsi yükləndikdə yaradılan bir obyekt ağacıdır. Bu ağac HTML-dəki hər elementi (teq, mətn, atribut) bir JavaScript obyekti kimi göstərir. JavaScript DOM vasitəsilə bu elementlərə müraciət edə, onları oxuya, dəyişdirə, silə və ya yeni elementlər əlavə edə bilər.

💡 Sadə Analoq

HTML sənədi xəritə, DOM isə həmin xəritənin canlı, dəyişdirilə bilən elektron versiyasıdır. JavaScript bu xəritənin üzərindəki ölkələri (elementlər) tapa, adlarını dəyişə, yenilərini əlavə edə bilər.

Brauzer HTML sənədini oxuyanda:

1

HTML oxunur

Brauzer <html>, <head>, <body> kimi teqləri sırayla oxuyur.

2

DOM ağacı qurulur

Hər teq — bir node (düyün)ə çevrilir. Nestlənmiş teqlər isə valideyn-övlad münasibətləri yaradır.

3

JavaScript müraciəti mümkün olur

İndi document obyekti vasitəsilə bütün elementlərə çata bilərik.

🌳
DOM Ağacı
HTML-dən JavaScript obyektinə

Bu sadə HTML kodu olduğunu düşünün:

HTML
<!DOCTYPE html>
<html>
  <head>
    <title>Mənim Səhifəm</title>
  </head>
  <body>
    <h1 id="bashliq">Salam Dünya</h1>
    <p class="aciqlamalar">Bu bir paraqrafdır.</p>
    <ul>
      <li>Element 1</li>
      <li>Element 2</li>
    </ul>
  </body>
</html>

Bu HTML-in DOM ağacı belə görünür:

DOM AĞACI (vizual)
document
  └── html
       ├── head
       │    └── title  ──▶  "Mənim Səhifəm"
       └── body
            ├── h1  [id="bashliq"]  ──▶  "Salam Dünya"
            ├── p   [class="aciqlamalar"]  ──▶  "Bu bir paraqrafdır."
            └── ul
                 ├── li  ──▶  "Element 1"
                 └── li  ──▶  "Element 2"

JavaScript-dəki document obyekti bu ağacın köküdür. Hər şeydən bu kökdən başlayırıq.

🏛️
Klassik Seçici Metodlar
getElementById, getElementsByClassName, getElementsByTagName

Bu metodlar JavaScript-in köhnə, lakin hələ də işlək olan üsullarıdır. Onları bilmək vacibdir — həm köhnə kodlarda görəcəksiniz, həm də müasir metodlarla fərqini anlamaq üçün.

1. getElementById()

HTML-dəki id atributuna görə tək element qaytarır. ID-lər unikal olduğu üçün bu metod həmişə ya 1 element, ya da null qaytarır.

JavaScript
// HTML: <h1 id="bashliq">Salam</h1>

const bashliq = document.getElementById("bashliq");

console.log(bashliq);
// → <h1 id="bashliq">Salam</h1>

console.log(bashliq.textContent);
// → "Salam"

// Mövcud olmayan ID-yə görə:
const yoxElement = document.getElementById("yoxdur");
console.log(yoxElement); // → null

2. getElementsByClassName()

Eyni sinifə (class) sahib olan bütün elementləri qaytarır. Nəticə canlı HTMLCollection — massivə bənzər, lakin massiv olmayan bir kolleksiyadır.

JavaScript
// HTML:
// <p class="aciq">Birinci</p>
// <p class="aciq">İkinci</p>
// <p class="aciq">Üçüncü</p>

const paraqraflar = document.getElementsByClassName("aciq");

console.log(paraqraflar.length); // → 3

// Index ilə müraciət
console.log(paraqraflar[0].textContent); // → "Birinci"

// Dövr ilə gəzmək
for (let i = 0; i < paraqraflar.length; i++) {
  console.log(paraqraflar[i].textContent);
}
⚠️ Xəbərdarlıq: HTMLCollection massiv deyil!

getElementsByClassName bir HTMLCollection qaytarır. Bu, massivin bəzi metodlarını (.forEach, .map) dəstəkləmir.

JavaScript
// ❌ YALNIŞDIR — HTMLCollection üzərində .forEach çalışmaz
paraqraflar.forEach(el => console.log(el));

// ✅ DOĞRUDUR — massivə çevirmək lazımdır
Array.from(paraqraflar).forEach(el => console.log(el));

3. getElementsByTagName()

Müəyyən teq adına sahib bütün elementləri qaytarır. Məsələn, bütün <li>-ləri, bütün <p>-ləri tapmaq üçün.

JavaScript
const butunLilar = document.getElementsByTagName("li");

console.log(butunLilar.length); // Neçə li varsa

// Bütün p teqlərini tap
const butunP = document.getElementsByTagName("p");

// Bütün elementləri tap ("*" joker simvoldur)
const hamisini = document.getElementsByTagName("*");
⚡
Müasir Seçici Metodlar
querySelector və querySelectorAll

Müasir JavaScript-in ən güclü seçiciləri — querySelector və querySelectorAll. Bu metodlar CSS seçicilərindən istifadə edir, yəni CSS-dəki hər şeyi (#id, .class, teq, atribut, nəvə seçicilər) JavaScript-də işlədə bilərsiniz.

1. querySelector()

CSS seçicinə uyğun ilk tapılan elementi qaytarır. Heç nə tapılmasa null qaytarır.

JavaScript
// ID-yə görə seçim (#)
const bashliq = document.querySelector("#bashliq");

// Sinfə görə seçim (.)
const ilkKart = document.querySelector(".kart");
// DIQQƏT: Yalnız İLK .kart elementi qaytarır!

// Teq adına görə seçim
const ilkP = document.querySelector("p");

// Atributa görə seçim
const emailSahesi = document.querySelector('input[type="email"]');

// Nəvə seçici (nested)
const navLinki = document.querySelector("nav ul li a");

// Birləşmiş seçici
const aktiv = document.querySelector(".menu .item.aktiv");

2. querySelectorAll()

CSS seçicinə uyğun bütün elementləri NodeList olaraq qaytarır. Fərqli olaraq NodeList .forEach() metodunu birbaşa dəstəkləyir!

JavaScript
// Bütün .kart elementlərini tap
const butunKartlar = document.querySelectorAll(".kart");

console.log(butunKartlar.length); // Elementlərin sayı

// ✅ NodeList forEach-i birbaşa dəstəkləyir
butunKartlar.forEach(function(kart) {
  console.log(kart.textContent);
});

// Arrow function ilə daha qısa yazılışı
butunKartlar.forEach(kart => console.log(kart.textContent));

// Bütün input[type="checkbox"] elementlərini tap
const checkboxlar = document.querySelectorAll('input[type="checkbox"]');

// :nth-child, :first-child kimi CSS pseudo-seçiciləri ilə
const tekSıraLilar = document.querySelectorAll("li:nth-child(odd)");
❌ ÇOX GENİŞ YAYILMIŞ XƏTA: CSS işarəsini unutmaq!

Bu, tələbələrin ən çox etdiyi səhvdir. querySelector CSS seçicisi istəyir — ID üçün #, sinif üçün . işarəsi MÜTLƏQ lazımdır!

JavaScript
// ❌ YANLIŞ — # işarəsi unudulub
document.querySelector("bashliq");
// Bu <bashliq> adlı HTML teqi axtarır, ID deyil → null qaytarır!

// ❌ YANLIŞ — . işarəsi unudulub
document.querySelector("kart");
// Bu <kart> adlı HTML teqi axtarır → null qaytarır!

// ✅ DOĞRU
document.querySelector("#bashliq");  // ID üçün #
document.querySelector(".kart");     // Sinif üçün .
document.querySelector("p");         // Teq üçün işarəsiz

Lakin performans kritik olduğu nadir hallarda getElementById() ən sürətlidir.

📖
DOM Məzmununu Oxumaq
textContent, innerHTML, innerText

Element tapdıqdan sonra onun məzmununu oxumaq üçün əsasən üç xassə var:

JavaScript
// HTML: <p id="nümunə"><b>Qalın</b> və adi mətn</p>

const el = document.getElementById("nümunə");

// textContent — bütün mətnlər (HTML olmadan)
console.log(el.textContent);
// → "Qalın və adi mətn"

// innerHTML — daxildəki tam HTML kodu
console.log(el.innerHTML);
// → "<b>Qalın</b> və adi mətn"

// innerText — yalnız görünən mətn (CSS-ə baxır)
console.log(el.innerText);
// → "Qalın və adi mətn" (display:none elementlər daxil edilmir)

⚠️ innerHTML ilə XSS Təhlükəsi

İstifadəçidən gələn məlumatı birbaşa innerHTML-ə vermək çox təhlükəlidir. Zərərli JavaScript kodu inyeksiya edilə bilər.

✅ Güvənli Alternativ

İstifadəçi mətnini textContent ilə yazın — HTML teqlərini avtomatik deaktiv edir, güvənlidir.

JavaScript
const userMelumat = '<img src=x onerror="alert(1)">';

// ❌ TEHLÜKƏLİ — XSS hücumuna açıqdır
element.innerHTML = userMelumat;

// ✅ GÜVƏNLİ — Mətn olaraq yazır, HTML kimi işlətmir
element.textContent = userMelumat;
// Nəticə: Literal olaraq <img src=x ...> mətnini göstərir
✏️
DOM Məzmununu Dəyişmək
Elementlər yaratmaq, əlavə etmək, silmək

Mövcud elementin məzmununu dəyişmək

JavaScript
const bashliq = document.querySelector("#bashliq");

// Mətn dəyişmək
bashliq.textContent = "Yeni Başlıq!";

// HTML əlavə etmək
bashliq.innerHTML = "<em>İtalik</em> Başlıq";

Yeni element yaratmaq və əlavə etmək

JavaScript
// 1. Yeni element yarat
const yeniLi = document.createElement("li");

// 2. Məzmun ver
yeniLi.textContent = "Yeni element";

// 3. Sinfini əlavə et (könüllü)
yeniLi.className = "siyahı-elementi";

// 4. Siyahıya əlavə et
const ul = document.querySelector("ul");
ul.appendChild(yeniLi); // sona əlavə edir

// İlk mövqeyə əlavə etmək üçün:
ul.prepend(yeniLi);

Element silmək

JavaScript
const silinecek = document.querySelector(".kohne");

// Müasir üsul
silinecek.remove();

// Köhnə üsul (IE dəstəyi lazım olduqda)
silinecek.parentNode.removeChild(silinecek);
🎨
Stil və Siniflər
CSS-i JavaScript ilə idarə etmək

classList — sinifləri idarə etmək (tövsiyə olunan)

JavaScript
const element = document.querySelector(".kart");

// Sinif əlavə et
element.classList.add("aktiv");

// Sinif sil
element.classList.remove("aktiv");

// Sinif var/yox dəyiş (toggle)
element.classList.toggle("gizli");
// "gizli" varsa silir, yoxsa əlavə edir

// Sinif var mı yoxla
if (element.classList.contains("aktiv")) {
  console.log("Element aktivdir");
}

// Birdən çox sinif əlavə et
element.classList.add("kart", "vurgulanmis", "gosterilen");

style xassəsi — birbaşa CSS yazmaq

JavaScript
const qutu = document.querySelector("#qutu");

// CSS xassəsi kebab-case deyil, camelCase yazılır!
qutu.style.backgroundColor = "mavi";   // background-color
qutu.style.fontSize        = "20px";    // font-size
qutu.style.display         = "none";    // gizlət
qutu.style.display         = "block";   // göstər
qutu.style.borderRadius    = "8px";     // border-radius
✅ Tövsiyə: classList vs style

Üslub dəyişiklikləri üçün birbaşa style yazmaq əvəzinə CSS siniflərini əvvəlcədən CSS-də yazın, sonra classList.add/remove/toggle ilə tətbiq edin. Bu, kod ayrılığını (separation of concerns) qoruyur.

🔧
Atributlar ilə İşləmək
getAttribute, setAttribute, removeAttribute
JavaScript
// HTML: <a id="link" href="https://google.com" target="_blank">...</a>
const link = document.querySelector("#link");

// Atribut oxu
console.log(link.getAttribute("href"));   // "https://google.com"

// Atribut dəyiş / əlavə et
link.setAttribute("href", "https://bing.com");

// Atribut var mı?
console.log(link.hasAttribute("target")); // true

// Atribut sil
link.removeAttribute("target");

// data-* atributları üçün dataset istifadə et
// HTML: <div data-user-id="42" data-rol="admin"></div>
const div = document.querySelector("div");
console.log(div.dataset.userId); // "42"  (data-user-id → userId)
console.log(div.dataset.rol);    // "admin"

Hadisə Dinləyiciləri
addEventListener ilə istifadəçi əmələrini tutmaq

Hadisələr (events) — klik, klaviatura basması, forma göndərilməsi kimi istifadəçi və ya brauzer hərəkətləridir. addEventListener bu hərəkətləri tutmağa imkan verir.

JavaScript — Əsas istifadə
const duyme = document.querySelector("#duyme");

// Sintaksis:
// element.addEventListener("hadisəAdı", callbackFunksiya)

duyme.addEventListener("click", function() {
  console.log("Düymə kliklənirldi!");
});

// Arrow function ilə daha qısa
duyme.addEventListener("click", () => {
  console.log("Klik!");
});

// event obyekti ilə
duyme.addEventListener("click", (e) => {
  console.log("Klikləndi:", e.target); // kliklənən element
  e.preventDefault(); // default davranışı ləğv et
});

// Hadisəni silmək üçün funksiyanı çölə çıxar
function klikHandler() {
  console.log("Klik!");
}
duyme.addEventListener("click", klikHandler);
duyme.removeEventListener("click", klikHandler); // sil

Kritik Xətalar — Bug Kitabçası
Tələbələrin ən çox düşdüyü tələlər

🐛 Xəta #1 — Null Xətası: Element yüklənməyib

Bu, ən geniş yayılmış xətadır. JavaScript kodu HTML elementlər yüklənməmişdən əvvəl işlədikdə baş verir.

❌ Xəta Mesajı

Cannot read properties of null (reading 'addEventListener')

və ya

Cannot set properties of null (setting 'textContent')

JavaScript
// ❌ PROBLEM: script <head>-dədir, <body> hələ yüklənməyib
const duyme = document.getElementById("duyme"); // null qaytarır!
duyme.addEventListener("click", () => {}); // 💥 XƏTA!

3 Həll Yolu:

JavaScript — Həll 1: Scripti body-nin sonuna qoy
<!-- HTML faylında </body>-dən əvvəl -->
<body>
  <button id="duyme">Klik</button>

  <script>
    // Artıq element yüklüdür ✅
    document.getElementById("duyme").addEventListener("click", () => {});
  </script>
</body>
JavaScript — Həll 2: DOMContentLoaded hadisəsi
document.addEventListener("DOMContentLoaded", () => {
  // DOM tam yükləndikdə çalışır ✅
  const duyme = document.getElementById("duyme");
  duyme.addEventListener("click", () => {});
});
JavaScript — Həll 3: defer atributu (müasir)
<!-- script <head>-dədir, amma defer ilə HTML yüklənəndən sonra çalışır -->
<script src="app.js" defer></script>

// app.js içi normal yazılır ✅
document.getElementById("duyme").addEventListener("click", () => {});

🐛 Xəta #2 — querySelector-da CSS İşarəsini Unutmaq

❌ Problem: querySelector null qaytarır

Bütün CSS işarələrini unutduqda metod null qaytarır. Sonrakı əməliyyatlar çökür.

JavaScript
// ❌ ID seçici — # unudulub
document.querySelector("bashliq");    // null!

// ❌ Sinif seçici — . unudulub
document.querySelector("kart");        // null!

// ✅ Düzgün istifadə
document.querySelector("#bashliq");  // ID üçün #
document.querySelector(".kart");     // Sinif üçün .
document.querySelector("p");         // Teq adı üçün işarəsiz
💡 Qızıl Qayda

querySelector/querySelectorAll istifadə edərkən həmişə özünüzə soruşun: "Bu CSS-dəki seçici kimi yazılacaqmı?" Əgər cavab bəlidirsə, CSS sintaksisini aynen kopiyalayın.

🐛 Xəta #3 — NodeList / HTMLCollection üzərində .forEach() çağırmaq

⚠️ Xəbərdarlıq: forEach dəstəyi

getElementsByClassName() və getElementsByTagName() HTMLCollection qaytarır — bu .forEach() dəstəkləmir!
querySelectorAll() isə NodeList qaytarır — bu .forEach()ni birbaşa dəstəkləyir.

JavaScript
// ❌ HTMLCollection üzərində forEach — XƏTA!
const lilar = document.getElementsByTagName("li");
lilar.forEach(el => console.log(el)); // 💥 TypeError!

// ✅ HƏLL 1: Array.from ilə dönüştür
Array.from(lilar).forEach(el => console.log(el));

// ✅ HƏLL 2: Spread operator ilə
[...lilar].forEach(el => console.log(el));

// ✅ HƏLL 3: querySelectorAll istifadə et (forEach dəstəkləyir)
document.querySelectorAll("li").forEach(el => console.log(el));

🐛 Xəta #4 — id adlarında boşluq istifadə etmək

❌ HTML ID-lərində boşluq olmaz!

ID-lər boşluqsuz olmalıdır. Boşluqlu ID JavaScript-in CSS seçicilərini qarışdırır.

HTML + JavaScript
<!-- ❌ YANLIŞ — ID-də boşluq -->
<div id="mənim div"></div>

// Bu boşluğu iki ayrı sinif kimi görür!
document.querySelector("#mənim div");
// → #mənim elementinin içindəki div axtarır — xəta!

<!-- ✅ DOĞRU — tire (-) və ya alt_xətt (_) istifadə et -->
<div id="mənim-div"></div>
document.querySelector("#mənim-div"); // ✅

🐛 Xəta #5 — Dövrsüz NodeList üzərindən əməliyyat

⚠️ Tələ: NodeList bir element kimi davranmır

querySelectorAll() heç vaxt tək element qaytarmır — hətta bir element tapsa belə NodeList qaytarır.

JavaScript
// ❌ YANLIŞ — NodeList-i birbaşa element kimi istifadə etmək
const kartlar = document.querySelectorAll(".kart");
kartlar.style.color = "qırmızı"; // 💥 NodeList.style yoxdur!

// ✅ DOĞRU — hər element üçün ayrıca tətbiq et
kartlar.forEach(kart => {
  kart.style.color = "qırmızı"; // ✅ Hər kart üçün
});

// ✅ Tək element istəyirsinizsə querySelector istifadə edin
const ilkKart = document.querySelector(".kart");
ilkKart.style.color = "qırmızı"; // ✅

JavaScript — Tam nümunə: Todo Siyahısı
// HTML strukturu:
// <input id="yeni-tapshiriq" placeholder="Tapşırıq daxil et">
// <button id="elave-et">Əlavə Et</button>
// <ul id="siyahi"></ul>

document.addEventListener("DOMContentLoaded", () => {
  const input    = document.querySelector("#yeni-tapshiriq");
  const duyme    = document.querySelector("#elave-et");
  const siyahi   = document.querySelector("#siyahi");

  function tapshiriqElave() {
    const metn = input.value.trim();
    if (!metn) return; // boş giriş

    // Yeni <li> yarat
    const li = document.createElement("li");
    li.textContent = metn;
    li.classList.add("tapshiriq");

    // Klik ilə tamamlandı/tamamlanmadı dəyiş
    li.addEventListener("click", () => {
      li.classList.toggle("tamamlandi");
    });

    // Sil düyməsi yarat
    const silDuyme = document.createElement("button");
    silDuyme.textContent = "🗑";
    silDuyme.addEventListener("click", (e) => {
      e.stopPropagation(); // li-nin klik hadisəsini durdur
      li.remove();
    });

    li.appendChild(silDuyme);
    siyahi.appendChild(li);
    input.value = ""; // input-u təmizlə
    input.focus(); // focusu geri ver
  }

  // Düymə kliki
  duyme.addEventListener("click", tapshiriqElave);

  // Enter düyməsi ilə də əlavə etmək
  input.addEventListener("keydown", (e) => {
    if (e.key === "Enter") tapshiriqElave();
  });
});
