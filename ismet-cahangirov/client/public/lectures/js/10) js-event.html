Bu dərslikdə JavaScript-in ən vacib mexanizmi olan hadisə dinləyiciləri haqqında hər şeyi öyrənəcəksiniz — sintaksisdən tutmuş qabaqcıl texnikalara qədər.

addEventListener() event.target preventDefault() stopPropagation()
Bölmə 1

Hadisə Nədir?

Brauzerdə istifadəçi hər hərəkət etdikdə — düyməyə basdıqda, siçanı hərəkət etdirdikdə, forma doldurduqda — bu hadisə (event) adlanır. JavaScript bu hadisələrə "qulaq asaraq" müvafiq kod icra edə bilər.

Fikirləşin ki, siz bir kafedəsiniz. Ofisiant sifarişinizi gözləyir (listen edir). Siz "qəhvə" dedikdə, o reaksiya verir (handler işləyir). Eynilə JavaScript-də: element hadisəni gözləyir, hadisə baş verdikdə funksiya işə düşür.

💡 Anlayış
Event — brauzerdə baş verən bir hal (klik, klaviatura basımı, yüklənmə və s.)
Event Listener — o hadisəni "gözləyən" dinləyici
Event Handler — hadisə baş verdikdə çağırılan funksiya

Hadisə Axışı

1

Element seçilir

DOM-dan element tapılır: document.getElementById('btn')

2

Listener əlavə edilir

addEventListener() ilə hadisə növü və handler qeydiyyata alınır.

3

Hadisə baş verir

İstifadəçi düyməyə basır — brauzer event obyekti yaradır.

4

Handler çağırılır

Qeydiyyata alınmış funksiya event obyekti ilə birlikdə çağırılır.

Bölmə 2

addEventListener() Sintaksisi

addEventListener() üç parametr qəbul edir. Birinci ikisi mütləqdir, üçüncüsü isteğe bağlıdır:

JavaScript — Sintaksis
element.addEventListener('hadisəNövu', handler, seçimlər);

// Parametrlərin izahı:
// 1) 'hadisəNövu'  → string: 'click', 'keydown', 'submit' və s.
// 2) handler       → çağırılacaq funksiya (event parametri ilə gəlir)
// 3) seçimlər     → { once, capture, passive } — isteğe bağlı

Müxtəlif İstifadə Üsulları

JavaScript
const btn = document.getElementById('myBtn');

// ── ÜsUL 1: Anonim funksiya (inline) ─────────────────────────
btn.addEventListener('click', function(event) {
  console.log('Klikləndi!');
});

// ── ÜSUL 2: Arrow funksiya ───────────────────────────────────
btn.addEventListener('click', (event) => {
  console.log('Arrow ilə klikləndi!');
});

// ── ÜSUL 3: Adlı funksiya (ən tövsiyə olunan!) ───────────────
function handleClick(event) {
  console.log('Adlı funksiya çağırıldı!');
}

btn.addEventListener('click', handleClick);  // ✓ Mötərizəsiz!

// ── ÜSUL 4: once — yalnız bir dəfə işlə ─────────────────────
btn.addEventListener('click', handleClick, { once: true });

// ── ÜSUL 5: passive — performans üçün (scroll) ───────────────
document.addEventListener('scroll', handleScroll, { passive: true });
⚠️ Tez-tez Edilən Səhv
btn.addEventListener('click', handleClick()) — bu YANLIŞ!
Mötərizə əlavə etsəniz, funksiya dərhal çağırılır və nəticəsi (adətən undefined) listener kimi qeyd olunur. Mötərizəsiz yazın: handleClick

Bölmə 4

Event Obyekti Nədir?

Hadisə baş verdikdə brauzer avtomatik olaraq Event obyekti yaradır və onu handler funksiyasına göndərir. Bu obyekt hadisə barədə bütün məlumatları saxlayır — kim kliklənib, hansı düymə basılıb, siçan haradadır və s.

JavaScript — Event obyektinə çatmaq
// Parametrə istənilən ad vermək olar (event, e, evt — hamısı eynidir)
btn.addEventListener('click', function(event) {
  console.log(event);          // Bütün Event obyekti
  console.log(event.type);     // "click"
  console.log(event.target);   // Kliklənən element
});

// Arrow funksiya ilə
btn.addEventListener('click', (e) => {
  console.log(e.clientX, e.clientY);  // Siçan koordinatları
});
💡 Qeyd
Handler funksiyasında parametr adı isteğe bağlıdır. event, e, evt — hamsı eyni işləyir. Ən geniş istifadə olunanı e-dir, ancaq kodun aydın olması üçün event da yaxşı seçimdir.
Bölmə 5

Event Obyektinin Propertilər

Bütün hadisə növlərinin ortaq propertilər var. Bundan əlavə, hər növün özünəməxsus propertilər var (məsələn, siçan hadisəsinin clientX/Y-si, klaviatura hadisəsinin key-i).

Ümumi (Universal) Propertilər

PropertyTipİzah & Nümunə
event.type string Hadisə növü: "click", "keydown", "submit" və s.
event.target Element Hadisəni birbaşa yaradan element. Klik edilən düymə, daxil olan input.
event.currentTarget Element Listener qeydiyyata alınmış element. this ilə eyni (arrow olmayan funksiyada).
event.timeStamp number Hadisənin baş verdiyi vaxt (millisaniyə, səhifənin açılmasından). Performance ölçmək üçün.
event.bubbles boolean Hadisə yuxarıya doğru yayılırmı? Çox hadisə üçün true.
event.cancelable boolean Hadisə ləğv edilə bilərmi? true olarsa preventDefault() işləyir.
event.defaultPrevented boolean Artıq preventDefault() çağırılıbsa true qaytarır.

Mouse Hadisəsinin Propertilər

Propertyİzah
e.clientX / e.clientYSiçanın viewport içindəki koordinatları (scroll nəzərə alınmır)
e.pageX / e.pageYSiçanın sənəd içindəki koordinatları (scroll nəzərə alınır)
e.offsetX / e.offsetYSiçanın target element içindəki koordinatları
e.screenX / e.screenYSiçanın ekrandakı mütləq koordinatları
e.buttonHansı düymə: 0=sol, 1=orta, 2=sağ
e.ctrlKey / e.shiftKey / e.altKey / e.metaKeyModifier düymələr basılıbmı? (boolean)
e.relatedTargetmouseover/mouseout-da əvvəlki/sonrakı element

Keyboard Hadisəsinin Propertilər

Propertyİzah
e.keyBasılan düymənin insan oxuna bilən dəyəri: "Enter", "a", "ArrowLeft"
e.codeFiziki düymə kodu (dil asılı olmayaraq): "KeyA", "Enter", "Space"
e.keyCodeRəqəmsal kod (köhnəlmiş! e.key istifadə edin)
e.repeatDüymə basılı tutulubsa true
e.ctrlKey / e.shiftKey / e.altKeyModifier düymələr basılıbmı?

// target vs currentTarget fərqi

div.addEventListener('click', (e) => {
  console.log(e.target);         // Faktiki kliklənən uşaq element
  console.log(e.currentTarget);  // .parent elementi (listener buradadır)
});

// Modifier düymə yoxlaması
document.addEventListener('keydown', (e) => {
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();
    console.log('Ctrl+S saxlama əmri!');
  }
});

// Siçan koordinatları

  console.log(`Klik: X=${e.clientX}, Y=${e.clientY}`);
});

Bölmə 6

Event Obyektinin Metodları

preventDefault() — Standart Davranışı Bloklama

Bəzi elementlərin standart davranışı var: link tıklandıqda keçid edir, form göndərildikdə səhifə yenilənir. preventDefault() bunu dayandırır.

JavaScript
// 1. Link keçidini bloklama
const link = document.querySelector('a');
link.addEventListener('click', (e) => {
  e.preventDefault();  // Səhifə keçməz
  console.log('Link bloklandı!');
});

// 2. Form göndərməni bloklama (validasiya üçün)
const form = document.querySelector('form');
form.addEventListener('submit', (e) => {
  e.preventDefault();
  // Manual validasiya yoxla...
  const ad = document.getElementById('ad').value;
  if (ad === '') {
    console.log('Ad boş ola bilməz!');
    return;
  }
  // Əl ilə göndər
  form.submit();
});

// 3. Sağ klik menyusunu bloklama
document.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  // Öz menyunuzu göstərin
});

stopPropagation() — Yayılmanı Dayandırma

Hadisə yayılandıqda (bubble) ana elementlərin listener-ləri də işləyir. stopPropagation() bunu dayandırır.

JavaScript
const ana = document.querySelector('.ana');
const usaq = document.querySelector('.usaq');

ana.addEventListener('click', () => console.log('Ana klikləndi'));

usaq.addEventListener('click', (e) => {
  e.stopPropagation();  // Ana elementə çatmayacaq
  console.log('Yalnız uşaq klikləndi');
});

// stopImmediatePropagation() — eyni elementdəki
// digər listener-ları da dayandırır
btn.addEventListener('click', fn1);
btn.addEventListener('click', (e) => {
  e.stopImmediatePropagation();  // fn1 artıq işləməyəcək
});

composedPath() — Hadisə Yolu

JavaScript
document.addEventListener('click', (e) => {
  // Hadisənin keçdiyi bütün elementlər
  const yol = e.composedPath();
  console.log(yol);
  // [button, div, main, body, html, document, window]
});

Bölmə 11

Bubbling & Capturing

Hadisə baş verdikdə üç mərhələdən keçir:

1

Capturing (Tutma) Mərhələsi

Hadisə window-dan başlayaraq hədəf elementə doğru aşağı enir. { capture: true } ilə tutulur.

2

Target Mərhələsi

Hadisə birbaşa hədəf elementə çatır. Həm capturing, həm bubbling listener-ları işləyir.

3

Bubbling (Qabarcıq) Mərhələsi

Hadisə hədəf elementdən yuxarı qalxır: parent → grandparent → ... → document → window.

JavaScript — Bubbling & Capturing
// Standart: Bubbling (capture: false) — hər zaman belə işləyir
document.addEventListener('click', handler);
document.addEventListener('click', handler, false);

// Capturing — nadiren istifadə olunur
document.addEventListener('click', handler, true);
document.addEventListener('click', handler, { capture: true });

// Nümunə: iç elementə klik, xaricə çatmasın
const modal = document.querySelector('.modal');
const modalContent = document.querySelector('.modal-content');

modal.addEventListener('click', () => modal.close());

modalContent.addEventListener('click', (e) => {
  e.stopPropagation();  // Modal bağlanmasın
});

Event Delegation

Event Delegation — hər uşaq elementə ayrı-ayrı listener əlavə etmək əvəzinə, ana elementə tək listener qoymaq texnikasıdır. Bubbling mexanizminə əsaslanır.

❌ Pis — Hər elementə ayrı listener
// 100 düymə üçün 100 listener!
const duymeler =
  document.querySelectorAll('.item');

duymeler.forEach(d => {
  d.addEventListener('click', fn);
});
// Dinamik əlavə olunan yeni
// elementlər işləmir!
✅ Yaxşı — Delegation
// Yalnız 1 listener — ana elementdə
const lista =
  document.querySelector('#lista');

lista.addEventListener('click', (e) => {
  if (e.target.matches('.item')) {
    işlə(e.target);
  }
});
// Dinamik elementlər avtomatik işləyir!
JavaScript — Real Event Delegation Nümunəsi
// Tapşırıq siyahısı — dinamik əlavə olunan elementlər
const tapşırıqlar = document.querySelector('#tapşırıqlar');

tapşırıqlar.addEventListener('click', (e) => {
  // Sil düyməsinə klikləndimi?
  if (e.target.matches('.sil-btn')) {

    return;

  // Tamamlandı checkbox-ınamı?
  if (e.target.matches('.tamamlandi')) {

  console.log('Tapşırıq ID:', id);

    Bölmə 13

    Event Listener Silmə

    JavaScript — removeEventListener
    // ── Düzgün silmə üsulu ───────────────────────────────────────
function handler(e) {
  console.log('Klik!');
}

btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);  // ✓ Eyni referans!

// ── YANLIŞ — Anonim funksiya silinə bilməz ───────────────────
btn.addEventListener('click', () => console.log('A'));
btn.removeEventListener('click', () => console.log('A'));
// ↑ Bu işləmir! Hər () => {} yeni funksiya obyektidir.

// ── AbortController ilə silmə (modern üsul) ──────────────────
const controller = new AbortController();

btn.addEventListener('click', handler, {
  signal: controller.signal
});

// Sonra bir əmrlə bütün qeydiyyatları sil:
controller.abort();

// ── once: true — Özü özünü silir ────────────────────────────
btn.addEventListener('click', handler, { once: true });
// İlk klikdən sonra avtomatik silinir
    🔴 Yaddaş Sızması (Memory Leak)
    Silinməyən listener-lər yaddaş sızmasına səbəb ola bilər, xüsusən dinamik olaraq yaradılan elementlər üçün. Komponent/modul məhv olduqda mutləq removeEventListener() çağırın. AbortController istifadəsi çox səmərəlidir.

    Tez-tez Edilən Xətalar & Buglar

    ❌ Xəta 1 — Funksiyaya mötərizə əlavə etmək

    Yanlış
    btn.addEventListener('click', handleClick());
// handleClick() dərhal işlər!
// undefined listener olur.
    Düzgün
    btn.addEventListener('click', handleClick);
// Yalnız referans göndərilir.
// Klik zamanı çağırılır. ✓

    ❌ Xəta 2 — DOM hazır olmamış işə başlamaq

    Yanlış — <head>-də
    <!-- head-də JS -->
const btn = document
  .getElementById('btn');
// btn null-dur! DOM yüklənməyib
btn.addEventListener(...)
// TypeError: null
    Düzgün
    document.addEventListener(
  'DOMContentLoaded', () => {
    const btn = document
      .getElementById('btn');
    btn.addEventListener(...);
  }
); // və ya script defer

    ❌ Xəta 3 — Arrow funksiyada this

    JavaScript
    // Arrow funksiyada 'this' elementi göstərmir!
btn.addEventListener('click', () => {
  console.log(this);  // window (və ya undefined strict modda)
});

// Adi funksiyada 'this' elementi göstərir ✓
btn.addEventListener('click', function() {
  console.log(this);  // <button> elementi
});

// Alternativ: event.currentTarget həmişə işləyir
btn.addEventListener('click', (e) => {
  console.log(e.currentTarget);  // Həmişə <button> ✓
});

    ❌ Xəta 4 — Döngüdə Listener əlavə etmək

    JavaScript
    // Yanlış — var ilə closure problemi
for (var i = 0; i < 3; i++) {
  btn[i].addEventListener('click', function() {
    console.log(i);  // Həmişə 3 çıxar!
  });
}

// Düzgün — let ilə blok scope
for (let i = 0; i < 3; i++) {
  btn[i].addEventListener('click', function() {
    console.log(i);  // 0, 1, 2 ✓
  });
}

// Ən yaxşı — Event Delegation istifadə et
ana.addEventListener('click', (e) => {
  if (e.target.matches('.btn'))
    console.log(e.target.dataset.index);
});

    ❌ Xəta 5 — mousemove-da ağır əməliyyatlar

    JavaScript — Throttle / Debounce
    // mousemove saniyədə yüzlərlə tetiklənir!
// Ağır DOM dəyişiklikləri performansı öldürür.
// requestAnimationFrame ilə optimallaşdır:

let ticking = false;

document.addEventListener('mousemove', (e) => {
  if (!ticking) {
    window.requestAnimationFrame(() => {
      yeniləElementi(e.clientX, e.clientY);
      ticking = false;
    });
    ticking = true;
  }
});

// scroll üçün passive: true istifadə et
window.addEventListener('scroll', handler, {
  passive: true  // preventDefault() çağırılmayacaq deməkdir
});
    ✅ Xülasə — Qaydalar
    1. Handler-i mötərizəsiz verin: handleClick ✓, handleClick() ✗
    2. DOM-a DOMContentLoaded-dən sonra müraciət edin
    3. this lazımsa adi funksiya, əks halda e.currentTarget
    4. Döngüdə var əvəzinə let istifadə edin
    5. Anonim funksiya listener-ı silinə bilmir — adlı funksiya istifadə edin
    6. mousemove/scroll-da ağır əməliyyat etməyin — requestAnimationFrame istifadə edin
    7. e.keyCode köhnəlmiş — e.key istifadə edin
