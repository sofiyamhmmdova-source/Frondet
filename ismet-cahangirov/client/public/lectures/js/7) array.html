Bölmə 01

1. Array (Massiv) nədir?

Array — bir dəyişkən içərisində bir neçə dəyəri eyni anda saxlaya biləcəyin qutu kimidir. Məsələn, 30 tələbənin adını ayrı-ayrı dəyişkənlərə yazmaq əvəzinə, hamısını bir array-da saxlaya bilərsən.

🗃️ Real Həyatdan Nümunə

Düşün ki, bir siyahı dəftərin var. Hər sətirə bir şey yazırsan: alma, armud, üzüm... Array tam olaraq budur — yaddaşda ardıcıl yerləşdirilmiş dəyərlər siyahısı.

array-neye-oxsayir.js 
// Array olmadan — çox uzun, çox çətin:
let tələbə1 = "Aytən";
let tələbə2 = "Bəhruz";
let tələbə3 = "Camal";
// 30 tələbə üçün 30 dəyişkən? 😰

// Array ilə — asan, qısa, rahat:
let tələbələr = ["Aytən", "Bəhruz", "Camal", "Damla"];
// Hamısı bir yerdə! ✅

💡 Array-in xüsusiyyətləri

✔ Fərqli tip dəyərlər (string, number, boolean, başqa array) saxlaya bilər
✔ Ölçüsü dinamikdir — istənilən vaxt böyüyüb kiçilə bilər
✔ Hər elementə sıra nömrəsi ilə (indeks) müraciət edilir
✔ JavaScript-də array-lər obyekt tipindədir

qarisiq-array.js 
// Array içinə hər cür dəyər qoya bilərsən:
let qarışıq = [
  "Salam",        // string
  42,             // number
  true,           // boolean
  null,           // null
  [1, 2, 3]       // başqa array (iç-içə)
];

console.log(qarışıq);
// ▶ ["Salam", 42, true, null, [1,2,3]]
Bölmə 02

2. Array Necə Yaradılır?

Array yaratmağın bir neçə üsulu var. Ən çox istifadə olunanı kvadrat mötərizə [] ilə yazmaq üsuludur.

yaratmaq.js 
// ✅ Üsul 1 — Literal sintaksis (tövsiyə olunur):
let meyvələr = ["alma", "armud", "üzüm"];

// ✅ Üsul 2 — Boş array (sonradan element əlavə etmək üçün):
let boşSiyahı = [];

// ✅ Üsul 3 — new Array() konstruktoru:
let rəqəmlər = new Array(1, 2, 3, 4, 5);

// ⚠️ DİQQƏT! new Array(5) — 5 elementli array DEYİL:
let yanılma = new Array(5);
console.log(yanılma);    // ▶ [ <5 empty items> ] ← boş yuva!
console.log(yanılma.length); // ▶ 5  (amma içi boş)

// ✅ Array.of() — new Array()'nin qarışıqlığını aradan qaldırır:
let düzgün = Array.of(5);
console.log(düzgün);      // ▶ [5]  ✅ bir elementli array
⚠️ Tələ! new Array(5) yazdıqda JavaScript 5 element olan array DEYIL, ölçüsü 5 olan boş array yaradır. Bu çox geniş yayılmış səhvdir. Həmişə literal sintaksisdən [] istifadə et.

📏 Array uzunluğu — .length

Hər array-in .length xassəsi var. Bu, array-dəki elementlərın sayını verir. İndekslərlə fərqini anlamaq vacibdir:

length.js 
let rənglər = ["qırmızı", "yaşıl", "mavi"];

console.log(rənglər.length); // ▶ 3  (3 element var)

// Son elementin indeksi həmişə length-1 olur:
console.log(rənglər[rənglər.length - 1]); // ▶ "mavi"

// length dəyərini dəyişmək olar — amma diqqətli ol:
rənglər.length = 1;
console.log(rənglər); // ▶ ["qırmızı"]  ← digərləri silindi!
Bölmə 03

3. İndeks — Elementlərə Müraciət

Array-in hər elementinin bir indeks nömrəsi var. Ən vacib məqam: indekslər 0-dan başlayır, 1-dən deyil!

indeks.js 
let şəhərlər = ["Bakı", "Gəncə", "Sumqayıt", "Lənkəran"];
//                  ↑         ↑          ↑           ↑
//               indeks:0   indeks:1   indeks:2    indeks:3

console.log(şəhərlər[0]); // ▶ "Bakı"     ← birinci element
console.log(şəhərlər[2]); // ▶ "Sumqayıt"
console.log(şəhərlər[9]); // ▶ undefined  ← yoxdur, xəta deyil!

// Elementi dəyişmək:
şəhərlər[1] = "Mingəçevir";
console.log(şəhərlər); // ▶ ["Bakı","Mingəçevir","Sumqayıt","Lənkəran"]

// Yeni element əlavə etmək:
şəhərlər[4] = "Şirvan";
console.log(şəhərlər.length); // ▶ 5
⚠️ Klassik Səhv: Çox tələbə şəhərlər[1] yazdıqda "birinci şəhər"i gözləyir, amma cavab "Gəncə" olur. Çünki indekslər 0-dan başlayır! Birinci elementə [0] ilə müraciət edilir.
at-metodu.js 
let rəqəmlər = [10, 20, 30, 40, 50];

// .at() metodu — mənfi indekslərə icazə verir:
console.log(rəqəmlər.at(0));   // ▶ 10  (birinci)
console.log(rəqəmlər.at(-1));  // ▶ 50  (sonuncu)  ← çox rahat!
console.log(rəqəmlər.at(-2));  // ▶ 40  (sondan ikinci)

// Köhnə üsulla sonuncu elementi almaq:
console.log(rəqəmlər[rəqəmlər.length - 1]); // ▶ 50 (daha uzun)
💡 Məsləhət: Sonuncu elementi almaq üçün köhnə üsul arr[arr.length-1] yerinə arr.at(-1) yazsan daha qısa və oxunaqlı olur. Bu modern JavaScript-dir.
Bölmə 04

4. Əsas Metodlar — Əlavə et, Sil, Kəs

Bu metodlar array-i birbaşa dəyişdirir (mutasiya edir). Onları öyrəndikdən sonra array-i istədiyin kimi idarə edə bilərsən.

📌 push() — Sona element əlavə et

Array-in sonuna bir və ya bir neçə element əlavə edir. Yeni length dəyərini qaytarır.

push.js 
let sepet = ["alma", "armud"];

sepet.push("üzüm");
console.log(sepet); // ▶ ["alma","armud","üzüm"]

// Bir neçəsini birlikdə əlavə edə bilərsən:
sepet.push("kivi", "ananas");
console.log(sepet);
// ▶ ["alma","armud","üzüm","kivi","ananas"]

// push() yeni uzunluğu qaytarır:
let yeniUzunluq = sepet.push("portağal");
console.log(yeniUzunluq); // ▶ 6
📌 pop() — Sondan element sil

Array-in son elementini çıxarıb qaytarır. Array kiçilir.

pop.js 
let növbə = ["Əli", "Vəli", "Anar"];

let çıxan = növbə.pop();
console.log(çıxan);  // ▶ "Anar"  (çıxarılan)
console.log(növbə);  // ▶ ["Əli","Vəli"]

// Boş array-dən pop() çağırsan:
let boş = [];
console.log(boş.pop()); // ▶ undefined (xəta vermir)
📌 unshift() — Əvvələ element əlavə et

Array-in əvvəlinə element əlavə edir. Qalan elementlər sağa sürüşür.

unshift.js 
let sıra = ["B", "C", "D"];

sıra.unshift("A");
console.log(sıra); // ▶ ["A","B","C","D"]

// Bir neçə element:
sıra.unshift("-1", "0");
console.log(sıra); // ▶ ["-1","0","A","B","C","D"]
⚠️ Performans: unshift() bütün elementlərin indekslərini dəyişdirdiyi üçün böyük array-lərdə push()-a nisbətən yavaş işləyir.
📌 shift() — Əvvəldən element sil

Array-in ilk elementini çıxarıb qaytarır. Qalan elementlər sola sürüşür.

shift.js 
let növbə = ["Birinci", "İkinci", "Üçüncü"];

let xidmətEdildi = növbə.shift();
console.log(xidmətEdildi); // ▶ "Birinci"
console.log(növbə);        // ▶ ["İkinci","Üçüncü"]
📌 splice() — Ortadan əlavə et / sil

splice(başlanğıc, silinəcəkSayı, ...əlavəEdilənlər) — Array-in istənilən yerindən element sil, əlavə et, və ya əvəzlə. Silinen elementləri qaytarır.

splice.js 
let aylar = ["Yan", "Fev", "Aprel", "May"];
//              0      1       2          3
// Mart-ı 2-ci indeksə əlavə etmək (heç nə silmədən):
aylar.splice(2, 0, "Mart");
console.log(aylar);
// ▶ ["Yan","Fev","Mart","Aprel","May"]  ✅

// 2-ci indeksdən 2 element silmək:
let siliənlər = aylar.splice(2, 2);
console.log(siliənlər); // ▶ ["Mart","Aprel"]
console.log(aylar);     // ▶ ["Yan","Fev","May"]

// Əvəzlə — 1 elementi başqası ilə:
aylar.splice(0, 1, "Yanvar");
console.log(aylar); // ▶ ["Yanvar","Fev","May"]
💡 Yadda saxla: splice(başlanğıc, 0, x) → heç nə silmə, sadəcə əlavə et.
splice(başlanğıc, n) → n ədəd element sil, heç nə əlavə etmə.
📌 concat() — İki array-i birləşdir

İki və ya daha çox array-i birləşdirir. Orijinalları dəyişdirmir — yeni array qaytarır.

concat.js 
let qızlar  = ["Aytən", "Damla"];
let oğlanlar = ["Bəhruz", "Camal"];

let hamısı = qızlar.concat(oğlanlar);
console.log(hamısı);
// ▶ ["Aytən","Damla","Bəhruz","Camal"]

// Orijinallar dəyişmir:
console.log(qızlar); // ▶ ["Aytən","Damla"]  ✅ eyni

// Spread operatoru ilə eyni iş (modern üsul):
let birlikdə = [...qızlar, ...oğlanlar];
console.log(birlikdə);
// ▶ ["Aytən","Damla","Bəhruz","Camal"]
📌 slice() — Parça kəs (kopyala)

slice(başlanğıc, son) — Array-in bir hissəsini kopyalayıb yeni array qaytarır. Orijinalı dəyişdirmir.
Son indeks daxil edilmir!

slice.js 
let hərflər = ["A", "B", "C", "D", "E"];
//              0    1    2    3    4

console.log(hərflər.slice(1, 3)); // ▶ ["B","C"]  (1 və 2, 3 yox!)
console.log(hərflər.slice(2));    // ▶ ["C","D","E"] (2-dən sona)
console.log(hərflər.slice(-2));   // ▶ ["D","E"]  (sondan 2)
console.log(hərflər.slice());     // ▶ ["A","B","C","D","E"] (tam kopyası)

// Orijinal dəyişmədi:
console.log(hərflər); // ▶ ["A","B","C","D","E"] ✅
⚠️ splice vs slice: Adları çox oxşardır amma tamamilə fərqlidir!
• splice() → orijinalı dəyişdirir, silir/əlavə edir
• slice() → orijinalı dəyişdirmir, kopyalayır
Bölmə 05

5. Axtarış Metodları

Array içindəki elementləri tapmaq, yoxlamaq üçün bu metodlardan istifadə edirlər.

axtarish.js 
let rəqəmlər = [10, 25, 30, 25, 50];

// indexOf() — ilk tapılan indeksi ver, yoxdursa -1 qaytarır:
console.log(rəqəmlər.indexOf(25));     // ▶ 1
console.log(rəqəmlər.indexOf(99));     // ▶ -1 (yoxdur)

// lastIndexOf() — sondan axtarır:
console.log(rəqəmlər.lastIndexOf(25));  // ▶ 3

// includes() — var ya yox? true/false:
console.log(rəqəmlər.includes(30));    // ▶ true
console.log(rəqəmlər.includes(100));   // ▶ false

let tələbələr = [
  { ad: "Aytən", qiymət: 85 },
  { ad: "Bəhruz", qiymət: 92 },
  { ad: "Camal", qiymət: 74 }
];

// find() — şərtə uyan İLK elementi qaytarır:
let yüksək = tələbələr.find(t => t.qiymət > 90);
console.log(yüksək); // ▶ {ad:"Bəhruz", qiymət:92}

// findIndex() — şərtə uyan ilk elementin İNDEKSİ:
let idx = tələbələr.findIndex(t => t.qiymət > 90);
console.log(idx); // ▶ 1

// some() — heç olmasa BİRİ uyan var mı? true/false:
console.log(tələbələr.some(t => t.qiymət >= 80)); // ▶ true

// every() — HAMISI şərtə uyur mu? true/false:
console.log(tələbələr.every(t => t.qiymət >= 60)); // ▶ true
console.log(tələbələr.every(t => t.qiymət >= 80)); // ▶ false
💡 Fərq: indexOf() sadə dəyərləri (string, number) axtarır. Obyektlər üçün find() / findIndex() işlənməlidir, çünki indexOf({...}) həmişə -1 qaytarar (obyektlər istinad ilə müqayisə edilir).
Bölmə 06

6. Çevirici Metodlar — map, filter, reduce

Bu üç metod funksional proqramlaşdırmanın əsasını təşkil edir. Hamısı yeni array qaytarır (orijinalı dəyişdirmir) — reduce istisnasıdır.

🗺️ map() — Hər elementi çevir

Hər elementə bir funksiya tətbiq edib eyni uzunluqda yeni array yaradır. Məsələn: hər qiyməti 2 dəfə artır.

map.js 
let qiymətlər = [60, 75, 80, 90];

// Hər qiyməti 10% artır:
let artırılmış = qiymətlər.map(q => q * 1.1);
console.log(artırılmış);
// ▶ [66, 82.5, 88, 99]

let tələbələr = [
  { ad: "Aytən", qiymət: 85 },
  { ad: "Bəhruz", qiymət: 92 }
];

// Sadəcə adları al:
let adlar = tələbələr.map(t => t.ad);
console.log(adlar); // ▶ ["Aytən","Bəhruz"]

// map() orijinalı DƏYİŞDİRMİR:
console.log(qiymətlər); // ▶ [60,75,80,90] ✅ eyni

🔍 filter() — Şərtə uyanları seç

Şərtə uyan elementləri götürüb yeni array qaytarır. Uymayanlar nəticəyə daxil edilmir.

filter.js 
let rəqəmlər = [1, 2, 3, 4, 5, 6, 7, 8];

// Cüt rəqəmləri seç:
let cütlər = rəqəmlər.filter(r => r % 2 === 0);
console.log(cütlər); // ▶ [2,4,6,8]

let məhsullar = [
  { ad: "Telefon", qiymət: 450 },
  { ad: "Çanta",   qiymət: 80  },
  { ad: "Laptop",  qiymət: 1200},
  { ad: "Kitab",   qiymət: 15  }
];

// 100 manatdan bahalı məhsullar:
let bahalılar = məhsullar.filter(m => m.qiymət > 100);
console.log(bahalılar);
// ▶ [{ad:"Telefon",qiymət:450}, {ad:"Laptop",qiymət:1200}]

♻️ reduce() — Hamısını bir dəyərə yığ

Array-in bütün elementlərini istifadə edərək tək bir dəyər qaytarır. Cəm, məhsul, ən böyük dəyər, obyekt qurma və s. üçün istifadə olunur.

reduce.js 
let qiymətlər = [100, 200, 50, 75];

// Cəm hesabla:
let cəm = qiymətlər.reduce((toplam, cari) => toplam + cari, 0);
console.log(cəm); // ▶ 425
//                      ↑         ↑           ↑            ↑
//                  yığıcı    cari dəyər   nəticə        başlanğıc

// Maksimum tapma:
let max = qiymətlər.reduce((en_böyük, cari) =>
  cari > en_böyük ? cari : en_böyük
);
console.log(max); // ▶ 200

// Sözlərin sayını hesabla:
let meyvələr = ["alma", "armud", "alma", "üzüm", "alma"];
let say = meyvələr.reduce((obj, m) => {
  obj[m] = (obj[m] || 0) + 1;
  return obj;
}, {});
console.log(say); // ▶ {alma: 3, armud: 1, üzüm: 1}
⚠️ reduce-da başlanğıc dəyəri unutma! reduce(fn, 0)-dakı 0 — başlanğıc dəyərdir. Onu yazmassan, boş array-dən reduce() çağıranda xəta alacaqsan: TypeError: Reduce of empty array with no initial value
Bölmə 07

7. Dövrə Metodları

Array elementlərinin üzərindən keçmək üçün bir neçə üsul var. Hansını seçmək istədiyinə görə:

dovre.js 
let şəhərlər = ["Bakı", "Gəncə", "Sumqayıt"];

// ── 1) forEach() — hərdəfərəki element üçün iş gör:
şəhərlər.forEach((şəhər, indeks) => {
  console.log(indeks + ": " + şəhər);
});
// ▶ 0: Bakı
// ▶ 1: Gəncə
// ▶ 2: Sumqayıt

// ── 2) for...of — ən sadə dövrə (indeks lazım deyilsə):
for (let şəhər of şəhərlər) {
  console.log(şəhər);
}

// ── 3) Klassik for dövrəsi — indeks lazımdırsa:
for (let i = 0; i < şəhərlər.length; i++) {
  console.log(i, şəhərlər[i]);
}

// ── 4) flatMap() — map + düzləşdir:
let cümlələr = ["Salam dünya", "Necəsən"];
let sözlər   = cümlələr.flatMap(c => c.split(" "));
console.log(sözlər);
// ▶ ["Salam","dünya","Necəsən"]
⚠️ forEach-dən return işləmir! forEach içinə return yazsan o funksiyadan çıxır, amma dövrəni DAYANDIRMIR. Dövrəni erkən bitirmək lazımdırsa for...of + break istifadə et.
forEach-return-bug.js 
let arr = [1, 2, 3, 4, 5];

// ❌ BUG — dövrə dayanmır:
arr.forEach(n => {
  if (n === 3) return; // bu SADƏCƏ callback-dan çıxır
  console.log(n);   // 4 və 5 yenə çap olunur!
});
// ▶ 1, 2, 4, 5  ← 3 çap olunmadı amma dövrə getdi

// ✅ DÜZGÜN — for...of ilə break:
for (let n of arr) {
  if (n === 3) break;
  console.log(n);
}
// ▶ 1, 2  ← 3-dən sonra dayandı ✅
Bölmə 08

8. Sıralama, Birləşdirmə, Digər Faydalı Metodlar

Array-i sıralamaq, mətne çevirmək, düzləşdirmək üçün bu metodlar çox işə yarayır.

sort-join-flat.js 
// ───────── sort() ─────────
let adlar = ["Camal", "Aytən", "Bəhruz"];
adlar.sort();
console.log(adlar); // ▶ ["Aytən","Bəhruz","Camal"]  (əlifba)

let rəqəmlər = [10, 2, 100, 21];

// ⚠️ TƏLƏ — sort() rəqəmləri STRING kimi sıralayır:
rəqəmlər.sort();
console.log(rəqəmlər); // ▶ [10,100,2,21] ❌ YANLIŞ!

// ✅ Düzgün rəqəm sıralaması:
rəqəmlər.sort((a, b) => a - b);
console.log(rəqəmlər); // ▶ [2,10,21,100] ✅

// Azalana görə:
rəqəmlər.sort((a, b) => b - a);
console.log(rəqəmlər); // ▶ [100,21,10,2]

// ───────── reverse() ─────────
let sıra = [1, 2, 3, 4, 5];
sıra.reverse();
console.log(sıra); // ▶ [5,4,3,2,1]  ← orijinalı dəyişdirir!

// ───────── join() ─────────
let meyvələr = ["alma", "armud", "üzüm"];
console.log(meyvələr.join(", "));  // ▶ "alma, armud, üzüm"
console.log(meyvələr.join(" - ")); // ▶ "alma - armud - üzüm"
console.log(meyvələr.join(""));    // ▶ "almaarmudüzüm"

// ───────── flat() — iç-içə array-i düzləşdir ─────────
let iç_içə = [1, [2, 3], [4, [5, 6]]];

console.log(iç_içə.flat());      // ▶ [1,2,3,4,[5,6]]  (1 səviyyə)
console.log(iç_içə.flat(2));     // ▶ [1,2,3,4,5,6]   (2 səviyyə)
console.log(iç_içə.flat(Infinity)); // ▶ [1,2,3,4,5,6] (hamısı)

// ───────── fill() ─────────
let sifir = new Array(5).fill(0);
console.log(sifir); // ▶ [0,0,0,0,0]

let arr = [1, 2, 3, 4, 5];
arr.fill(9, 1, 4); // indeks 1-3 arası 9 ilə doldur:
console.log(arr); // ▶ [1,9,9,9,5]
Bölmə 09

9. 🐛 Ən Çox Rast Gəlinən Bug-lar

Hər proqramçı bu xətaları bir dəfə edir. Onları əvvəlcədən bilsən, saatlarla debug etməkdən xilas olursan.

🐛 Bug 1 — sort() rəqəmləri yanlış sıralayır

sort() standart olaraq elementləri string kimi müqayisə edir. Rəqəmlər üçün müqayisə funksiyası vermək şərtdir.

bug-sort.js 
// ❌ BUG:
[5, 10, 1, 100, 25].sort();
// ▶ [1, 10, 100, 25, 5]  ← "10" < "25" çünki "1" < "2" (?!)

// ✅ DÜZGÜN:
[5, 10, 1, 100, 25].sort((a,b) => a - b);
// ▶ [1, 5, 10, 25, 100]  ✅

🐛 Bug 2 — Referans ilə kopyalama

Array-i = ilə başqa dəyişkənə mənimsətsən, kopyalanmır — eyni array-ə işarə edir. Birini dəyişsən digəri də dəyişir!

bug-reference.js 
// ❌ BUG — kopyalama yox, referans:
let a = [1, 2, 3];
let b = a;      // b, a-nı kopyalamadı — hər ikisi eyni yeri göstərir
b.push(4);
console.log(a); // ▶ [1,2,3,4]  ← a da dəyişdi! 😱

// ✅ Düzgün kopyalama üsulları:
let c = [...a];          // spread (ən çox istifadə olunan)
let d = a.slice();      // slice() ilə kopyala
let e = [...a];
e.push(99);
console.log(a); // ▶ [1,2,3,4]  ← dəyişmədi ✅
console.log(e); // ▶ [1,2,3,4,99]

// ⚠️ Qeyd: Bu üsullar SƏTHI kopyalamadır.
// İç-içə obyekt/array-lər hələ də paylaşılır!

🐛 Bug 3 — typeof ilə array yoxlamaq

Array-lərin typeof nəticəsi "object" olur. Array-i yoxlamaq üçün Array.isArray() istifadə et.

bug-typeof.js 
let arr = [1, 2, 3];

// ❌ YANLIŞ yoxlama:
console.log(typeof arr);         // ▶ "object"  (fərq görünmür)
console.log(typeof {});          // ▶ "object"  (eyni!)
console.log(typeof null);        // ▶ "object"  (JavaScript'in klassik xətası)

// ✅ DÜZGÜN yoxlama:
console.log(Array.isArray(arr)); // ▶ true  ✅
console.log(Array.isArray({}));  // ▶ false ✅
console.log(Array.isArray("salam"));// ▶ false ✅

🐛 Bug 4 — map / filter əvəzinə forEach işlətmək

forEach() heçvaxt bir şey qaytarmır (undefined). Dəyər toplamaq istəyirsənsə map() ya filter() işlət.

bug-foreach-return.js 
let r = [1,2,3];

// ❌ BUG — forEach heç nə qaytarmır:
let ikiqat = r.forEach(x => x * 2);
console.log(ikiqat); // ▶ undefined  ← !!!

// ✅ DÜZGÜN — map() yeni array qaytarır:
let doğru = r.map(x => x * 2);
console.log(doğru); // ▶ [2,4,6]  ✅

🐛 Bug 5 — delete ilə element silmə

delete arr[i] elementi silmir, sadəcə undefined ilə əvəz edir. Array-in uzunluğu dəyişmir. Bunun əvəzinə splice() işlət.

bug-delete.js 
let arr = ["A", "B", "C", "D"];

// ❌ YANLIŞ:
delete arr[1];
console.log(arr);        // ▶ ["A", undefined, "C", "D"]  ← boşluq!
console.log(arr.length); // ▶ 4  ← hələ 4!

// ✅ DÜZGÜN — splice ilə tam sil:
let arr2 = ["A", "B", "C", "D"];
arr2.splice(1, 1);
console.log(arr2);        // ▶ ["A","C","D"]  ✅
console.log(arr2.length); // ▶ 3  ✅

🐛 Bug 6 — Dövrə içərisində array-i dəyişdirmək

Üzərindən keçdiyin array-i eyni dövrə içərisində dəyişdirsən, gözlənilməz nəticələr çıxar.

bug-loop-mutation.js 
let arr = [1, 2, 3, 4, 5];

// ❌ PROBLEM — dövrə gedərkən splice işlətmək:
for (let i = 0; i < arr.length; i++) {
  if (arr[i] % 2 === 0) {
    arr.splice(i, 1); // element sildikdə indekslər sürüşür!
  }
}
console.log(arr); // ▶ [1,3,5] görünür amma 4 unudula bilir!

// ✅ DÜZGÜN — filter() istifadə et:
let tək = [1,2,3,4,5].filter(n => n % 2 !== 0);
console.log(tək); // ▶ [1,3,5]  ✅
