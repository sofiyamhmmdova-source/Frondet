01

Funksiya nədir?

Proqramlaşdırmada funksiya (function) — müəyyən bir işi yerinə yetirmək üçün yazılmış, adlandırılmış kod blokudur. Funksiyalar sayəsində eyni kodu dəfələrlə yazmaqdan xilas oluruq.

🧠 Real həyat bənzətməsi

Düşün ki, sən hər səhər çay dəmləyirsən: su qaynadırsan, çay tökür, şəkər əlavə edirsən. Bu addımlar həmişə eynidir. Funksiya da eynən belədir — bir dəfə yazırsın, istədiyin qədər "çağırırsan".

♻️ DRY Prinsipi

DRY — Don't Repeat Yourself (Özünü Təkrar Etmə) deməkdir. Bu, proqramlaşdırmanın ən fundamental qaydasıdır. Eyni kodu iki dəfə yazmaq əvəzinə bir funksiya yazıb onu çağır.

DRY Prinsipinin Nümayişi 
// ❌ PISI YANAŞMA — eyni kodu 3 dəfə yazdıq
console.log("Salam, Əli!");
console.log("Salam, Leyla!");
console.log("Salam, Kamran!");

// ✅ DRY YANAŞMASİ — bir funksiya, sonsuz istifadə
function salamVer(ad) {
  console.log("Salam, " + ad + "!");
}

salamVer("Əli");     // → Salam, Əli!
salamVer("Leyla");   // → Salam, Leyla!
salamVer("Kamran");  // → Salam, Kamran!
💡

Əsas ideya: Funksiya bir dəfə yazılır, istənilən qədər çağırılır. Bu, kodu qısa, oxunaqlı və dəyişdirməsi asan edir.

02

Funksiya növləri

JavaScript-də funksiya yaratmağın bir neçə yolu var. Hər birinin öz xüsusiyyəti var — gəlin hamısını öyrənək.

📝 2.1 — Function Declaration (Funksiya Bəyannaməsi)

Ən klassik üsul. function açar sözü ilə başlayır, sonra funksiyaya ad verilir. Bu üsulun xüsusiyyəti: funksiya kodda yazılmadan əvvəl də çağırıla bilər (buna Hoisting deyilir — bunu 6-cı bölmədə öyrənəcəyik).

Function Declaration 
// Struktur: function ad(parametrlər) { ... }

function toplama(a, b) {
  return a + b;
}

let netice = toplama(5, 3);
console.log(netice); // → 8

// Hoisting — funksiyadan ƏVVƏL çağırmaq mümkündür!
console.log(salam()); // → "Əhsən!" — xəta vermir!

function salam() {
  return "Əhsən!";
}

💾 2.2 — Function Expression (Funksiya İfadəsi)

Funksiya bir dəyişkənə mənimsədilir. Bu üsulda funksiyaya ad vermək məcburi deyil (belə funksiyalara anonymous — anonim funksiyalar deyilir). Hoisting işləmir — funksiya yalnız yazıldıqdan sonra çağırıla bilər.

Function Expression 
// Funksiya bir dəyişkənə mənimsədilir
const vurma = function(a, b) {
  return a * b;
};

console.log(vurma(4, 6)); // → 24

// ❌ Bu xəta verər — Hoisting işləmir!
// console.log(vurma(4, 6)); ← bu sətri əvvəl yazsaq, ReferenceError

// Funksiyalar dəyişkənlər kimi ötürülə bilər
const emeliyyat = vurma;
console.log(emeliyyat(3, 3)); // → 9

🏹 2.3 — Arrow Function (Ok Funksiyası)

ES6 (2015) ilə gəlmiş müasir sintaksis. Daha qısa yazılır. function açar sözünün əvəzinə => (ox) işarəsi istifadə edilir. Əhəmiyyətli fərq: Arrow funksiyaların öz this konteksti yoxdur (bu, irəli mövzudur).

Arrow Function — Müxtəlif Yazılış Formaları 
// ─── Uzun forma (bir neçə sətir kodu) ───
const salam = (ad) => {
  const mesaj = "Salam, " + ad;
  return mesaj;
};

// ─── Qısa forma (tək ifadə — return avtomatikdir) ───
const kvadrat = (x) => x * x;
// ← return yazmırıq, avtomatik qaytarır!

// ─── Tək parametrdə mötərizə isteğe bağlıdır ───
const ikiqat = sayi => sayi * 2;

// ─── Parametrsiz — mötərizə mütləqdir ───
const vaxtGoster = () => new Date().toLocaleTimeString();

console.log(salam("Aytən"));  // → Salam, Aytən
console.log(kvadrat(5));     // → 25
console.log(ikiqat(7));      // → 14
console.log(vaxtGoster());   // → 14:32:05 (məsələn)
📌

Nə zaman hansını istifadə etməli? Ümumi qayda: müasir proyektlərdə Arrow function daha çox istifadə edilir. Lakin metodlar və konstruktorlar üçün klassik function daha uyğundur.

03

Parametrlər, Arqumentlər və Default Dəyərlər

🔤 Parametr vs Arqument fərqi

  • Parametr (Parameter) — funksiya tərifindəki yer tutucu dəyişkəndir. Funksiya yazılarkən müəyyən edilir.
  • Arqument (Argument) — funksiya çağırılanda göndərilən əsl dəyərdir.
🧠 Bənzətmə

Parametr — blankdakı boş xanalardır: "Ad: ____". Arqument isə həmin xanaya yazdığın əsl məlumatdır: "Ad: Nigar". Blank (şablon) bir dəfə hazırlanır, amma hər dəfə fərqli məlumat doldurula bilər.

Parametr və Arqument 
//        ↓ parametr  ↓ parametr
function tanit(ad, yas) {
  console.log(ad + " — " + yas + " yaşındadır.");
}

//    ↓ arqument  ↓ arqument
tanit("Murad", 25);   // → Murad — 25 yaşındadır.
tanit("Xədicə", 30); // → Xədicə — 30 yaşındadır.

// Çox arqument göndərsən — artıqlar nəzərə alınmır
tanit("Elvin", 22, "Bakı"); // "Bakı" nəzərə alınmır

// Az arqument göndərsən — çatmayanlar "undefined" olur
tanit("Günel"); // → Günel — undefined yaşındadır.

🎯 Default Parameters (Standart Dəyərlər)

Arqument göndərilmədikdə undefined əvəzinə müəyyən edilmiş standart dəyər istifadə olunur. Bu, ES6 ilə gəlmiş çox faydalı xüsusiyyətdir.

Default Parameters 
//                  ↓ default dəyər    ↓ default dəyər
function sifaris(mehsul, say = 1, renk = "qara") {
  console.log(say + " ədəd " + renk + " rəngli " + mehsul);
}

sifaris("köynək", 3, "mavi");
// → 3 ədəd mavi rəngli köynək

sifaris("şalvar", 2);
// → 2 ədəd qara rəngli şalvar  ← "qara" default işləndi

sifaris("papaq");
// → 1 ədəd qara rəngli papaq   ← ikisi də default işləndi

// Arrow function ilə default parametr
const gucle = (eded, guc = 2) => eded ** guc;
console.log(gucle(3));    // → 9  (3² — default 2)
console.log(gucle(2, 10)); // → 1024 (2¹⁰)
💡

Praktik tövsiyə: Default dəyərlər həmişə parametr siyahısının sonunda yerləşdirilməlidir. Əgər ortada olarsa, onu atlayıb növbətisinə keçmək çətin olar.

04

Return — Geri Qaytarma

return açar sözü funksiyanın bir dəyər qaytarması üçün istifadə edilir. Funksiya return-a çatanda dayaqır və nəticəni çağırıcıya ötürür.

🧠 Bənzətmə

Hesablamalar aparan maşın kimi düşün. Bir tərəfdən ham material (parametrlər) daxil olur, maşın işləyir, digər tərəfdən isə hazır məhsul (return dəyəri) çıxır. Maşının çıxışı olmasa, içəriyə nə getdiyinin heç bir fərqi olmaz.

return ilə vs. return-süz funksiya 
// ❌ Return olmayan funksiya — dəyər saxlanmır
function cemi1(a, b) {
  a + b; // hesablanır, amma heç yerə getmir
}
let x = cemi1(4, 5);
console.log(x); // → undefined ← itib getdi!

// ✅ Return olan funksiya — dəyər qaytarılır
function cemi2(a, b) {
  return a + b;
}
let y = cemi2(4, 5);
console.log(y); // → 9 ✓

// return — funksiyanı ANINDA dayandırır
function yoxla(eded) {
  if (eded < 0) {
    return "Mənfi ədəd!"; // ← buradan çıxır
  }
  return "Müsbət ədəd!"; // ← yalnız yuxarı işləmədikdə
}

console.log(yoxla(-5)); // → Mənfi ədəd!
console.log(yoxla(7));  // → Müsbət ədəd!
return-un praktik gücü — funksiyaları birləşdirmək 
// Hər funksiya öz işini edir, return sayəsində birləşirik
const daireSahesi = (r) => Math.PI * r ** 2;
const yuvarlaq = (sayi, reqem) => sayi.toFixed(reqem);

const radiuslu = 5;
const sahe = daireSahesi(radiuslu);
console.log(yuvarlaq(sahe, 2)); // → "78.54"

// Funksiya nəticəsini birbaşa istifadə
console.log(yuvarlaq(daireSahesi(3), 2)); // → "28.27"
⚠️

Tuzaq: return-dan sonra gələn kod heç vaxt işləmir! JavaScript bunu "dead code" (ölü kod) adlandırır. Bəzi linterlər sizi xəbərdar edər.

05

Scope — Əhatə Dairəsi

Scope — dəyişkənin kodun hansı hissəsindən görünə biləcəyini, yəni əhatə dairəsini müəyyən edir. Bu, JavaScript-in ən vacib konseptlərindən biridir.

🧠 Ev bənzətməsi

Düşün ki, bir ev var. Həyətdə (Global Scope) olan şeylər — meşbə, ağaclar — hamı tərəfindən görülür. Yataq otağında (Function Scope) olan şeylər — çarpayı, şkaf — yalnız o otaqda olanlar tərəfindən görülür. Həyətdəki adam otağa girməsə, içəridəkiləri görə bilmir.

🌍 Global Scope
let dil = "Azərbaycan";
📦 Function Scope
let sehir = "Bakı";
🔒 Block Scope
let kuce = "İstiqlaliyyət";

🌍 5.1 — Global Scope (Qlobal Əhatə Dairəsi)

Hər hansı funksiyanın xaricində müəyyən edilmiş dəyişkənlər qlobal scope-dadır. Onlara kodun istənilən yerindən müraciət etmək mümkündür.

Global Scope 
let sirketAdi = "AzərTech"; // ← Global scope

function birinci() {
  console.log(sirketAdi); // → "AzərTech" ✓ görür
}

function ikinci() {
  console.log(sirketAdi); // → "AzərTech" ✓ o da görür
}

birinci();
ikinci();
⚠️

Diqqət: Çox sayda qlobal dəyişkən yaratmaq pis təcrübədir. Böyük proyektlərdə bu, gözlənilməz xətalara — "name collision" problemlərinə — səbəb ola bilər.

📦 5.2 — Function (Local) Scope — Funksiya Əhatə Dairəsi

Funksiyanın içindəki dəyişkənlər yalnız o funksiyanın daxilindən görünür. Xaricindən müraciət etmək mümkün deyil — sanki kilid vurulmuş otaq kimidir.

Function Scope 
function hesapla() {
  let neticə = 100; // ← Local (function) scope
  console.log(neticə); // → 100 ✓ daxildən görünür
}

hesapla();

// ❌ Funksiyadan kənarda müraciət — xəta!
// console.log(neticə); ← ReferenceError: neticə is not defined

// Hər funksiya öz dəyişkən "kimiçi"ni yaradır
function funA() {
  let deger = "A-nın dəyəri";
  console.log(deger);
}

function funB() {
  let deger = "B-nin dəyəri"; // Eyni ad, başqa dəyər — ziddiyyət yoxdur!
  console.log(deger);
}

funA(); // → A-nın dəyəri
funB(); // → B-nin dəyəri

🔒 5.3 — Block Scope (Blok Əhatə Dairəsi)

Fiqurlu mötərizələr { } arasındakı kod bloku — if, for, while, switch — öz scope-unu yaradır. let və const blok scope-a hörmət edir. var isə blokları keçir (bu problematikdir!).

Block Scope — let vs var 
// ─── let ilə block scope ───
if (true) {
  let blokDeyeri = "mən blokdayam";
  console.log(blokDeyeri); // ✓ blok içindən görünür
}
// console.log(blokDeyeri); ← ❌ ReferenceError! blokdan çıxdı

// ─── var ilə blok keçir (PROBLEM!) ───
if (true) {
  var varDeyeri = "mən qaçdım!";
}
console.log(varDeyeri); // → "mən qaçdım!" ← ❌ gözlənilməz!

// ─── for dövrəsindəki klassik tuzaq ───
for (let i = 0; i < 3; i++) {
  console.log(i); // → 0, 1, 2
}
// console.log(i); ← ❌ let ilə buradan görünmür
06

var, let, const — Fərqlər və Hoisting

JavaScript-də dəyişkən elan etmənin 3 yolu var: var, let, const. Onların arasındakı fərqləri bilmək çox vacibdir.

var
  • Function-scoped
  • Yenidən elan edilə bilər
  • Hoisted — undefined ilə
  • Köhnə standart
  • İstifadə etmə!
let
  • Block-scoped
  • Dəyəri dəyişdirilə bilər
  • Hoisted — lakin başlatılmır
  • Müasir standart
  • Dövrə sayğacı üçün ✓
const
  • Block-scoped
  • Dəyəri dəyişdirilə bilməz
  • Hoisted — lakin başlatılmır
  • Müasir standart
  • Default seçim ✓✓
var, let, const müqayisəsi 
// ─── var: köhnə, problemli ───
var ad = "Orxan";
var ad = "Tərlan"; // ← eyni adla yenidən — XƏTA VERMİR! (problem)
console.log(ad);   // → "Tərlan"

// ─── let: dəyər dəyişər, yenidən elan edilməz ───
let sayi = 10;
sayi = 20;         // ← dəyər dəyişdirildi ✓
// let sayi = 30; ← ❌ SyntaxError: yenidən elan edilə bilməz

// ─── const: dəyişməz (primitiv üçün) ───
const PI = 3.14159;
// PI = 3.14; ← ❌ TypeError: Assignment to constant variable

// ⚠️ const ilə obyekt/array daxilini dəyişmək olar!
const insan = { ad: "Nərmin" };
insan.ad = "Könül"; // ← Obyektin içi dəyişdirilə bilər ✓
console.log(insan); // → { ad: "Könül" }

🏗️ Hoisting (Yuxarı Qaldırma)

Hoisting — JavaScript mühərrikinin bütün dəyişkən və funksiya elanlarını, kod icra edilməzdən əvvəl, scope-un yuxarısına "apararaq" tanıması prosesidir. Ancaq dəyərlər yuxarı getmir — yalnız elanlar.

Hoisting — necə işləyir? 
// ─── var ilə hoisting ───
console.log(x); // → undefined (xəta yox! amma dəyəri gəlmir)
var x = 5;
console.log(x); // → 5

// JavaScript bunu belə "görür" (arxa planda):
// var x;            ← elan yuxarı çıxdı
// console.log(x);   → undefined
// x = 5;            ← dəyər öz yerindədir

// ─── let/const ilə hoisting — "Temporal Dead Zone" ───
// console.log(y); ← ❌ ReferenceError: TDZ-dədir!
let y = 10;
console.log(y); // → 10 ✓

// ─── function declaration ilə hoisting — mükəmməl işləyir ───
console.log(salamVer()); // → "Salam!" ← funksiyadan ƏVVƏL çağırıldı!

function salamVer() {
  return "Salam!";
}
🚫

Tövsiyə: Hoisting-ə güvənmək pis təcrübədir. Dəyişkənlərinizi həmişə istifadə etməzdən əvvəl elan edin. var əvəzinə const və let istifadə edin. Bu, bir çox gizli xətanın qarşısını alır.

07

Closure — Bağlam (Giriş Anlayışı)

Closure — bir funksiyanın, o funksiya müəyyən edildikdə mövcud olan xarici dəyişkənlərə, həmin dəyişkənlər artıq scope-dan çıxsa belə, çatmaq imkanıdır. Bir az mürəkkəb səslənsə də, onu anlamaq JavaScript ustası olmaq üçün çox vacibdir.

🧠 "Xatirə" Bənzətməsi

Düşün ki, bir uşaq böyüyür. Valideynlərinin onu böyütdükdə istifadə etdiyi kitablar — "uşaqlığın kitabları" — artıq evdə olmasa da, uşaq böyüdükdə o kitabların məzmununu xatırlayır. Closure da belədir: funksiya, yarandığı mühitin "xatirəsini" saxlayır.

Closure — Əsas Nümunə 
function sayac() {
  let eded = 0; // ← bu sayac() scope-undadır

  return function() {
    eded++; // ← xarici eded-ə çatır! (Closure)
    return eded;
  };
}

const say = sayac(); // sayac() bitdi, amma eded "yaşayır"

console.log(say()); // → 1
console.log(say()); // → 2
console.log(say()); // → 3

// Hər sayac müstəqildir!
const say2 = sayac();
console.log(say2()); // → 1 (yenidən 0-dan başladı)
console.log(say());  // → 4  (köhnə sayac davam edir)
Closure-un Praktik İstifadəsi — Özəl Dəyişkənlər 
// "bank hesabı" — balansı qoruyuruq
function hesabYarat(ilkinMebleg) {
  let balans = ilkinMebleg; // ← xarici dünya görə bilmir

  return {
    yatir: (m) => { balans += m; return balans; },
    cek:   (m) => { balans -= m; return balans; },
    bax:   ()  => balans
  };
}

const hesab = hesabYarat(1000);
console.log(hesab.bax());     // → 1000
console.log(hesab.yatir(500)); // → 1500
console.log(hesab.cek(200));  // → 1300
// hesab.balans ← undefined! xarici dünyadan gizlənib
📌

Xatırlat: Closure — "funksiya + onun yarandığı mühit" kombinasiyasıdır. Bu, JavaScript-in ən güclü xüsusiyyətlərindən biridir və React Hooks, modul sistemi kimi müasir texnologiyaların əsasını təşkil edir.

08

Xülasə və Praktik Tapşırıqlar

Təbrik edirik! Bu dərslikdə öyrəndiklərini aşağıdakı cədvəldə yekunlaşdıraq:

Konsept Nə deməkdir? Açar söz/İşarə
Function Declaration Klassik funksiya tərifi, hoisting işləyir function ad() {}
Function Expression Dəyişkənə mənimsədilmiş funksiya const f = function() {}
Arrow Function Qısa sintaksis, öz this-i yoxdur const f = () => {}
Parametr Funksiyadakı yer tutucu dəyişkən function f(parametr)
Arqument Çağıranda göndərilən əsl dəyər f(arqument)
Default Parameter Arqument gəlmədikdə istifadə edilən dəyər function f(x = 5)
return Funksiyanı dayandırır, dəyər qaytarır return deger;
Global Scope Hər yerdən görünən dəyişkən Funksiyanın xaricindəki dəyişkən
Function Scope Yalnız funksiyanın içindən görünür function() { let x }
Block Scope Yalnız { } bloku içindən görünür let, const
Hoisting Elanların yuxarı "qaldırılması" var, function elanları
Closure Funksiyanın xarici scope-u "xatırlaması" Funksiya içindəki funksiya

🎯 Praktik Tapşırıqlar

TAP-01 · Asan

BMİ Hesablayıcı

Çəki (kq) və boy (m) parametrlərini qəbul edən bmiHesabla adlı bir funksiya yaz. Funksiya BMİ dəyərini (çəki / boy²) qaytarsın. Nəticəyə görə konsola "Norma", "Artıq çəki" və ya "Piylənmə" yazsın. (BMİ: <25 Norma, 25-30 Artıq, >30 Piylənmə)

TAP-02 · Orta

Şifrə Generatoru (Closure ilə)

Closure istifadə edərək bir şifrə generatoru funksiyası yaz. generatorYarat(uzunluq) funksiyası bir daxili funksiya qaytarsın. Həmin daxili funksiya çağırıldıqca hər dəfə uzunluq həcmli, rəsgele simvollardan ibarət yeni şifrə yaratsın. Hər generatorun öz uzunluğu olsun (məsələn, gen8 = generatorYarat(8), gen12 = generatorYarat(12)).

TAP-03 · Orta-Çətin

Scope Eksperimenti

Aşağıdakı kod nə çap edər? İcra etmədən cavabı yaz, sonra yoxla:

Scope Eksperimenti 
let reng = "qırmızı";

function boyama() {
  let reng = "mavi";
  console.log("boyama içi:", reng);

  function cercive() {
    console.log("cercive içi:", reng);
  }
  cercive();
}

boyama();
console.log("global:", reng);
TAP-04 · Çətin

Köhnə DRY-sız Kodu Yenidən Yaz

Aşağıdakı DRY prinsipini pozan kodu refactor (yenidən strukturlaşdır) et. Bütün hesablamaları parametr qəbul edən ümumi funksiyalarla əvəz et. Arrow function, default parametrlər və düzgün scope istifadə et:

Refactor ediləcək kod 
// ❌ Bu kodu düzəlt!
let endirim1 = 100 * 0.9;
let qiymeti1 = 100 - endirim1;
console.log("Yeni qiymət:", qiymeti1);

let endirim2 = 250 * 0.9;
let qiymeti2 = 250 - endirim2;
console.log("Yeni qiymət:", qiymeti2);

let endirim3 = 75 * 0.85;
let qiymeti3 = 75 - endirim3;
console.log("Yeni qiymət:", qiymeti3);
🚀

Növbəti addım: Bu mövzuları mənimsədikdən sonra — Higher-Order Functions (map, filter, reduce), Callbacks, Promises və Async/Await mövzularına keçə bilərsən. Funksiyalar bu konseptlərin hamısının əsasıdır!
