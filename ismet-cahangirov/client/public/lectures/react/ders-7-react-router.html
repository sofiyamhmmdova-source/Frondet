Niyə "routing" lazımdır?

Adi çoxsəhifəli sayta baxanda hər keçiddə brauzer serverə yeni sorğu göndərir və bütün səhifəni yenidən yükləyir. React kimi SPA tətbiqlərdə isə bunu istəmirik — bir dəfə yüklənən tətbiq daxilində "səhifələr" arasında ani keçid edilir. Bu işi React Router görür.

01 · Nəzəri Hissə

Route Xəritəsindəki Dayanacaqlar

Aşağıdakı 6 dayanacaq React Router-i sıfırdan öyrənmək üçün məntiqi ardıcıllıqdır — hər biri özündən əvvəlkinin üzərində qurulur.

1

SPA-da Routing Necə İşləyir

Brauzerin History API-si (pushState, replaceState) sayəsində URL ünvan çubuğunda dəyişiklik etmək mümkündür — serverə heç bir sorğu getmədən. React Router bu API-ni "dinləyir": URL dəyişəndə hansı komponentin həmin ünvana uyğun gəldiyini tapır və yalnız onu ekranda göstərir. Server isə ilk yükləmədə tək bir index.html qaytarır, qalan hər şeyi brauzerdəki JavaScript idarə edir.

2

react-router-dom Quraşdırılması

Kitabxana npm vasitəsilə əlavə olunur. Vite, Create React App və s. bütün müasir React qurğuları ilə birbaşa işləyir:

terminal
npm install react-router-dom

Quraşdırdıqdan sonra package.json faylında react-router-dom asılılıq kimi görünməlidir.

3

Əsas Komponentlər: BrowserRouter, Routes, Route

  • <BrowserRouter> — History API-ni tətbiqə bağlayan "əhatə edici" komponent. Adətən bütün tətbiqi bir dəfə, ən yuxarı səviyyədə əhatə edir.
  • <Routes> — daxilindəki <Route>-lardan cari URL-ə uyğun gələn ilkini tapıb göstərən konteyner.
  • <Route> — bir path-ı bir komponentə (element) bağlayır.
App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;
4

Link vs adi <a> teqi

Bu, ən vacib fərqlərdən biridir. <a href> brauzerin default naviqasiyasını işə salır — səhifə tam yenidən yüklənir və React tətbiqinin vəziyyəti sıfırlanır. <Link> isə klik hadisəsini tutur (preventDefault), History API vasitəsilə URL-i dəyişir və yalnız uyğun komponenti yenidən göstərir.

Navbar.jsx
// ❌ Səhifəni tam yükləyir, SPA məntiqini pozur
<a href="/about">Haqqımızda</a>

// ✅ Yalnız komponenti dəyişir, sürətli, state qorunur
<Link to="/about">Haqqımızda</Link>

// Aktiv linki fərqli stillə göstərmək üçün NavLink
<NavLink
  to="/about"
  className={({ isActive }) => isActive ? 'nav-link active' : 'nav-link'}
>
  Haqqımızda
</NavLink>

Qayda: tətbiq daxilindəki keçidlər üçün həmişə Link/NavLink, xarici saytlara keçid üçün adi <a href> istifadə et.

5

useNavigate və useParams Hook-ları

  • useParams() — URL-in dinamik hissəsindəki dəyəri oxumaq üçün (məs. /product/:id → id).
  • useNavigate() — kod daxilində (məs. düymə basıldıqda, formadan sonra) proqramla yönləndirmə üçün.
ProductDetail.jsx
import { useNavigate, useParams } from 'react-router-dom';

function ProductDetail() {
  const { id } = useParams();       // URL-dən :id-ni oxuyur ("3" kimi string)
  const navigate = useNavigate();   // proqramla naviqasiya üçün

  function handleBuy() {
    navigate('/checkout/success');  // sifarişdən sonra yönləndirmə
  }

  return (
    <div>
      <button onClick={() => navigate(-1)}>← Geri</button>
      <h2>Məhsul ID: {id}</h2>
      <button onClick={handleBuy}>Al</button>
    </div>
  );
}
6

Nested və Dynamic Route-lar

Dynamic route — URL-in bir hissəsi dəyişən parametrdir: /product/:id. Nested route isə bir route-un daxilində başqa route-ların yerləşməsidir; valideyn komponent özündə <Outlet /> saxlamalıdır ki, uşaq route orada göstərilsin.

App.jsx
<Routes>
  <Route path="/products" element={<ProductsLayout />}>
    <Route index element={<ProductList />} />
    <Route path=":id" element={<ProductDetail />} />
  </Route>
  <Route path="*" element={<NotFound />} />
</Routes>
ProductsLayout.jsx
import { Outlet } from 'react-router-dom';

function ProductsLayout() {
  return (
    <div>
      <h1>Məhsullar</h1>
      {/* uşaq route-lar məhz bu yerdə göstəriləcək */}
      <Outlet />
    </div>
  );
}
02 · Praktiki Hissə

Çoxsəhifəli Tətbiq Strukturu

İndi öyrəndiklərimizi real layihə strukturuna çevirək: Home, About, Contact və dinamik Product Detail səhifələri, üstəgəl 404 səhifəsi.

Qovluq strukturu src/

src/ ├─ components/ │ └─ Navbar.jsx ├─ pages/ │ ├─ Home.jsx │ ├─ About.jsx │ ├─ Contact.jsx │ ├─ ProductDetail.jsx │ └─ NotFound.jsx ├─ data/ │ └─ products.js ├─ App.jsx └─ main.jsx

Bütün route-ların birləşdiyi fayl App.jsx

App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import Navbar from './components/Navbar';
import Home from './pages/Home';
import About from './pages/About';
import Contact from './pages/Contact';
import ProductDetail from './pages/ProductDetail';
import NotFound from './pages/NotFound';

function App() {
  return (
    <BrowserRouter>
      <Navbar />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
        <Route path="/product/:id" element={<ProductDetail />} />
        {/* Diqqət: "*" HƏMİŞƏ ən sonda olmalıdır */}
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;

Aktiv linkli naviqasiya components/Navbar.jsx

Navbar.jsx
import { NavLink } from 'react-router-dom';

function Navbar() {
  const linkStyle = ({ isActive }) =>
    isActive ? 'nav-link nav-link--active' : 'nav-link';

  return (
    <nav className="navbar">
      {/* "end" olmasa "/" hər zaman aktiv görünər */}
      <NavLink to="/" className={linkStyle} end>Ana səhifə</NavLink>
      <NavLink to="/about" className={linkStyle}>Haqqımızda</NavLink>
      <NavLink to="/contact" className={linkStyle}>Əlaqə</NavLink>
    </nav>
  );
}

Dinamik məhsul detalları pages/ProductDetail.jsx

ProductDetail.jsx
import { useParams, useNavigate } from 'react-router-dom';
import products from '../data/products';

function ProductDetail() {
  const { id } = useParams();
  const navigate = useNavigate();

  // useParams həmişə string qaytarır — Number-ə çeviririk
  const product = products.find((p) => p.id === Number(id));

  if (!product) {
    return (
      <div>
        <p>Belə məhsul tapılmadı.</p>
        <button onClick={() => navigate('/')}>Kataloqa qayıt</button>
      </div>
    );
  }

  return (
    <div className="product-detail">
      <button onClick={() => navigate(-1)}>← Geri</button>
      <img src={product.image} alt={product.name} />
      <h2>{product.name}</h2>
      <p>{product.price} AZN</p>
    </div>
  );
}

export default ProductDetail;

04 · Tez-tez Verilən Suallar

Ən çox soruşulan 3 sual

Brauzer refresh edəndə niyə bəzən xəta çıxır?

Local development zamanı (Vite/CRA dev server) bu adətən problem yaratmır, çünki dev server avtomatik olaraq bütün ünvanlar üçün index.html qaytarır. Amma production-da adi statik server (Nginx, Apache və s.) /product/5 kimi ünvan üçün fiziki fayl axtarır — belə fayl yoxdur, nəticədə server 404 verir.

Həll: server-i elə konfiqurasiya et ki, tanımadığı bütün ünvanlar üçün index.html-i qaytarsın (SPA fallback), qalanını React Router öz üzərinə götürsün:

nginx.conf / _redirects
# Nginx nümunəsi
location / {
  try_files $uri /index.html;
}

# Netlify — public/_redirects faylı
/*  /index.html  200

Vercel bunu avtomatik edir, Apache-da isə .htaccess faylında oxşar "rewrite" qaydası yazılır.

Link ilə adi <a> teqinin fərqi nədir?

<a href> brauzerin default naviqasiyasını işə salaraq bütün səhifəni yenidən yükləyir və tətbiqin state-ini sıfırlayır. <Link to> isə klik hadisəsini tutub History API ilə URL-i dəyişir, yalnız uyğun komponent yenidən render olunur, state qorunur. Sadə qayda: daxili keçidlər üçün Link, xarici saytlar üçün <a>.

useParams ilə useSearchParams nə vaxt işlədilir?

useParams — URL-in path hissəsindəki, route strukturunun məcburi bir parçası olan dəyərlər üçündür (/product/:id — dəyər olmadan bu səhifənin mənası yoxdur). useSearchParams isə query string-dəki (?sort=asc&category=telefon) opsional parametrlər üçündür — filtr, sıralama, səhifələmə kimi, dəyər olmasa da səhifə normal işləyir.

ProductList.jsx
import { useSearchParams } from 'react-router-dom';

function ProductList() {
  const [searchParams, setSearchParams] = useSearchParams();
  const category = searchParams.get('category'); // ?category=elektronika

  function filterBy(cat) {
    setSearchParams({ category: cat });
  }

  return (
    <button onClick={() => filterBy('elektronika')}>
      Elektronika
    </button>
  );
}
05 · Ola Biləcək Xətalar

Ən çox rast gəlinən buglar

React Router öyrənərkən demək olar hər kəsin qarşılaşdığı 8 tipik problem və onların həlli.

01 "useNavigate() may be used only in the context of a <Router>" xətası

SƏBƏBBrowserRouter tətbiqə əlavə edilməyib, ona görə Link, useNavigate, useParams kimi elementlər "Router konteksti" tapmır.
HƏLLBrowserRouter-i ən yuxarı səviyyədə (məs. main.jsx-də) əlavə et və bütün tətbiqi onun daxilinə al.

02 <a href> istifadə etdikdə səhifənin "yanıb-sönməsi"

SƏBƏBAdi <a> teqi brauzerin default naviqasiyasını işə salır — tam səhifə yenidən yüklənir, state itir.
HƏLLTətbiq daxilindəki bütün keçidlər üçün <Link> və ya <NavLink> istifadə et.

03 Parametr dəyişəndə komponentin "yenilənməməsi"

SƏBƏB/product/1-dən /product/2-yə keçəndə React eyni komponenti yenidən istifadə edir (unmount etmir), ona görə boş asılılıq siyahılı useEffect yalnız bir dəfə işləyir.
HƏLLuseEffect-in asılılıq massivinə parametri əlavə et: useEffect(() => { ... }, [id]).

04 404 route bütün digər route-ları "udur"

SƏBƏBpath="*" olan Route siyahının başında və ya ortasında yerləşdirilib — Routes ilk uyğun gələni seçir, "*" isə hər ünvana uyğun gəlir.
HƏLLpath="*" olan Route-u <Routes> daxilində həmişə ən sonda yerləşdir.

05 Nested route-da uşaq komponent heç görünmür

SƏBƏBValideyn (layout) komponentində <Outlet /> unudulub.
HƏLLLayout komponentinin JSX-inə uşaq route-ların göstəriləcəyi yerdə <Outlet /> əlavə et.

06 Nested route-da path düzgün uyğunlaşmır

SƏBƏBUşaq route-un path-ı "/" ilə başlayıb (path="/:id") — bu, mütləq (absolute) path kimi qəbul olunur və valideynlə birləşmir.
HƏLLNested route-larda uşaq path-larını "/" olmadan nisbi (relative) yaz: path=":id".

07 useParams-dan gələn id ilə massivdəki id üst-üstə düşmür

SƏBƏBuseParams() həmişə string qaytarır ("3"), massivdəki id isə adətən number-dır (3). === müqayisəsi fərqli tipləri bərabər saymır.
HƏLLNumber(id) ilə çevir: products.find(p => p.id === Number(id)).

08 Production-da bütün daxili keçidlərdə 404

SƏBƏBHosting/server SPA fallback üçün konfiqurasiya olunmayıb (bax: yuxarıdakı FAQ bölümü).
HƏLLDeploy etməzdən əvvəl serverin bütün naməlum ünvanlar üçün index.html qaytardığından əmin ol.
06 · Tövsiyələr

Nələri etsək daha yaxşı olar?

1Route-ları mərkəzləşdir

Böyük layihələrdə bütün route-ları App.jsx-də qarışdırmaqdansa, ayrıca routes.jsx faylında massiv kimi təsvir et.

2Lazy loading istifadə et

React.lazy + Suspense ilə hər səhifəni ayrıca bundle et — ilkin yüklənmə sürətlənir.

3Ortaq Layout qur

Navbar/Footer kimi ortaq elementlər üçün Outlet əsaslı Layout komponentindən istifadə et, hər səhifədə təkrarlama.

4Aktiv linki NavLink ilə göstər

Link yerinə NavLink istifadə et ki, isActive ilə cari səhifəni vizual fərqləndirə biləsən.

5"Tapılmadı" halını idarə et

Dinamik səhifədə uyğun məlumat tapılmadıqda boş ekran göstərmə — aydın mesaj və geri qayıtma yolu təklif et.

6Redirect-lərə diqqət et

Formadan sonra navigate(..., { replace: true }) istifadə et ki, "Geri" düyməsi istifadəçini yenidən formaya qaytarmasın.

7Server konfiqurasiyasını yoxla

Deploy etməzdən əvvəl hostinqin SPA fallback (bütün ünvanlar üçün index.html) qaydasını mütləq təsdiqlə.

8TypeScript ilə tipləşdir

TypeScript istifadə edirsənsə, useParams<{ id: string }>() kimi tipləşdirmə səhvləri erkən aşkarlayır.

07 · Yekun

Bu dərsdə nə öyrəndik?

  • SPA-da client-side routing server routing-dən nə ilə fərqlənir və History API necə işləyir.
  • BrowserRouter, Routes, Route ilə əsas naviqasiya strukturunu qurmağı.
  • Link/NavLink ilə <a> teqinin fərqini və nə üçün SPA-da Link istifadə olunduğunu.
  • useNavigate ilə proqramla, useParams ilə URL-dən dinamik dəyər oxumağı.
  • Nested və dynamic route-ları Outlet ilə birlikdə qurmağı, 404 səhifəsini düzgün yerləşdirməyi.
  • Ən çox rast gəlinən 8 xətanı və onların qarşısını necə almağı.

Növbəti addım: yuxarıdakı tapşırığı tamamla, məhsul kataloqunu qur və hər məhsul üçün ayrıca detal səhifəsini işlət. Bonus tapşırıqları da unutma! 🚀
