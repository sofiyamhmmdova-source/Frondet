HTML əsasları

Səhifənin strukturunu qur, məzmunu semantik teqlərlə təşkil et və əlçatan formalar hazırla.

← Kurs səhifəsinə qayıt

1. HTML sənədinin quruluşu

HTML brauzerə səhifədə hansı məzmunun olduğunu bildirir. Sənəd doctype ilə başlayır; head bölməsində metadata, body bölməsində isə görünən məzmun yerləşir.

<!doctype html>
<html lang="az">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mənim səhifəm</title>
  </head>
  <body>
    <h1>Salam!</h1>
    <p>Mənim ilk səhifəm.</p>
  </body>
</html>

2. Başlıqlar, mətn və keçidlər

h1 əsas başlıqdır; sonrakı bölmələr üçün h2 və h3 istifadə et. Başlıq səviyyələrini görünüşə görə yox, məzmunun quruluşuna görə seç.

<h1>Portfolio</h1>
<h2>Haqqımda</h2>
<p>Mən veb proqramlaşdırma öyrənirəm.</p>
<a href="https://example.com">Layihələrimə bax</a>

Siyahılar üçün ul/ol və onların içində li teqindən istifadə olunur. Şəkillərə məzmunu izah edən alt mətni əlavə et.

3. Semantik səhifə quruluşu

Semantik teqlər səhifə hissələrinin məqsədini bildirir və həm oxunaqlılığı, həm də əlçatanlığı yaxşılaşdırır.

<header>Saytın başlığı</header>
<nav aria-label="Əsas menyu">Keçidlər</nav>
<main>
  <section>
    <h2>Layihələr</h2>
    <article>Portfolio layihəsi</article>
  </section>
</main>
<footer>Əlaqə məlumatları</footer>

4. Əlçatan forma

Hər input üçün görünən label yarat. for atributu input-un id dəyərinə uyğun olmalıdır. Uyğun input tipindən istifadə et ki, brauzer məlumatı yoxlamağa kömək etsin.

<form>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Göndər</button>
</form>
Tapşırıq: Özün haqqında portfolio səhifəsi hazırla. Səhifədə semantik header, menyu, “Haqqımda” bölməsi, ən azı iki layihə, alt mətnli şəkil və əlaqə forması olsun.
